# R20260917-01 · 成片模板编排与人机协同

本主题定义一个新工具的需求、调研与方案：**给一段已有 MP4 和若干文档，让 AI 无人值守地
产出带模板化字幕的成片；人想插手时，提供一个代价极低、不绑定 Recordly 窗口的干预面；
人改完能无损交回 AI 继续，最终沉淀成可复用的「项目」。**

## 一句话

**AI 跑完全程是默认；人只在必须时插一脚；插脚的界面由我们决定，不必是 Recordly 那个窗口。**

**建设方式**：不再"学会整个工具再用它"，而是**按需取材、按需构建**——
从开源仓**合法合规地**取用需要的那一部分（接口契约 / 外部工具 / 代码），
整合进自己的项目，再由人机协同串成流水线（`01` §11）。

### 需要提前知道的四个硬事实

1. **AI 可以手写项目并出片** —— 本轮已实测跑通，不是推测（`06`§2）。
2. **人工改完交回 AI 基本无损** —— 13 个字幕字段里 12 个能安全往返，
   **唯一被毁的是 `fontFamily`**，而它恰好是"换清秀中文字体"的关键（`06`§3）。
3. **Recordly 没有任何对外 API/CLI** —— 只有 18 个 `RECORDLY_SMOKE_EXPORT*` 环境变量，
   且它们**只能触发导出，不能打开项目**。所以"独立工具"是**唯一可行**形态，
   且"自动布景打开 GUI"**做不到**（`04`§7、ADR-10）。
4. **交接面有一个真陷阱** —— Recordly 有 **1 秒静默自动保存**且**无文件监听**：
   AI 在人打开 GUI 期间改写 `.recordly` 会被无声冲掉（`04`§2.5.2）。
   这直接决定了方案必须引入**交接锁 + 指纹校验**（ADR-04）。
