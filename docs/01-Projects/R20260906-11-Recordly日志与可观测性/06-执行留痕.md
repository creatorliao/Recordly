# 06 · 执行留痕

## 变更 1 · 按次启动会话日志与金路径埋点

| 维度 | 记录 |
|------|------|
| **① 修改了哪些内容** | `electron/sessionLog.ts`、`sessionLogFormat.ts`（及测试）；`main.ts` 启动/退出；IPC `register/sessionLog.ts`；preload / `electron-env.d.ts`；录制/选源/光标/字幕/导出/弹框收口；启动窗「打开日志文件夹」 |
| **② 是怎么修改的** | 每次 `whenReady` 新建 `<userData>/logs/recordly-时间-pid.log`（JSONL）。挂钩 console.error/warn、崩溃、渲染 console。金路径写一等事件。`notifyError`/`notifyAlert` 先入档再展示。资源快照：相位切换 + 录制中 5s / 空闲 30s |
| **③ 有什么作用** | 打包后也能对着「这一次启动」排障；弹框与回退浏览器采集、光标 helper 失败不再只闪界面 |
| **④ 对工作流的影响** | 录→停→编→导不变。更多菜单多一项「打开日志文件夹」（可选）。出问题把 `logs` 里最新那一份交给智能体 |

- 专题：`R20260906-11`
