# 02 · 问题：没有按次启动的会话日志

> 与 `01` 同期落盘。触发场景：`R20260906-09` 成片卡顿 / 鼠标不同步——现场已经发生，磁盘上对不上「这一次启动」的运维日志。

## 1. 现象

1. 培训师走完录→停→编→导后，成片卡、鼠标跟不上，或弹出错误。
2. 事后想让智能体「对着日志查」，找不到**本次启动**的单一日志文件。
3. 开发时 `npm run dev` 能在终端里看到 `console.log`；**打包装好的 Windows 应用**关掉终端后，这些输出通常无处可寻。

## 2. 为什么这是运营问题而不只是开发问题

| 谁 | 需要什么 |
|----|----------|
| 培训师 | 出问题后能把「这一次」的文件交给人 / 智能体 |
| 运维 / 开发 | 判断卡在采集、合成还是导出；弹框是否同一根因 |
| 智能体 | 一份有界上下文：启动头（版本、路径、后端）+ 时间线 + 错误 |

没有会话文件时，只能靠复述现象，`R20260906-09` 才会停在「根因未查、录的时候卡还是整合时卡分不清」。
