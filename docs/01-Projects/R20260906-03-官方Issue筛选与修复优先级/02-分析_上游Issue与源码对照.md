### 集群 P · Windows Portable / 安装位置（G1 装得上，**你已改判保留**）

| Issue | 状态 | 症状 |
|-------|------|------|
| **#886** | open | 只要 portable，不安装就能用 |
| **#386** | closed（未做成） | 要 Windows **解压即跑的 ZIP**；Release 里的 zip 没有可直接运行的 exe，installer `.exe` 被误当成 portable |
| **#706** | open | 希望装到非系统盘 / 自选路径 |

**源码（本仓）：** `electron-builder.json5` 的 `win.target` **只有 `nsis`**，没有 `portable` / `zip`。NSIS 已开 `allowToChangeInstallationDirectory: true` → **#706「改安装目录」在本仓配置上可能已满足**，真缺口是免安装包。`app.getPath("userData")` 默认仍进本机 AppData，U 盘带走不会带走项目/设置，除非再做「数据跟 exe 走」。

**上游 PR：** 检索时**没有**专门做 Windows extract-and-run 的干净 open PR。#883（Windows installer，已合）是安装向导，与 portable **互补不是替代**。Linux AppImage（#818）仍剔除。

**设计约束：** 构建仍可打 NSIS（能力不删）。**对内发布默认 ZIP 解压即跑**（你已说安装包每次被拦）。单文件 `portable` 不像安装也不担保，不当默认。详见 `03` §1.6.1。
