## 二、核心工作流程（金路径）

```
启动录制 → 选窗口（软件）→ 边操作边讲解 → 停止 → 编辑 → 导出视频
```

核心能力（必须稳）：

1. **录得稳**：窗口录的是那个窗口；焦点不被抢；HUD 不挡点击  
2. **点得动**：录制中能点被录软件（含画面下方）  
3. **听得清**：麦克风讲解不断、导出后还有声  
4. **存得了**：项目能保存/打开；能回到录制  
5. **剪得省**：自动缩放、修剪，录完到导出尽量 ≤15 分钟  
6. **字得上**：一键字幕（G3）  
7. **导得出**：MP4 有画面有声  
8. **装得上**：内部监控常拦安装包 → **对内主发解压即跑 ZIP**；NSIS 能力可留着不当日常分发；身份仍用 Electron  

**保留方向（你已点名，不是当前金路径保命，但不剔除）：**

9. **导入第三方视频**：把已有成片/片段（会议录像、手机拍的、别人给的 MP4）拉进同一条编辑时间线，再剪、加字幕、导出 —— 服务 G2（少开第二个剪辑软件）  
10. **直播**：把「边讲边让人看见」做成可推流（如 RTMP），和录课场景接近；**默认仍是录→编→导**，直播为可选能力  
11. **Portable**：解压即跑（U 盘/无管理员/躲安装拦截）。**发布默认给 ZIP**；安装包降为备胎（见 `03` §1.6.1、`14` D17）  
12. **手机当摄像头 / QR 镜像**：手机当讲解脸或麦、同网扫码镜像手机屏 —— 你很喜欢；可选，默认仍录电脑窗口  
13. **点击音 / 扩展音频**：操作有「咔哒」、导出里听得见 —— **可以考虑**；做成产品内可选，不靠已死的扩展商店  
14. **美颜 / 虚化 / 像素化 / 壁纸**：露脸更干净、打码、换背景 —— **以后加都好**；默认关，不挡金路径

## 三、目标锚（落不进就不做）

| 编号 | 目标 | 衡量 |
|------|------|------|
| G1 | 金路径可用 | 录→停→编→导无阻断 |
| G2 | 减轻剪辑 | 录完到导出 ≤15 分钟 |
| G3 | 字幕 / 配音 | 一键字幕、讲解声可靠 |
| G4 | 少而稳 | 不过度设计；默认不改老习惯 |

范围：

- 平台 **仅 Windows**（Linux / macOS-only 一律剔除）  
- 语言 **简体中文 + 英文**  
- 分支 `dev-creator`，本地修，不代关上游 Issue  
- 低垂果实（面小、好修、对金路径有用）**优先考量**

## 四、本轮筛 Issue 的原则（对上最佳实践）

**值得做：** 断金路径、或点名能力（声/字幕/省剪辑）、或低垂且方向一致。  
**弄掉：** 其他 OS、**重建扩展商店本身**、巨型 GPU 换引擎当主导出。  
**保留（你已改判，均不插队金路径保命）：** 导入（#824）；直播（#878）；portable（#886/#386/#706）；**手机摄像头/QR（#418/#427，及相关 PR 如 #426）**；**点击音/扩展音频（#443/#574/#572，及相关 PR）**；**美颜/虚化/像素/壁纸（#186/#701/#385/#480，及相关 PR 如 #835）**。后三类默认关、可选开。扩展商店文档/市场入口仍不做。  
**每个候选：** 过四闸 → 打 R/C/E → 看象限 → 极高分优先；过不去且能决定暂缓的，记文档不硬做。
