# 01 · 需求：场景与尺子

## 角色与目标

| 项 | 内容 |
|----|------|
| 角色 | 培训师，用 Recordly 录软件操作课 |
| 金路径 | 启动录制 → 停止 → 编辑 → 导出 |
| 本夹要回答的缺口 | 录制中途暂停再继续：成片是两段还是一段？中间怎么接？ |
| 落进的目标 | G1 完整路径可用（停得下、进得了编辑器）；G4 体验可预期、不过度设计 |
| 范围 | 仅 Windows 主路径（原生 DXGI / WGC 捕获）；浏览器 MediaRecorder 作对照。不改产品代码。 |

## 场景

培训师点开始录制后，控制条上的按钮变成暂停。讲到一半要翻讲义、接电话，点暂停；回来点继续，再讲完点停止，进编辑器。

他需要知道：

1. 时间轴上会出现两个视频片段，还是一个？
2. 暂停那段墙钟时间会不会写进成片（黑场、静音、空镜）？
3. 画面、系统声、麦克风、光标、摄像头是否同一套时钟？

## 成功 / 失败

| 成功 | 失败 |
|------|------|
| 用源码能说清「一段文件、墙钟暂停被抠掉、时间戳接上」 | 只凭界面猜测「暂停=分段」 |
| 分清「同一次会话暂停」与「停录后再录第二次」 | 和 `R20260907-04` 的多段合并混为一谈 |
