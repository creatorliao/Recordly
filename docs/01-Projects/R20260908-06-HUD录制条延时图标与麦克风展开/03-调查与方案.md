# 调查与方案

调查日：2026-09-08。对照附图-01～03 与 `LaunchWindow.tsx`。

## 现状（改前）

```text
[ Screen 图标 + 名 + caret ] | [ 麦图标=开菜单 ] [ 电平 ] [ 系统声 ] [ 摄像头=开菜单 ]
[ 齿轮=倒计时菜单 ] [ 红录 ] [ 拍板 ] [ 笔记 ] [ 三点 ]
```

| 控件 | 图标 | 点击实际 | 用户以为 |
|------|------|----------|----------|
| 倒计时 | `GearSixIcon` | 选 0/3/5/10s | 打开设置 |
| 麦克风 | `MicIcon` | 只开 Popover | 开关麦（title 也这么写） |
| Screen | `SourceIcon` + caret | 开源列表 | 展开选屏（正确） |

菜单里倒计时选项已经用 `TimerIcon`，条上却换成齿轮，新旧不一致。

## 施工规格

```text
[ Screen 图标 + 名 + caret ]
[ 麦标=开关 ][ caret=设备 ] [ 电平 ] [ 系统声 ] [ 摄像头 ]
[ 秒表(+秒数)=倒计时 ] [ 红录 ] …
```

- `HudIcons.tsx` 增加 `CountdownIcon`（线宽与其它 HUD 标一致）。  
- 延时钮 `title` / `aria-label` = `recording.countdownDelay`；`countdownDelay > 0` 时显示数字并 `ibActive`。  
- 麦：外层 `hudSplit`；左钮 `setMicrophoneEnabled`；关麦时关掉 mic 浮层。右钮才是 `MicPopover` trigger，caret 旋转对齐 Screen。  
- 不改 `CountdownPopover` 选项、不改设备枚举。

## 七问

1. G4，开录路径不变。  
2. 不新设置页、不加第三套图标库。  
3. 倒计时秒数与麦列表逻辑不动。  
4. 培训师要一眼认出「几秒后开录」和「麦开没开」。  
5. 箭头在麦旁边，不挪到顶栏。  
6. 关麦走左钮，避免 title 写开关、点击却出菜单。  
7. 对齐 Zoom/OBS/本条 Screen：主操作 + chevron 选设备。
