## PR-01 延时变成设置钮

| 字段 | 值 |
|------|----|
| 现象 | HUD 齿轮高亮，弹出「倒计时延迟 / 无延迟 / 3s / 5s / 10s」。菜单项自己是秒表，条上却是齿轮。 |
| 根因 | `LaunchWindow.tsx` 里 `CountdownPopover` 的 trigger 用 `GearSixIcon`，title/aria 走 `recording.deviceGear`（「设备与倒计时」）。齿轮语义是「设置」，培训师会当成更多设置，而不是开录前倒计时。 |
| 方案 | 条上改用 HUD 线标秒表（`CountdownIcon`）；有延时时显示秒数；文案改回 `countdownDelay`。齿轮只留在真正的设置（本条三点菜单），不占延时位。 |

## PR-02 麦克风不像 Screen

| 字段 | 值 |
|------|----|
| 现象 | Screen：显示器 + 名称 + 向下箭头，一看就能展开选源。麦：单独一只麦标，点了才出「关闭麦克风 / 设备列表」，条上看不出「旁边还能展开」。关麦还要塞进菜单。 |
| 根因 | `MicPopover` 把整颗 icon 按钮当 `PopoverTrigger`。没有 caret。主按钮 title 写成 enable/disable，实际点击却是开菜单，**文案和行为打架**。 |
| 方案 | 对齐 Screen 的「主件 + 展开箭头」：麦标点击 = 开/关麦；箭头点击 = 打开设备浮层。竖条同样保留两件，避免只能关不能选。 |
