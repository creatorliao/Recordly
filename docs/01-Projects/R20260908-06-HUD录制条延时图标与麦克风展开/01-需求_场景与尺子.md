# 需求：HUD 延时图标与麦克风展开

## 角色与范围

| 项 | 内容 |
|----|------|
| 角色 | 培训师，Windows 上点红钮开录 |
| 金路径 | **启动录制** → 停 → 编 → 导 |
| G | **G4**（图标对得上、不误解）；开录不被挡（G1） |
| 非目标 | 不改倒计时秒数、麦设备列表、录制链路；不新开设置页 |

## 用户原话（两点）

1. 延时相关设置为什么变成了设置（齿轮）按钮？图标对不上旧版。应改回**延时相关图标**。  
2. 禁用/启用麦克风：点麦克风时，旁边应有类似 **Screen** 的展开图标和功能。现在设计容易误解。

## 成功 / 失败

| 成功 | 失败 |
|------|------|
| 倒计时入口是秒表/延时标，不是齿轮；悬停文案是「倒计时延迟」 | 齿轮打开「倒计时延迟」，像进系统设置 |
| 麦图标点击 = 开/关麦；旁边箭头打开设备列表（对齐 Screen 的 caret） | 点麦只弹出菜单，条上无「还能展开」的提示 |
| 竖条仍能开/关麦、仍能选设备 | 竖条丢展开或丢开关 |
