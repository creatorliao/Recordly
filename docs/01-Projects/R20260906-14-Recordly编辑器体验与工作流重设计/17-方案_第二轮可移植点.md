- 点击穿透 / 拖动不回归。

### 3.3 I10 · 选源后自动开录

对齐 `openscreen/.../LaunchWindow.tsx` 的 `recordAfterSourceSelectionRef`。

**行为**

```
点录制
  ├─ 已在录 / 正在保存 → 忽略或走停录（与现在同）
  ├─ 已有源 → 直接 toggleRecording（含倒计时）
  └─ 没有源
        ├─ 打开现有源 popover（不要新开一套选择器）
        ├─ flag = true
        ├─ 用户挑中一个源 → flag 清掉 → toggleRecording()
        └─ 关掉 popover / 没选 → flag 清掉 → 不录
```

**落点**

- `LaunchWindow.tsx` 或 `useLaunchWindowActions.ts`：一面 `useRef`。
- `handleSourceSelect`：若 flag，选源成功后再开录。
- popover 关闭回调：清 flag（现有 `requestOpen("sources")` 那条路要接上关闭事件；没有关闭事件就在 popover `onOpenChange(false)` 清）。
- Linux 分支保持「直接录 / portal」，本仓 Windows 为主。

**不改**

- [#790 选源即开录] 仍不做：选源按钮本身只选不录；**只有从录制键进来的那次选择**才自动开录。
- 已有源时点源按钮：只换源，不开录。

**验收**

- 冷启动第一次：点录制 → 选「屏幕/窗口」→ 选完开始（有倒计时则先倒数）。
- 选到一半关掉：不录。
- 已经有源再点录制：立刻进倒计时/开录，不再弹选择器。

## 四、已有两项：只说明，不施工

### 4.1 A1 停录进编辑器

`finalizeRecordingSession` → `switchToEditor()`。手册已有「录完进剪辑」。本轮零改动。

### 4.2 A2 截图时条会「没了」

机制：`setContentProtection(true)` → `WDA_EXCLUDEFROMCAPTURE`。不是「检测到截图软件就 hide」。

本仓默认开，三点可关。Win+Shift+S / 系统截图预览里看不见条，和 OpenScreen 是同一条路。

手册补一句即可（等你说开始做再写进 `R20260906-01`）：「默认录像和系统截图里没有控制条；若要拍进条，到三点里关掉。」

微信/QQ 老截图仍可能拍到条：两边都这样。**不做进程监控。**

若以后做笔记窗：创建时同样 `setContentProtection`，并走现有 `reassertHudOverlayCaptureProtection`。
