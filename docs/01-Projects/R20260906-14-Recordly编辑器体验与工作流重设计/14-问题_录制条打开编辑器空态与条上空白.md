# 14 · 问题：录制条打开编辑器空态 + 条上空白

> 角色：培训师，录 Windows 软件操作。金路径：启动录制 → 停止 → 编辑 → 导出。  
> G1 路径不断 / G4 对齐大多数软件习惯。仅 Windows；简中 + 英文。  
> 用户已明示执行。本页是这两条真机问题的需求、对照与方案真源。

---

## 一、问题场景

### 问题 1 · 还没有录过，点「打开编辑器」被整页拦住

| 项 | 事实 |
|----|------|
| 谁 | 培训师，当天第一次打开，库里可能有旧课，也可能什么都没有 |
| 从哪来 | 录制条（未在录）点 **打开编辑器** |
| 现在怎样 | 不进完整编辑器。中间白底红字：「没有可加载的视频。请先录制或选择一段视频。」下面只有「打开项目」「返回录制」 |
| 为什么不对 | 按钮写的是打开**编辑器**，却换成一张拦截页。历史课在「打开项目」弹层里，不像剪映/Premiere 那种项目格子。老用户会以为软件坏了或必须先录一段 |

源码落点：`useInitialEditorSource` 找不到当前项目 / 当前录制会话 / 当前视频后 `setError(noVideoToLoad)`；`EditorShell` 一有 `error` 就整页替换，侧栏项目格子进不去。

### 问题 2 · 「打开编辑器」旁边有一块不该在的空白

P03 在录制键右侧加了「打开编辑器」后，旧的「打开项目」浮层没有删掉，而是藏成 `w-0 h-0` + 透明 trigger，仍插在条的 flex 里（`ProjectPopover`，且 HUD popover **不走 portal**）。视觉上就是魔杖钮和三点之间多出一块空。

---

## 二、用户要的行为（后说覆盖）

从录制条打开编辑器，**必须能打开完整编辑器**：

1. **有已录制的部分**（当前会话 / 当前视频 / 当前项目）→ 直接装载这一课。
2. **没有已录制的部分** → 装载**空项目**，左侧打开 **项目** 选项卡，让人点历史课、点上次那一课，或新建。

不要再出现那张红字拦截页（真文件损坏等加载失败除外）。

---

## 三、常用软件怎么做

| 软件 | 没有「当前正在编的素材」时 |
|------|---------------------------|
| 剪映 / CapCut | 进草稿箱/项目列表，选历史草稿或新建；不报「没有视频」整页错误 |
| Camtasia | 欢迎页：Recent + New Project，再进时间轴 |
| Premiere / DaVinci | 启动是项目管理器，选最近或新建，不会把空时间轴当成错误 |
| VS Code | 空工作区 + 资源管理器，选最近文件夹 |
| OBS | 打开即完整工作室，场景可以是空的 |
| 资源管理器 / Office | 点「打开」进完整窗口，最近文件在侧栏或开始屏幕 |

共同习惯：**点「打开编辑器」就进编辑器壳**；没素材 = 空画布 + 项目/最近列表，不是错误页。  
「新建」在录屏课场景里 = **回去录**（金路径）或 **从文件导入**，不要发明一个没有素材的迷宫时间轴当主入口。

本仓已有能力，只是空态没接上：侧栏项目格子（P04-D2）、文件菜单「最近打开 / 新建录制 / 从文件新建」、时间轴本来就会画「尚未加载视频」。

## 四、方案（已按用户口径代决）

### 4.1 打开规则

```
点「打开编辑器」
  ├─ 当前项目 / 当前录制会话 / 当前视频 有一个能装 → 装它，左侧停在「场景」
  └─ 都没有 → 空项目（不 setError）
        ├─ 完整编辑器壳（顶栏 / 左轨 / 时间轴）
        ├─ 强制打开侧栏，切到「项目」
        ├─ 预览区友好空态，不挂 VideoPlayback（空 src 会误报加载失败）
        └─ 列表按修改时间，第一格标「上次」
```

不自动打开最近一课（冷启动「启动时打开 = 编辑器」仍按 P02-B4 自动开最近课；从条上进来是用户要自己选）。

### 4.2 项目选项卡动作

| 动作 | 行为 | 对齐 |
|------|------|------|
| 点某一格 | 打开该课，切到「场景」看画面 | 剪映点草稿 |
| 第一格「上次」 | 只是角标，不自动进 | 用户自己点 |
| 导入 | 已有：选视频或 `.recordly` | 从文件新建 |
| 新建录制 | 返回录制条（未保存先问） | 金路径；文件菜单已有「新建录制」 |

### 4.3 条上空白

删掉条上隐藏的 `ProjectPopover`。三点菜单「打开项目」改为 `switchToEditor()`：有当前课就开课，没有就进空项目 + 项目选项卡。魔杖和三点之间**不再放分隔线**（浅色条上那条线加间距看起来像一颗空白按钮）。

### 4.4 不做

- 不改停录自动进编辑器（仍装刚录的那一课）
- 不改冷启动自动开最近课
- 不把真加载失败改成空态（冒烟缺路径、文件坏了仍走错误页）
- 不新造第三种「项目管理器窗口」

### 4.5 对金路径的影响

录 → 停 → 编 → 导 **不变**。只修「还没录就点打开编辑器」和条上多出来的空。  
操作变化：未录时点打开编辑器，从拦截页改成完整编辑器 + 项目选项卡。手册须提示。
