# 04 · 需求：工具栏 / 侧栏与 VS Code 对齐

> 2026-09-06 真机截图 + 口述。不改产品代码。  
> 原则：`AGENTS.md` §二.8（大多数软件习惯）+ 本条「专业工具跟 VS Code 的密度走」。

---

## 1. 你点的问题（原话收束）

1. **核心流程**要像剪映、OBS：录完进剪、导出先选路、设置进设置。  
2. **录制工具栏**不要自己搞一套胖胶囊；参考 VS Code，做成**标准、瘦、专业**的条。  
3. **编辑器左侧导航太粗**，参考 VS Code Activity Bar 收窄，把宽度还给预览/时间轴。  
4. 三点里的 **语言 / 外观 / 采集画质** 不该在常用工具里，应到**编辑器设置**。  
5. 圆角过大、高度过高，有「很 AI / 胖胖」的感觉。  
6. 工具栏上要有 **打开编辑器** 按钮（不要只藏在三点里）。

| 面 | 现在 | 观感问题 |

| 编辑器左轨 | 按钮 `36×36`（`h-9 w-9`）+ 图标 `27px` + 右侧圆点列 + `px-2` | 轨比 VS Code 粗一截 |
| 右侧设置板 | 固定约 `280–332px` | 和左轨加在一起吃预览 |

VS Code 对照（稳定惯例，不是抄皮肤）：

| 件 | VS Code | 我们应对齐的 |
|----|---------|--------------|
| Activity Bar | **48px** 宽，图标约 **24px**，无文字，hover 出 tooltip | 左轨收成 48px，图标 22–24 |
| 顶栏 / Tab 条 | 约 **35px** 高，圆角几乎为 0～4 | 编辑器顶栏、录制条都往 32–36 靠 |
| 设置 | `文件 → 首选项` / 齿轮，不进主工具条 | 语言、外观、画质进设置 |
| 常用动作 | 顶栏或命令，一键到达 | **打开编辑器**上条，不进三点 |

## 3. 哪些能跟 VS Code 对齐（综合考量）

**对齐（做）**

| 能力 | 为什么 | 落到哪 |
|------|--------|--------|
| 瘦活动栏 | 专业工具把像素留给内容 | 编辑器左轨 |
| 矮工具条、小圆角 | 桌面工具不是手机胶囊 | 录制 HUD + 编辑器顶栏 |
| 设置归设置 | 所有专业软件都这样 | 三点只留动作 |
| 主路径按钮外露 | VS Code 打开文件不藏菜单深处 | HUD「打开编辑器」 |
| tooltip 代替粗标签 | 活动栏不写字 | 左轨已有 tooltip，保持 |
| Delete / Ctrl+S | 已在方案 L6 | 不变 |

**不对齐（不做，避免过度设计）**

- 整套 File / Edit / Selection / Terminal / Git / 调试
- 面包屑、问题面板、命令面板重做
- 扩展市场当主入口（本仓已收敛）
- 把录制条做成 VS Code 状态栏（22px 太矮，红钮点不准）

录制条对标的是 **VS Code 标题栏密度 + OBS 控制条功能**，不是像素级抄 VS Code。

## 4. 和剪映 / OBS 的流程对齐（本条补强）

| 步 | 剪映 | OBS | 我们（方案） |
|----|------|-----|--------------|
| 打开 | 草稿箱 / 上次项目 | 进工作室（源+开始录制） | 设置：工具栏 \| 编辑器 |
| 录 | — | 开始录制在主界面 | 瘦工具条上的录制键 |
| 停 | — | 停完文件在案 | 停录进编辑器 |
| 编 | 左媒体 / 中预览 / 下时间轴 / 右属性 | 可选 | 已有；左轨收窄 |
| 导出 | 先选路径和名字 | 录像路径在设置里预先定 | 导出先选路 |
| 设置 | 设置页 | 设置窗口 | 外观语言画质进设置 |

## 5. 成功 / 失败

| 成功 | 失败 |
|------|------|
| 录制条一眼是「专业桌面条」，高度大约一指节 | 仍是胖胶囊、圆角像聊天气泡 |
| 三点一屏能看完，只有动作 | 还要滚到「语言」 |
| 左轨约 48px，预览明显变宽 | 图标 27px + 圆点列还在吃宽度 |
| 条上能直接点「打开编辑器」 | 仍要先开三点再找打开项目 |

**不做**：换肤主题引擎、重做整套动效、为「像 VS Code」加终端。

## 7. 后说覆盖（2026-09-06 晚）：VS Code 只借鉴编辑器顶栏

你补充：更希望借鉴 VS Code **窗口顶部那条菜单栏**（文件(F) 编辑(E) … 右侧一颗布局钮），并把**我们编辑器顶部工具栏**迁成这个样式；**只改这一部分**。

### 7.1 核查结论：上一稿方案不是这样

| 上一稿写的 | 和你要的差在哪 |
|------------|----------------|
| VS Code 主对齐面 = **左轨 Activity Bar 48px** | 你要的是 **顶栏菜单条**，不是活动栏 |
| 顶栏只是「顺手」：`h-11`(44)→36，图标 16–18，**不另开题** | 顶栏才是本题；不是减 8px 了事 |
| **不对齐**「菜单栏全家桶」 | 样式要对齐菜单栏；能力仍只用我们已有的文件/编辑/导出 |
| V2 一个包：左轨 + 顶栏一起改 | 违反「只改顶栏这一部分」 |

源码现状（`EditorHeader.tsx`）：一条 `h-11` 图标工具条——左：摄像头 / 文件夹 / 保存 / 文件下拉 / 撤销重做（带边框方钮）；中：课名；右：预设文字 + **蓝色导出胶囊**。这是图标工具条，不是 VS Code 那种左对齐文字菜单。

### 7.2 改成这样（只动顶栏）

**改的文件面**：`EditorHeader.tsx` 以及它直接拉起来的触发器样式（`EditorPresetMenu` 触发器、`EditorExportMenu` 触发器）。不改左轨、不改时间轴、不改录制 HUD、不改设置页内容。

**样式（只认官方源码，见 [`12`](12-对照_VSCode官方顶栏源码事实.md)，仓在 `D:\code\vscode` @ `3d7cfab`）**

- 条高 **30**（`titlebarPart.ts`：无 Command Center 时；有命令中心才是 35，我们不抄命令中心）  
- `line-height: 22px`；应用图标槽宽 **35**、图 **16**  
- 菜单标题：`padding: 0 8px`，`border-radius: 5px`  
- 左 / 中 / 右三栏 + 拖区，按 `titlebarpart.css` 抄  
- 左：`文件(F)` `编辑(E)`；中：课名 `font-size: 12px`；右：文字「预设」「导出」，不要 112px 蓝胶囊  
- hover/open 用 selection 底，不要图标砖

**能力（不借 VS Code 的项）**

| 菜单 | 映射已有动作 | 不新增 |
|------|----------------|--------|
| 文件(F) | 返回录制/新录制、从文件新建、打开项目、保存、另存 | — |
| 编辑(E) | 撤销、重做 | 选择 / 转到 |
| 预设 | 现成预设 popover，触发器改成文字 `预设` | — |
| 导出 | 现成导出下拉，触发器改成文字 `导出` | 运行 / 终端 / 帮助 |

不抄：终端、调试、Git、命令面板、整套英文菜单结构。

| 文件/编辑能点出原来那些动作 | 多出空的「终端」「运行」 |
