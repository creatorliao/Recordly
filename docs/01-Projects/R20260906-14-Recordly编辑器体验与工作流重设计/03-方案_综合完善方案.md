## 一、目标信息架构（一句话）

**两间房（录制工具栏 / 编辑器）由设置决定开哪间；导出先写地址；关窗默认退出（和大多数软件一样），可选缩到托盘；Tray 能进任一面也能退出。**

对齐原则见 `AGENTS.md` §二.8：默认跟剪映 / OBS / Windows 走，非常规行为可关。

```
设置「启动时打开」= 录制工具栏 | 编辑器
设置「关闭窗口时」= 退出应用（默认）| 最小化到托盘
            │
冷启动 ──► 按「启动时打开」进对应那一间
            │
     ┌──────┴──────┐
     ▼             ▼
录制工具栏       编辑器（侧栏项目格子）
     │             │
     │   互相一键切换；停录默认进编辑器
     │
窗口右上角 X ──► 未保存则问 ──► 按「关闭窗口时」
     ├─ 退出应用（默认，剪映/OBS 同类）
     └─ 藏到 Tray（可选；首次气泡说明）
            │
Tray（若启用）：打开录制工具栏 | 打开编辑器 | 退出
```

金路径动词仍是：录 → 停 → 编 → 导。两间房都合法。

### 1.1 按「大多数软件习惯」审查（后说覆盖）

对照：剪映 / CapCut、OBS、Camtasia、Windows 资源管理器、Office。微信/QQ 的「关到托盘」是**通讯常驻**习惯，不是剪辑/录屏同类的默认。

| 点 | 大多数软件怎么做 | 原方案 | 修订 |
|----|------------------|--------|------|
| 导出 | 先选目录和文件名，再编码 | 先选路 | **保持**（纠正当前产品的反习惯） |
| 启动 | 录屏软件进录制；剪辑软件进项目/最近草稿 | 二选一，默认工具栏 | **保持**默认工具栏；拨到编辑器时改为打开**最近一个项目**（没有才空态） |
| 关 X | 剪映/OBS/Camtasia：关窗≈结束这次；托盘软件会给「关闭时最小化到托盘」 | 写死 X 只回 Tray、退出只在 Tray | **改为可配置**：默认**退出应用**；可选最小化到托盘。Tray 仍做，不当唯一下班口 |
| 项目 | 剪映草稿箱、侧栏媒体库 | 侧栏格子 | **保持** |
| 设置 | 设置进设置，不进动作三点 | 三点清 Preference | **保持** |
| Delete | 删当前选中 | L6 仅可选 | **改为要做** |
| 文本/字幕按时段 | 剪映文字轨过了就收 | 播放时收 | **保持** |
| 波形 | 剪映/PR 看得见人声 | 默认开轨 | **保持** |
| 追加 | 时间轴加一段素材，不是拼死一个文件 | clip 追加 | **保持** |
| 停录 | 录完进剪辑 | D4 进编辑器 | **保持** |
| 工具条密度 | 浮层条跟 Open Screen；编辑器**顶栏**跟 VS Code 菜单条；左轨 48 是另一条更早口述 | 无 | **再修订** V2 拆开：顶栏=D17（本题）；左轨=D12（另包，不塞进「对齐 VS Code」） |

上一稿「X 必须回 Tray、退出只在 Tray」**不符合同类软件习惯**，已被本表覆盖。Tray 仍是能力，不是唯一门厅。

## 二、壳层设计（对你每条口述的答）

### 2.1 缩放：去重、补中文、不扩功能

| 做 | 不做 |
|----|------|
| 删掉区块内那颗「删除缩放」，只留底栏一颗 | 不改自动/手动算法 |

### 2.2 导出：先地址，后干活

目标顺序：

1. 点「导出」→ 预设/编码仍可先看  
2. 点「开始导出」→ **先**系统保存框（目录 + 文件名，默认课名而不是 `export-时间戳`）  
3. 取消 = 什么都不编  
4. 确认后编码；进度条仍在原下拉  
5. 完成 →「在文件夹中显示」+「完成」（不再写 Done）  
6. 上次目录记住，下一节课少点两次

对照 #713 / #525：同时避免「先写 C 盘 temp 再搬家」。能直接往用户选的路径流式写就直接写；技术上仍要临时文件时，**编码前路径已定**，完成后原子挪过去。

「完成」按钮走已有 `common.actions.done`。进度里的 `Path:` 改成中文「编码路径」或干脆不展示内部 runtime 字。

### 2.3 关窗：默认退出；托盘是可选项

源码已有 Tray，但 `shouldUseTray()` **只开 Linux**。Windows 仍打开 Tray **能力**（菜单、可选最小化），不是从零发明。

设置增加（与「启动时打开」放一起）：

| 项 | 说明 |
|----|------|
| **关闭窗口时** | **退出应用**（默认）\| **最小化到托盘** |
| 首次选托盘 | 气泡：「已放到托盘。要退出请点托盘图标 → 退出。」 |

| 动作 | 新语义 |
|------|--------|
| 窗口 X（默认） | 未保存则问 → **退出整个应用**（不重建 HUD） |
| 窗口 X（已选最小化到托盘） | 未保存则问 → 藏窗，Tray 还在 |
| 顶栏「返回录制」 | 出差：藏编辑器、亮工具栏（#796） |
| 停录 | 进编辑器（D4，录完进剪辑） |
| Tray 菜单 | 打开录制工具栏 / 打开编辑器 / 退出；录制中加显示控制条、停止录制 |
| 任务栏右键退出 | 与 Tray「退出」相同 |

文案中文化。X 与「返回录制」必须拆开。**不要**再写「退出只在 Tray」——那是微信习惯，不是剪映/OBS 习惯。

C2 与 Windows Tray 仍同批：没有 Tray 就做不了「可选最小化」。默认退出不依赖 Tray 也能先做，但同批更干净。

### 2.4 启动：设置里二选一，两面互切

设置（编辑器设置页，不进三点动作列表）增加一项，持久化：

| 项 | 说明 |
|----|------|
| **启动时打开** | 开关/两档：**录制工具栏** \| **编辑器** |
| 默认 | **录制工具栏**（打开录屏软件的习惯 + 今天冷启动） |
| 改成编辑器后 | 打开**最近一个项目**；没有才空态（剪映开草稿的习惯） |

编辑器空态仍三块：开始录制、打开已有项目、打开视频。  
录制工具栏加 **打开编辑器**。Tray 也能进任一面。不要只靠三点「打开项目」。

三点菜单只留动作。外观 / 语言 / 采集画质 / **启动时打开** / **关闭窗口时** → 设置。

录制条上**单独一颗「打开编辑器」**（图标 + tooltip，不要只写在三点里）。代决 **D13（R-HUD）**：放在**录制键右侧**（对齐 Open Screen 的 Studio）；**D14**：录制中隐藏，避免误点进编辑器停录。

[#790 选源即开录] 仍不做。
