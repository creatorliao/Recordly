## 1. Open Screen 控制栏是什么

一条浮在桌面底部的录制条。从左到右（横条；还可转成竖条）：

```
拖动手柄 | 横/竖切换 | 源（图标+短名）
| 系统声 | [麦 摄像头 设备齿轮] | （可选）光标模式
| 录制键（录时展开成 红点+计时）
| 未录：打开 Studio（编辑器）
| 录中：暂停 / 重来 / 取消
| 笔记（提词器，非 Linux）
| 语言 | 最小化 | 关闭
```

设计注释写死了一套数（`HudControls.tsx` 29–34 行）：

| 量 | Open Screen | 本仓现在 | 本夹上一稿代决 D11（VS Code 向） |
|----|-------------|----------|----------------------------------|
| 条圆角 | **17px**（钮圆角 10 + 上下垫） | 20px | 6px |
| 条内边距 | 横 **7×9** | 11×20 | — |
| 条内间距 | **5px** | 约 10px | — |
| 图标钮 | **34×34**，圆角 10 | 40×40，圆角 11 | 28 |
| 录制键 | **34**，录时变宽带计时 | **46** 实心圆 | 28–30 |
| 条底色 | 深色 `#14171c` + 模糊 | 浅/随主题白胶囊 | 未定 |
| 开态强调 | 翠绿 `#10b981` | 蓝色描边 | — |

其它做法：

- **分组靠分隔线和靠近**，麦/摄/齿轮用细描边组，**不用**灰底大胶囊把「Screen 1」框起来。
- 录制键录着时**自己显示 mm:ss**，不必另放一个秒表钮。
- **打开 Studio** 在条上，未录制才出现。
- 设备齿轮只开「选麦/选摄像头」浮层，不是外观/语言大菜单。
- 组件全 `memo`：计时每秒刷新时不重绘整条（性能）。
- 语言仍在条右侧——这点和我们「设置进设置」**相反**。

笔记/提词器、竖条、光标采集模式是他们的加分项，不是录屏条的最小集。

## 2. 和我们的差距（功能）

| 能力 | Open Screen | 本仓 HUD | 培训师金路径 |
|------|-------------|----------|--------------|
| 打开编辑器 | 条上 Studio | **无**（三点里打开项目/视频） | **要**（已定 C3） |
| 系统声开关 | 条上 | 不在条上（多在别处） | 常要，**建议上条** |
| 麦 / 摄像头 | 条上 + 齿轮选设备 | 条上，点开 popover | 已有，可收成一组 |
| 倒计时 | 不占主位 | 单独秒表钮 | 可用，但可收进齿轮/设置 |
| 录中计时 | 录制键上 | 另套一套 RecordingControls | 要看得见，不必单独胖钮 |
| 暂停/重来/取消 | 录中三颗小钮 | 已有，版式更肥 | 保持能力，收密度 |
| 外观/语言/画质 | 语言在条上 | 三点里全塞 | **不要上条**（已定） |
| 笔记提词器 | 有 | 无 | 非金路径，本轮不借 |
| 横竖条 | 有 | 无 | P2，本轮不借 |
| 深色固定皮 | 有 | 跟随主题 | **不借固定深色**（跟系统/编辑器主题） |

## 3. 整合建议（能借 / 不借）

### 3.1 建议借（推荐做）

| ID | 借什么 | 反推到本仓 | 主题 |
|----|--------|------------|------|
| I1 | 条上「打开 Studio」 | 已定「打开编辑器」，位置对齐：录制键右侧、未录制时显示 | A / B |
| I2 | 密度：钮 34、垫 7、间距 5、录制键 34 | **改写 D11**：不要 6px/28（太方太小，浮层不像工具条）；也不要现在的 20/46 | B |
| I3 | 分隔线 + 靠近分组，去掉「Screen 1」灰框 | 源选择改成图标+短名；麦/摄/设备齿轮一组细边 | B |
| I4 | 录制键兼计时 | 录中展开显示时间，可考虑收掉单独秒表占位（倒计时进齿轮） | B |
| I5 | 系统声一颗开关 | 条上，开态用主题强调色（不必抄绿） | B |
| I6 | 设备齿轮只选麦/摄 | 和「外观语言」彻底分开 | A / B |
| I7 | 计时 `memo` | 移植时别让每秒刷新整条（走查项，不是功能） | B |

### 3.2 建议不借（推荐不做）

| ID | 不借 | 原因 |
|----|------|------|
| X1 | 语言按钮上条 | 违反「设置进设置」、也违反你刚定的三点迁出 |
| X2 | 笔记/提词器 | 非培训金路径，G4 |
| X3 | 竖条 | 有用但本轮加交互面，P2 |
| X4 | 固定深色皮 + 翠绿 | 我们已有浅/深/跟随系统；抄一套皮会和编辑器打架 |
| X5 | 像素级抄 17/10/圆角配方当品牌 | 你说了不要完全一致；取密度，留自己的主题色 |

### 3.3 可选（你点头再做）

| ID | 项 | 说明 |
|----|----|------|
| O1 | 倒计时从条上挪进设备齿轮 | 条更短；少点一次也能设 |
| O2 | 录中隐藏「打开编辑器」 | 与 Open Screen 相同，避免误点进编辑器停录；停录后再出现 |
| O3 | 光标模式切换 | 仅当 Windows 捕获真需要；不进本轮视觉 |

## 4. 推荐决策（请选或改）

**推荐包 R-HUD（一条拍板即可）：采用 I1–I7，不采用 X1–X5；O2 采纳；O1 采纳；O3 不做。**

改过的密度代决（覆盖原 D11）：

| 代决 | 推荐 | 备选 |
|------|------|------|
| D11′ | 钮 **34**、条垫 **7**、条圆角 **12**（比他们 17 略方一点，比 VS Code 6 软）、录制键 **34** | 全抄 17/10；或坚持 6/28 |
| D13 | 打开编辑器在录制键右侧（与 Studio 同位） | 三点左侧 |
| D14 | 录中隐藏打开编辑器（O2） | 一直显示 |
| D15 | 倒计时进设备齿轮，条上不单独放秒表（O1） | 秒表留在条上 |
| D16 | 条跟随现有浅/深主题，不固定 `#14171c` | 录制条永远深色 |

和原 D11（VS Code 32–36 / 圆角 6）的关系：浮层 HUD **更宜取 Open Screen 的「小圆角胶囊」密度**，编辑器左轨仍走 VS Code 48px（V2 不动）。两套表面，两套尺子，不混用。
