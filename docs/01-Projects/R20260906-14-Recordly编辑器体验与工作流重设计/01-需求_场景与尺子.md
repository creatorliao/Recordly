## 一、角色 / 金路径 / 为什么改 / G / 范围

| 项 | 钉死 |
|----|------|
| 角色 | 培训师，录 **Windows 软件操作** 给学员看 |
| 金路径（动词，不变） | **启动录制 → 停止 → 编辑 → 导出视频** |
| 为什么改 | 壳层别扭：关窗回 HUD、导出先编再选路径、项目藏在顶栏下拉、编辑中无法追加、字幕/音频看不见；录完到导出被这些摩擦拖过 15 分钟 |
| G1 | 录→停→编→导无阻断 |
| G2 | 录完到导出 ≤15 分钟（少来回、少找入口） |
| G3 | 一键字幕、讲解声可靠（听得见、看得见波形、能改字） |
| G4 | 少而稳；不把剪映整套搬进来 |
| 范围 | 仅 Windows；只做简体中文 + 英文；工作在 `dev-creator`；本地移植，不代合/不代关上游 |

**后说覆盖（按时间，后者为准）：**

金路径**动词顺序**仍是录→停→编→导。壳层是**三个面**，不是「编辑器唯一的家」：

1. **两个开场都合法**：打开时进入 **录制工具栏**，或打开时进入 **编辑器**。在设置里用开关记下，不要写死一种。
2. **关窗跟大多数软件走**：默认 **退出应用**。需要常驻时，设置里「关闭窗口时最小化到托盘」。Tray 是可选能力，不是唯一下班口。
3. **导出 = 先选文件夹和文件名，再编码，再打开该目录。**
4. **项目 = 侧栏格子**，不是顶栏「打开文件夹」下拉。
5. **编辑中可继续录**，新片段追加到**当前时间轴**（默认仍可开新文件；追加是可选入口）。
6. **录制条借 Open Screen 密度与分组，不抄皮**（R-HUD，2026-09-06 拍板）：钮 34 / 垫 7 / 条圆角 12；条上打开编辑器、系统声、设备齿轮；倒计时进齿轮；录中藏打开编辑器。语言不上条。
7. **VS Code 只借鉴编辑器顶栏**（D17）：把现在的图标工具条迁成「文件(F) 编辑(E)」那种菜单条；**只改顶栏**。不抄终端/运行/帮助。左轨 48 是更早另一条，不和本题绑在一个 PR。

再后说：默认必须符合大多数人工作习惯、大多数软件使用习惯（`AGENTS.md` §二.8）。「只回 Tray」那一稿已覆盖。R-HUD 已锁定；整夹施工仍须「开始做」。

## 二、你点名的场景（培训师一天）

### 场景 A · 一节操作课（主路径，开场由配置决定）

- **配置 = 编辑器**：打开 → 项目格子 / 空态 → 点「开始录制」→ 只留工具栏 / 摄像头 → 停录回时间轴 → 导出先起名选目录。
- **配置 = 录制工具栏**：打开 → 直接选源开录（今天的习惯）→ 停录进编辑器 → 其余同上。

失败样子：无法自己选第一屏；关窗又掉进 HUD 迷宫；导出完才问存哪。

### 场景 A2 · 关窗与下班

默认：点 X → 未保存则问 → **应用退出**（和剪映/OBS 一样）。  
若在设置里打开「最小化到托盘」：点 X → 窗没了托盘还在 → 托盘可再开两间房或退出。  
不要再逼人关一层窗再关一层工具栏。

### 场景 B · 讲到一半发现漏了一步

在编辑器里 scrub 到漏讲的位置 → 点「继续录制（追加）」→ 录一小段 → 新片段出现在时间轴后面（可删、可挪）→ 不用另存一个项目再手工拼接。

### 场景 C · 隔天接着剪

打开软件 → 侧栏格子里看见昨天的课 → 点进去继续剪。不要去顶栏文件夹图标里翻下拉。

### 场景 D · 听得清、改得动

时间轴上能看见**人声波形**（哪段在讲、哪段静音）。字幕能点进去改，中文字体不方框、不西文回落。文本框只在它的时间段出现，过了就收，收的时候有进出动画。

### 场景 E · 两个工作面 + Tray 互切

录制工具栏条上就能 **打开编辑器**；编辑器能打开录制工具栏；Tray（若开）能进任一面或退出。三点只放动作。

### 场景 F · 工具条像专业软件，不像胖胶囊

录制条高度大约 VS Code 顶栏（32–36），圆角小。编辑器左轨约 48px。语言 / 外观 / 画质只在设置里。预览区明显比现在宽。

## 三、成功 / 失败

| 成功 | 失败 |
|------|------|
| 设置里能选「打开进工具栏」或「打开进编辑器」，下次照做 | 写死一种开场，另一种人每次多绕一圈 |
| 导出前能决定「课目录 + 文件名」 | 先编码，再弹框，文件名是时间戳 |
| 关 X 默认退出；可选缩到托盘 | 关 X 掉回 HUD 迷宫，或写死只能从托盘退出 |
| 侧栏格子能扫到最近的课 | 项目藏在顶栏图标下拉，最多露出一小条 |
| 时间轴看得到讲解声；字幕中文可读、可改 | 音频「看不见」；字幕字体像没装中文 |
| 文本框过了时间段就收 | 选中后播过去文字还贴在画面上 |
| 缩放面板中文一致、删除按钮只有一个 | ANIMATION / Classic Animation；两个「删除缩放」 |
| 录制条 R-HUD（钮 34 / 圆角 12）、左轨 48px、条上能进编辑器 | 胖胶囊、三点里滚语言、找不到编辑器 |

**不做（本主题）**

- Linux / macOS-only、九语种、替上游关 PR
- 把 Recordly 做成完整剪映（多机位、复杂调色、完整混音台）
- 原样吞下 >500 行 / Slop / 换引擎的社区 PR
- 本轮改产品代码（等你说「开始做」）
