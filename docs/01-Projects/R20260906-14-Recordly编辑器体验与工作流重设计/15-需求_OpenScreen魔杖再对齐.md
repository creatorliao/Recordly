## 三、笔记 ≠ 旁白（先钉死）

OpenScreen 条上的 **Notes** 中文是「打开笔记」。它是：

- 独立小窗：富文本讲稿 / 提词器
- 可自动向下滚、调字号、调速度、水平镜像（给提词器玻璃用）
- 内容存在本机 localStorage，下次还在
- **不进时间轴、不成片、不配音、不生成字幕**

它**不是**：

- 旁白 / Voiceover 音轨
- 录完后往时间轴加讲解声
- 字幕草稿

培训师用得上的是「录的时候看讲稿」，不是「往成片里加一条旁白轨」。若以后要旁白，那是时间轴加音频，另开题，不要和笔记绑在一起。

## 四、成功 / 失败（本轮若做）

| 成功 | 失败 |
|------|------|
| 打开编辑器一眼是拍板，tooltip 是「打开编辑器」 | 仍是魔杖，或改名叫 Studio |
| 录制键不比旁边图标钮更「喊」；录中变方块 + mm:ss | 34px 实心红球 + hover 外圈光 |
| 没选源点录制 → 选源 → 选完开录；关掉选择器不录 | 选完还要再点一次录制，或选完立刻录、取消不了 |
| 停录进刚录的那一课 | 停录停在空条上（本仓已不是这样） |
| 截图/成片默认不含控制条；用户能在三点里关掉 | 去监控微信/QQ/Snipping 进程名来藏条 |
| 笔记若做：可选、不挡金路径、不进成片 | 把笔记做成必走步骤，或误做成旁白轨 |
| 竖条若做：可关、默认仍横条 | 写死竖条，或竖条把点击穿透/拖坏掉 |
