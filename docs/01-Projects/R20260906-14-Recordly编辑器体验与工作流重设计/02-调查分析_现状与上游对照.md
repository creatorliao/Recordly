> 本仓**没有** Excel 清单；过往 PR 账在 `R20260906-02` 的 Markdown 表里。

## 一、当前产品实际在干什么（动词）

```
冷启动 → Launch/HUD（选源、三点菜单）
      → 开始录制（编辑器未开）
      → 停止 → 打开编辑器窗口
      → 关编辑器 X（Windows）→ 再造 HUD，应用不退出
      → 编辑器顶栏摄像头 = 「返回录制」（#796 已在本树）
      → HUD 三点里才能「打开项目 / 打开视频」，没有「打开编辑器」主按钮
      → 导出：点导出 → 立刻编码 → 完成后才 save 对话框 / 或先写 temp 再问路径
      → 完成框：「在文件夹中显示」+ 硬编码 Done
```

你感觉「总要一步步退回工具栏再关」，就是这条 Windows 关窗逻辑，不是错觉。

## 二、你点名的问题：源码对照

### 2.1 缩放面板：重叠 + 中英混杂

| 现象 | 事实 |

### 2.2 导出：先执行，后选路径

`useExportDialogActions.handleStartExportFromDropdown`：校验视频后立刻 `handleExport(resolvedSettings)`，**不先弹保存框**。

编码结束后 `saveExportBlob` → `finalizeExportedVideo` / `saveExportedVideo` 才问路径。取消保存会进入 `hasPendingExportSave`（「文件已经导出好了，再选一次」）。

完成 UI `EditorExportMenu.tsx`：

- 「导出完成 / 文件已成功保存」已走 i18n
- 关闭按钮写死 **`Done`**（`common.actions.done` =「完成」已存在，没用）
- `dialogs.json` 里有 `exportComplete`，导出下拉**没引用**
- 进度里还有硬编码 `Path: {exportRuntimeLabel}`
- 取消另存为：temp 留下，出现 **Save Again**（`hasPendingExportSave`）——先选路之后这条支路应消失

文件名默认 `export-<timestamp>.mp4`（截图已证实）。

| [#857](https://github.com/webadderallorg/Recordly/pull/857) | MERGED | 导出体验：去掉 Legacy/Lightning 选择、转圈提示。**没改「先选路径」** |

没有现成的小 PR 能直接把「先选路径」搬进来。

### 2.3 关窗回到 HUD

`electron/main.ts`：

- `closeEditorWindowToHud`：藏编辑器 → `createWindow()` 重建 HUD → 再关编辑器
- Windows 上 `editorWindow.on("close")`：**无未保存时也 `preventDefault` + `closeEditorWindowToHud`**
- `returnToRecording()` 复用同一条路（#796）

所以右上角 X 和「返回录制」在 Windows 上几乎是同一结局。后说已改为 **X = 回 Tray、退出在 Tray**，必须拆开这三条路：返回录制 / 藏到 Tray / 退出。

### 2.3b Tray 已有实现，但 Windows 被关掉

`electron/main.ts`：

- `createTray` / `updateTrayMenu` / `showHudOverlayFromTray` / `onStopRecordingFromTray` **都在**
- `shouldUseTray()` **只在 Linux 为真**（注释写明 Win/mac 走任务栏/Dock）
- 现菜单英文：`Open` / `Quit`；录制中：`Show Controls` / `Stop Recording`
- 左键点击 Tray = `focusOrCreateMainWindow()`，**没有「打开编辑器」项**

所以不是「将来从零做 Tray」，而是：**Windows 打开已有 Tray + 改菜单语义 + 关窗藏到 Tray**。体量中等，不是巨型新功能。

### 2.5 项目：已有小格子，但挂在顶栏浮层

`ProjectBrowserDialog`：**已经是 2 列缩略图网格**（`grid-cols-2`），最多 24 条；`renderMode` 默认 `floating`，锚在顶栏文件夹按钮上，宽约 248–300px。Launch 三点也调同一套。

缺的不是「从零做格子」，而是：**格子不在侧栏常驻**，要先点顶栏图标才看得到。侧栏现有图标是效果 / 光标 / 摄像头 / 字幕 / 设置 / 插件，不是项目库。上游 [#118](https://github.com/webadderallorg/Recordly/issues/118) 说的是「工具侧栏不好找」，**不是**项目库——可参考交互，不要当成现成方案。

### 2.7 降噪与音频

| 来源 | 状态 | 体量 | 结论 |
|------|------|------|------|
| [#777](https://github.com/webadderallorg/Recordly/pull/777) | OPEN | +1287 / 31 文件 | RNNoise / Speex / 关；默认 RNNoise。`12` 已 ⏸ 人工；默认必须改成关或温和才符合六问 |
| [#120](https://github.com/webadderallorg/Recordly/issues/120) | OPEN | — | 音量 / 静音 / 独奏 / 淡入淡出 / **波形** |

本仓**已经有**时间轴波形组件（`AudioWaveform.tsx`、`sourceAudioTracks.ts`），但 `showSourceAudioTrack` **默认 false**，且只在 clip 勾了 `showSourceAudio` 时才出现。所以你「完全看不到音频」——能力在，默认关着。

设置面板里已有音量 / 标准化，不是零。缺的是：**默认看见人声轨**，以及录制中的活波形。

### 2.8 字幕：改着费劲、字体有问题

| 事实 | 含义 |
|------|------|
| 默认字体 `SF Pro Text / Helvetica Neue`（`types.ts` `getDefaultCaptionFontFamily`） | Windows 上没有 SF Pro，中文会回落到系统西文/乱回落 |
| `AutoCaptionSettings.fontFamily` 字段在，**字幕面板没有字体选择器**（只有字号 / 行数 / 底边距） | 即使想换也换不了；文本框面板反而有字体列表（`AnnotationSettingsPanel`） |
| 文本框默认同样西文栈；占位符写死 `Enter text...` | 中英夹杂 + 中文排版差 |
| 预览里可点字幕改字（`useAutoCaptionController.handleSaveAutoCaptionEdit`） | 能力在，主路径仍偏右侧面板 + `CaptionListPanel` |
| `R20260906-08` | 已收「不要下载/选模型」；动画 key 已有中文 |
| 字幕**已有**进出动画（`captionLayout.ts` fade/rise/pop） | 文本框没有对等出场，可复用这套而不是新写引擎 |
| [#220](https://github.com/webadderallorg/Recordly/issues/220) 等 | 生成失败类，本主题不当主线（仍归 08 / G3 连通） |

### 2.9 文本框过了时间轴还在

`VideoPlayback.tsx` 过滤逻辑：

- 没有起止时间 → 不显示
- **当前选中的文本框 → 永远显示**（即使播放头已离开区间）
- 未选中的才按 `startMs–endMs` 显示

编辑时钉住选中项方便改位置；**一播起来就不该还贴在画面上**。文本框没有退出动画；字幕已有 fade/rise/pop，应复用而不是新写。

### 2.10 三点菜单里的 Preference

`MorePopover.tsx` 现在一锅炖：

- 动作：录制文件夹、日志、打开视频、打开项目、HUD 是否进画面
- 设置：外观三档、采集画质三档、语言

你说的「Preference 不该在那个列表里」对得上：**动作和偏好混在一个短菜单**。外观已中文化（05 已修），问题变成信息架构，不是翻译。
