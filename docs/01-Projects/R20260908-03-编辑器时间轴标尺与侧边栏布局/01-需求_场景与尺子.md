# 需求：时间轴标尺与侧边栏布局

## 角色与金路径

| 项 | 内容 |
|----|------|
| 角色 | 培训师，在 Windows 上录软件操作、进编辑器成片 |
| 金路径 | 启动录制 → 停止 → 编辑 → 导出 |
| 本夹 G | **G4** 体验良好、不过度设计；**G1** 编辑器壳层不挡操作 |
| 范围 | 仅 Windows；简中 + 英文；`dev-creator`；不代合上游 |
| 非目标 | 不改录制引擎、导出编码、时间轴剪辑语义；不做其它 OS |

## 用户原话（真源）

1. 时间轴标识时间的那个区域太宽了，看起来并不协调。
2. 时间轴标识时间的那部分，顶部和播放器重叠了一下，和左边面板也重叠了一部分，要计算好它们之间应有的距离。
3. 侧边栏应该延伸至底部，时间轴不要叠在侧边栏上面；配置按钮应该在左下角，保持和类似 VS Code 一样的外观和设计；被控制的部分放在侧边栏内，内侧要腾出空间给侧边栏，才符合大多数工具的设计。
4. 样式预设既出现在了场景里面，也出现在了场景的 tab、光标的 tab 里面。
5. 时间轴右侧也应该预留一些空间；直接延伸到屏幕边沿不合适。请对照剪映及同类产品。
6. **后说（改后复验，覆盖第 5 条）**：右侧留白浪费。块内不要图标、文字垂直居中。齿轮左边距与顶栏对齐。抽屉去多余圆角/阴影。滚到底要有底垫。音量改通用扁滑动条。折叠钮只要小图标。

## 成功 / 失败

| 成功 | 失败 |
|------|------|
| 刻度区与色块、运输条比例协调，无「空出一大条只写 00」 | 标尺仍占满窗口左缘，00 落在齿轮正下方 |
| 运输条、标尺、左轨、抽屉四者互不侵入，间距可说出像素 | 播头菱形或拖高抓手压住播放钮 |
| 左轨（48px）+ 抽屉从标题栏下沿到状态栏上沿不断开；齿轮在左轨底、状态栏之上 | 时间轴仍通栏切断左轨 |
| 样式预设只出现在拍板后的**一处**主入口 | 场景页与光标页各挂一张同样的卡且未说明「故意双挂」 |
| 内容列右缘贴窗（无 12px 白边）；折叠为纯图标 | 仍留 `pr-3` 空条 |
| 时间轴块内无装饰图标，单行垂直居中 | 块内放大镜/气泡 + 两行字 |
| 抽屉控件 2–3px、无 chrome 投影；滚到底 ≥12px 底垫 | 胶囊滑条、按钮贴窗口底 |

## 习惯对齐

对照 VS Code（活动栏通高、齿轮左下）、剪映 / CapCut / Premiere（时间轴在预览列下方，不压活动栏；**面板与窗口右缘留铬条/内边距，不顶屏幕**）。非常规行为不做。不新开右侧活动栏。
