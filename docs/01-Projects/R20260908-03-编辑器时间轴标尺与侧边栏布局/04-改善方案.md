# 改善方案

节拍：① 计划（本文）→ 等人评审 → ③ 才施工。  
原则：默认保金路径；新能力不另开入口；对齐 VS Code / 剪映，不发明第三种壳。

## 目标布局（推荐；**右沟已按 PR-06 取消**）

```text
┌─ Header（全宽）──────────────────────────────────┐
│ 文件 / 项目名 / 导出                              │
├─ 48px ─┬─ 抽屉 ─┬─ 预览 ─────────────────────────┤
│ 工具   │        │ 画面                           │
│  …     │        ├─ 4px 缝 + 抓手 ────────────────┤
│  ⚙居中 │        │ 标尺+轨道贴列右；折叠=纯图标   │
├────────┴────────┴─ 底栏 ─────────────────────────┤
│ 已保存                            0:05 / 0:18    │
└──────────────────────────────────────────────────┘
```

`@待确认`：底栏是否同样给左轨让出 48px（更像 VS Code）。推荐：**左轨穿过底栏高度**，底栏只在内容列；若怕「已保存」左移难看，底栏可全宽但左轨仍画到窗口底（底栏 `padding-left` 不小于 48）。

## S2 · PR-02 间距（像素契约）

在 S3 列模型上执行，数字如下（可在 `14` 改一格）：

| 缝 | 推荐 | 依据 |
|----|------|------|
| 运输条 ↔ 标尺 | **4px** | 放下 4px 抓手热区，互不压控件 |
| 抓手 | 列内顶边，`top:0`，高 4px，`z` 低于播头点击、高于轨道 | 取消 `-top-2` |
| 播头手柄 | 全部画在标尺盒 **内部**（`top: 2px`），禁止 `-top-1` 伸出 | 对齐专业轨 |
| 播头时间气泡 | 仍可向上，但 `pointer-events-none` 且运输条 `z-20`，气泡不得挡点击 | 拖轨时才出现 |
| 标尺 ↔ 左栏 | **0 重叠**：时间轴 `left` = 左栏右缘 | S3 自然满足 |
| 标尺/轨道 ↔ 窗口右 | **0～1px**（S5 已被 PR-06 废止） | 后说：右沟浪费 |
| 左轨 ↔ 抽屉 | 保持现有 1px `border-r` | 已有 |

选项 B：运输条搬进时间轴顶（OpenScreen）。优点一体；缺点移动播放键，老用户找一拍。**本夹不采用**（原则 7：不改金路径操作位置）。

## S3 · PR-03 侧栏通底（推荐唯一骨架）

把

```text
列[ 行[侧栏|预览] , 时间轴通栏 , 底栏通栏 ]
```

改成

```text
列[ Header, 行[ 左轨通高 | 抽屉通高 | 列[预览, 时间轴] ], 底栏 ]
```

| 选项 | 底栏 | 推荐 |
|------|------|------|
| **A** | 底栏全宽；左轨 `h` 拉到窗口底，底栏文字 `pl-12` 避开齿轮 | 改动中，齿轮真在左下 |
| B | 底栏只在内容列，左轨含底栏高度 | 最像 VS Code |
| C | 时间轴 `margin-left: 48px` 仍通栏 | 抽屉仍被切，不满足「侧栏内的面板也通底」 |

**推荐 A 或 B**，禁止 C。A/B 在 `14` 二选一，默认 **B**。

齿轮：继续左轨底、唯一设置入口；不把齿轮搬到时间轴工具条（截图 1 那种「齿轮贴轨」是现状假象，修完应消失）。

被控面板（场景/光标/…）继续只在抽屉，不在时间轴左侧再做第三列。
