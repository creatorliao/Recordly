# 03 · 方案：素材库与时间轴合并

## 目标结构

采用两层信息架构：侧栏「项目」继续表示工程草稿箱；当前工程内部新增「素材」视图，显示已关联的视频素材。点项目格子仍然打开另一工程，向时间轴拖放素材才表示加入当前工程。

## 第一期范围

- 一条主视频轨，多段 clip 首尾相接。
- 支持素材预览、加入末尾、按播放头加入、删除、移动和撤销。
- 源视频保持独立，导出阶段按时间轴顺序合成。
- 仅携带媒体、讲解声和光标遥测；不自动携带对方工程的缩放、字幕和标注编辑。
- 不同分辨率允许上轨，统一按当前工程画布渲染，必要时信箱。

## 不做

不做多视频轨、叠化、转场市场、云素材、源文件 concat，也不改变单段录制后的默认新工程路径。

## 推荐落地顺序

1. 设计持久化模型并补迁移/坏数据保护。
2. 在无 UI 依赖下实现素材引用与 clip 顺序的领域操作。
3. 接素材箱和明确的「加入当前时间轴」入口。
4. 接预览、撤销和导出，补同分辨率/异分辨率测试。
5. 最后更新使用指南与人工验收清单。

遵守 `14-待确认代决与待检验.md` 的 Q1-Q4；尤其是跨工程素材来源、拖放落点和素材点击语义。
