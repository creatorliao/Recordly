## 一、角色 / 金路径 / 为什么改 / G / 范围

| 项 | 钉死 |
|----|------|
| 角色 | 培训师，录 **Windows 软件操作** 给学员看 |
| 金路径（动词，不变） | **启动录制 → 停止 → 编辑 → 导出视频** |
| 为什么改 | 一节课常常要录好几段（开场、演示、答疑、补漏）。今天每段是一份独立工程，点侧栏格子会**整份换掉**当前课，没法在同一条时间轴上排好再导出。培训师要么重新录一条长片，要么导出去用剪映拼，G2 的「录完到导出 ≤15 分钟」被打断 |
| G1 | 编得动、导得出；单段课的旧路径不断 |
| G2 | 多段课不必离开 Recordly 去第三方拼接 |
| G3 | 本夹不改字幕引擎、不改配音；多段上轨后，**各段自己的讲解声仍跟自己的画面走** |
| G4 | 少而稳；对齐剪映「草稿箱 ≠ 素材箱」，**不把 Recordly 做成剪映** |
| 范围 | 仅 Windows；zh-CN + en；`dev-creator`；不代合/不代关上游 |

**后说覆盖（按时间，后者为准）：**

1. 要的是**剪映素材库那种能力**：多个录制在**同一个工程里关联**，再拖到时间轴上调整。
2. 「项目库拖到时间轴」和「合并视频」是同一件事的两端：库里能看见素材 → 上轨 → 导出成一条片。不是另做一个「压文件」按钮。
3. 不改变金路径动词顺序。老用户仍然可以：**录一段 → 停 → 编这一段 → 导出**。多段是可选增强。
4. 默认交互对齐剪映 / CapCut：点草稿 = 打开那一课；往时间轴拖 = **往当前课里加一段**，不是换课。
5. 已拍板、本夹必须遵守：`R20260906-14` §2.6 —— **不原样合上游 #689**（停录后把两段源文件拼成一个不可拆文件）。合并发生在**时间轴 / 导出**，源文件保持独立。

## 二、你点名的场景（培训师一天）

### 场景 A · 一节课录了三段，要合成一片

上午录「开场」、中午录「演示」、下午补「答疑」。晚上打开工程，三段都在**当前课的素材箱**里，拖到时间轴上排好顺序，切掉口误，导出一条 mp4。

失败样子：侧栏只有「昨天那节 / 今天开场 / 今天演示」三个**工程格子**；一点演示，开场的时间轴没了；只能另开剪映。

### 场景 B · 讲漏一步，补一段再接上

已经在剪「演示」。发现漏了注册按钮。再录 40 秒 → 新素材进**当前工程** → 接到时间轴末尾（或播放头）→ 可删、可挪、可撤销。

失败样子：再录变成一份新工程；或停录后两段被压成一个拆不开的文件。

### 场景 C · 素材箱里看看，先不上轨

工程里已经关联了四段。培训师只想预览缩略图、听哪段有声，**先不上时间轴**。时间轴仍是现在正在剪的那条。

失败样子：一点缩略图就整份换工程，未保存的剪切丢了（或被迫先存再换）。

### 场景 D · 老用户不理新能力

只录一段的人：侧栏格子仍然是「打开那一课」。导入视频仍然是「用这个文件当正片」。导出路径、切割、缩放、字幕都不因「将来能多段」而变难。

失败样子：点格子变成「加入时间轴」，找不到「打开另一课」；或空工程强制先建素材箱才能导出。

### 场景 E · 分辨率不一样的两段（边界）

开场是 1920×1080 全屏，演示是 1280×720 窗口。拖上同一条正片轨。

成功（本夹推荐）：允许上轨，画布跟**工程画布**走，较小的一段居中或按工程比例信箱；导出不断。  
失败：静默拉伸变形，或直接拒绝且不说原因。

## 三、成功 / 失败

| 成功 | 失败 |
|------|------|
| 同一工程能关联 ≥2 段本机录制，关掉再开还在 | 只能同时打开一段；关联只活在内存里 |
| 拖到时间轴 = 加一段 clip，可删可挪可撤销 | 拖上去等于打开另一个 `.recordly`，当前课被替换 |
| 点侧栏「项目/最近」格子 = 换课（今天的语义） | 点、拖做成同一件事，老用户找不到换课 |
| 导出按时间轴顺序出一条片；源 mp4 仍各自在磁盘上 | 「合并」把源文件拼死，撤销只能靠备份 |
| 单段课的切割 / 缩放 / 光标 / 导出与今天一致 | 为了多段，单段预览卡、导出挂、光标飞掉 |
| 新能力可选；不会用拖的人仍可用「加入当前时间轴」菜单 | 只会拖、或只藏在谁都找不到的高级菜单 |
| 操作若变了，使用手册有变更提示 | 手册仍写「点格子就是打开那一课」却已改成上轨 |

## 四、不做什么（本夹）

- 不做剪映级多视频轨叠化、画中画时间线、转场商店、特效市场
- 不做云素材、团队空间、从手机同步
- 不原样合 #689：不把两段源文件 `concat` 成一个不可拆的新源
- 不把现有「项目」格子改成唯一的素材箱（那是草稿箱，见 `02` / `04`）
- 不改金路径默认：空态「新录制」仍是**新工程、新文件**
- 不在本夹重做字幕引擎、Whisper、降噪、样式预设
- 不做 Linux / macOS-only；不为 zh-CN / en 以外补文案
