# 04 · 走查：用户体验

## 培训师金路径

录制一段、停止、编辑、导出仍保持原有路径。需要多段时，打开当前工程，在素材视图查看关联录制，预览后明确拖到主轨或选择「加入当前时间轴」，再调整顺序并导出。

## 关键检查

| 场景 | 期望 |
|---|---|
| 单段用户点击项目格子 | 打开工程，不进入素材加入模式 |
| 多段用户拖素材 | 增加新的 clip，不替换当前工程 |
| 只预览素材 | 不改变时间轴和当前播放头 |
| 未保存时打开其他项目 | 仍出现保存确认 |
| 加入后撤销 | clip 和素材关联同时恢复 |
| 异分辨率素材 | 不变形，有可理解的信箱表现 |
| 关闭后重开 | 素材关联与 clip 顺序保持 |

## 体验结论

「点」和「拖」必须是不同语义，并在素材层提供文字按钮兜底。任何失败都应说明是文件不可读、权限不足、格式不支持还是导出失败，不能静默丢素材。
