# 04 · 改善清单与实施路线图

闸门：落在 G2/G4、不过度、不换导出引擎、Windows only。  
分：`S = 0.40R + 0.35C + 0.25E`（各 1–5，R 高 = 更安全）。

## 二、工作包（提交点，可回退）

原则：一包一件可验收行为；合上可 `git revert` 单包。

### WP-A · Delete 对齐剪映（先做）

- L1 + L2 + L3。
- 入口：`EditorTimelinePanel` 补 `onClipDelete={clipCommands.handleClipDelete}`；`useTimelineKeyboardShortcuts` 改为「有选中且不在可编辑字段」即删；可选抄 `modalGuard`。
- 选中 clip 时 Delete **删除该段**（D-A 代决）；靠 `useEditorHistory` 撤销。
- 本包**不合缝**。删正片后轴上仍可能留洞，由 WP-D 收。
- 验证：单元测 `resolveDeleteSelectionTarget` + 键盘路径；lint / 现有 timeline 测试。

### WP-E · 边柄拉长（点名 4，与 A 同批）

- L8。对齐剪映 / Premiere：**中间搬家（时长不变），两端改出入点（时长变）**。
- 视觉帽与 `resizeHandleWidth` **同为 6**；块宽 < 约 18px 时柄翻到块外（抄 OS `pillAffordance`）；根节点 drag 不得吃掉端点 pointerdown。
- `resolveResizeEnd` 允许右缘超过当前 `totalMs`（叠层撑长轴）；正片右缘仍夹在源片长。
- **删掉或关掉** `getClipDragTotalMs`「整块拖出轴尾撑长轴」——那是反专业行为。
- 补测：左柄只改 start、右柄只改 end、中间拖 duration 不变（可对照 OS `V4Timeline.geometry.test.tsx`）。
- 不碰合缝映射。拉左缘留下的洞仍由 WP-D 收。

### WP-F · 轨道配色收束（点名 5，CSS 低垂）

- L9。色真源：`R20260907-02/03-规范` 洗色表。只改 `ItemGlass.module.css` + 时间轴底 `--editor-timeline`。
- 浅色禁止 500 满填糖果；深色降低饱和，正片与闲置 green 不得同色。
- 选中：2px 色相边，去掉 inset 光圈。不抄 OS `box-shadow` ring、不改 3px 半径。
- 可与 WP-E 同 PR 或紧随；不碰交互逻辑。

### WP-G · 默认讲解声波形（点名 6，低垂）

- L10。承接 `R20260907-03`「默认一条」：有声源就画 **1 条**轨，旧课 `showSourceAudio` 缺省 true。
- 先修本仓可见性 + 加载占位；peaks 不稳再移植 OS `useAudioPeaks` / `ClipWaveform`。
- 不默认三条波形。设置可关。
- 与 WP-D：合缝后波形跟 clip span。

### WP-B · 视窗与手感（可与 A 并行、不碰模型）

- L4 必做（文档已承诺）。L6 / L7 同包或紧随。
- 只改 `useTimelineRange` / dnd snap / 新建时长。不改 clip 坐标含义。
- 抄 OS wheel / snap，适配 `dnd-timeline` 的 `Range`。

### WP-C · 外在元素换轨（点名 2）

- 注释轨、外部音频轨各至少多渲染 **1 条空占位行**（或拖到行间隙时新建 `trackIndex`）。
- 保持 `resolveDropRowId` 跨类禁止（避免字掉进正片轨）。
- 不抄 OS「一种 kind 一条 lane」。
- 验证：`timelineModel.test` 补「落到 annotation-1 / 新轨」；真机上下拖。

### WP-D · 裁剪合缝 / 磁吸（点名 1，第一批里最重）

培训师场景（必须全覆盖，见 `01` R2/R3/R9–R11）：

- 裁片头、**裁/删中间一段**、删前一段：后面正片立刻靠上，轴变短。
- **全轨一起动**：正片、源音频、缩放、字幕、注释、外部音频。不要只推正片、字幕还留在旧时间。
- **画面和字幕一起裁**：删除区间内的字幕整句去掉；骑在边界上的字幕切掉重叠部分再跟画面靠拢。
- Delete **正片块** = 去掉这段成片时间 + 全轨左移。Delete **仅叠层** = 只删该块（R11）。
- 第一期仍不做「自由/磁吸」双开关（D-C）。

技术：

- 引入时间线位置与源入出点分离，或等价压缩映射；抄 OS `resequenceClips` 思想，不搬 `timelineMap`。
- 同步改 `getTimelineDurationMs`、双向时间映射、各轨 span、**caption 投影（现状删 clip 根本不碰字幕）**、导出分段。
- 拆：D1 纯函数+测试（含「删中间 + 字幕切开」）→ D2 接到 split/resize/delete → D3 投影与导出回归。
- 行数近 500 再拆刀；D2/D3 超限给人盯。

## 三、后置与暂缓

| ID | 为何后置 |
|----|----------|
| F1 多选 | 习惯上有用，但培训师高频是「删当前一块」；等 Delete 稳了再加 |
| F2 右键 | 与工具栏/快捷键重复；先保证键盘 |
| F3 复制粘贴 | OS 可抄，非点名 |
| F4 自由轨开关 | 过度设计；先一种合缝 |
| F5 光标轨等 | 落不进本轮 G2 痛点 |

写入确认后的 `15` 条件：仅当 WP-D 评估 >500 行且无法拆小，才整包暂缓，先交付 A+E+F+C。
