# 02 · 现状分析：已有功能与能力

> 事实来自本仓源码通读。视觉壳层（抓手、标尺密度、抽屉）见相邻夹，本文只记**剪辑能力**。

## 一、架构一句话

Recordly 时间线 = **`ClipRegion` 保留段**（`startMs/endMs` 同时是源时间与时间线位置）+ `dnd-timeline` 拖拽引擎 + 若干固定/动态轨。  
不是剪映那种「磁吸主轨永远无缝」，也不是 OpenScreen 那种「source 入出点 + timeline 坐标 + `resequenceClips`」。

主入口：`EditorTimelinePanel` → `TimelineEditor` → `TimelineCanvas` / `TimelineWrapper`。

## 三、轨道与对象（能实现哪一部分）

| 对象 | 时间线有没有 | 能做什么 | 不能做什么 |
|------|--------------|----------|------------|
| 正片 clip | 有，固定 `row-clip` | 分割（C）、拖块换序、拉左右缘改时长、变速（设置里） | 拉缘后**不合缝**；键盘删 clip **未接线** |
| 源音频波形 | **有，常看不见** | 新录 `showSourceAudio: true`；默认只留 mixed/mic **一条**（`selectDefaultSourceAudioTracks`）；`AudioWaveform` 画峰 | 旧课缺字段当 false → 整轨不画；peaks 空则 0 行；正片块自己不画波形 |
| 缩放 zoom | 有，固定一行 | 点击添加、拖、拉缘、删（键盘路径已接） | 无多选（仅 Ctrl+A 全选 zoom） |
| 字幕 caption | 有，单轨 | 点击添加、改 span、删 | 禁止重叠 |
| 注释 annotation（字/图/箭头/模糊） | 有，`row-annotation-{n}` | 水平拖、拉缘、`trackIndex` 字段已存在 | **只渲染已有素材的轨**；拖到异类轨被打回 |
| 外部音频 | 有，动态多轨 | 添加时自动找空档；水平拖 | 同样缺「空轨占位」 |
| 光标 cursor | 无独立轨 | 遥测只给自动缩放建议 | 不能当块剪 |
| 变速 speed | 无独立轨 | 写在 clip 上 | 不画 speed 块 |
| 贴纸 | 无独立名 | 走 annotation `image`/`figure` | — |

预览上的叠层位置（`AnnotationRegion.position`）和时间线 `trackIndex` **各管各的**：换轨只改时间线分层，不改画面坐标。这与剪映「时间线换轨 ≈ 图层上下」接近，但和「画布里拖位置」不是一回事。

## 四、操作能力矩阵

| 能力 | 状态 | 证据 |
|------|------|------|
| 播放头 / 点击 seek | 有 | `PlaybackCursor`、`TimelineCanvas` |
| 水平平移 | 有 | Shift+滚轮 / 触控板横向，`useTimelineRange` |
| 时间轴缩放（Ctrl+滚轮） | **文档有、实现无** | `shortcuts.ts` 写了；`handleTimelineWheel` 遇 Ctrl **直接 return** |
| 选中 | 有（各类型各一个 selectedId） | `useTimelineState` |
| 分割 | 有 | `handleClipSplit` |
| 拉缘裁剪（改时长） | **部分、易被整块拖顶替** | `onResizeEnd` → `resolveResizeEnd`；右缘被 `totalMs` 夹死，**不能**靠拉边把轴拉长。视觉端点 `.zoomEndCap` 宽 4px，且整块挂了 `useItem` 的 drag `listeners` |
| 整块平移 | 有，时长锁定 | `onDragEnd` → `resolveDragEnd` **强制保持原 duration**；最后一条 clip 整块拖过轴尾反而会 `getClipDragTotalMs` **撑长轴**（专业软件不会这样） |
| 磁吸 / 合缝 | **无** | 全库无 resequence / ripple |
| 拖到邻块之间换序 | 有（仅 clip） | `resolveClipDragInsertionSpan` |
| 块边缘吸附 | **无** | 邻块是硬夹紧，不是 8px snap |
| 播放头吸附关键帧 | 部分 | 播放头拖拽 150ms |
| 删除（设置面板按钮） | 有 | Settings 已接 `onClipDelete` 等 |
| 删除（Delete 键） | **部分且 clip 断线** | 见 `03` 痛点 c |
| 撤销 / 重做 | 有 | `useEditorHistory` |
| 多选 | 仅全选 zoom | 无 Shift / 框选 |
| 右键菜单 | 无 | — |
| 空白轨 | 无 | Row 随已有 `trackIndex` 出现 |
| 时长变化后视窗 | 部分 | `totalMs` 变则 `createInitialRange` 重置 |
| 轨道配色 | **有色但偏糖** | `ItemGlass.module.css` 硬编码；浅色满填 `#60a5fa` / `#c084fc` / `#f472b6`；深色高饱和底 + 选中 inset 光圈。`R20260907-02` 规定的是 `accent/18` 一类**洗色**，未落到这些 class |

## 五、快捷键（时间线聚焦时才生效）

| 键 | 动作 |
|----|------|
| C | 分割 clip |
| Z | 加缩放 |
| A | 加注释（默认轨 0） |
| F | 加关键帧 |
| Delete / Backspace / Ctrl+D | 删选中（clip 回调常为空） |
| Ctrl+A | 全选缩放块 |
| Tab | 同时间重叠注释轮询 |

聚焦门闩：`TimelineEditor` 的 `isTimelineFocusedRef`；点预览或设置抽屉后按 Delete，整段快捷键不跑。

## 六、数据模型（和「靠过来」直接相关）

```
ClipRegion { id, startMs, endMs, speed, muted?, showSourceAudio? }
```

- `startMs/endMs`：**源入出点 = 时间线左右缘**。拉左缘增大 `startMs`，块在轴上右移，左边空一截。
- `TrimRegion` 由 `clipsToTrims` **反推空隙**，不驱动布局。
- `getTimelineDurationMs` 取 **max(各 clip.endMs, 源片长)**，裁片头**不会缩短**时间线总长。
- 播放映射 `mapTimelineTimeToSourceTime`：落在空隙里就夹到最近 clip 边——播放跳过空档，**轴上仍画着空档**。

因此：现有能力已经能「剪掉一段源内容」，但**不能**在不拆开「源坐标 / 时间线坐标」的前提下，把轴上的洞补上。详见 `03`。

## 七、和培训师金路径的对应

| 培训师要做的事 | 现在能不能做 |
|----------------|--------------|
| 录完整段进来修 | 能：自动一条全长 clip |
| 切开哪讲错了 | 能：C 分割 |
| 去掉片头片尾 / 拉长某段字或缩放 | **半能**：设计上有拉缘；端点常被识别成整块搬家；正片拉缘还不合缝 |
| 中间删一段后全轨靠拢 | **无** | 删 clip 不左移后续；轴上留洞 |
| 裁/删时字幕跟画面走 | **无** | `handleClipSpanChange` 的 `removedSegments` 会滤 zoom/annotation/audio，**不碰** `autoCaptions`；跨段字幕不会被切开 |
| 拉长一段叠层的时间 | **半能**：应拉右缘；现在容易整块滑走，且 resize 不能越过当前轴长 |
| 叠字叠箭头并排开 | **半能**：可加多层，但难换行 |
| 删掉选中的字/缩放/废段 | **半能**：设置里能删；Delete 不可靠；废段 clip 键盘删不掉 |
| 导出 | 不在本夹；裁剪结果会进投影与导出 |
