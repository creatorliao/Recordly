# 05 · 低垂果实方案（未实施）

本文只写**确认后怎么改**。不改产品代码。WP-D 合缝放在最后一节，标清「不是接线级低垂」。

---

## WP-A · Delete（L1–L3）

### 要解决的体验

选中时间线上任何一块，按 Delete / Backspace，块消失；误删 Ctrl+Z。不要求先再点一下时间线空白获得焦点。输入框打字时 Delete 仍是删字。

### 改法

1. **L1 接线**  
   `EditorTimelinePanel.tsx` 给 `TimelineEditor` 增加  
   `onClipDelete={clipCommands.handleClipDelete}`  
   （`TimelineEditor` / `useTimelineSelection` 已声明该 prop，只是没传。）

2. **L2 焦点**  
   `useTimelineKeyboardShortcuts.ts`：去掉「必须 `isTimelineFocusedRef`」对**删除**的拦截。  
   保留：可编辑元素 return；建议抄 OS `isModalOpen()`（`openscreen/src/lib/ai-edition/modalGuard.ts`）——对话框开着不删时间线。  
   Split / Z / A 等是否一并放宽：代决 D-B（推荐**只放宽删除**，避免预览播放时误分割）。

3. **L3 互斥选中**  
   点选某一类块时，把其他 `selectedXxxId` 置空（OpenScreen `selectRegion` / `selectClip` 互斥）。避免「看起来选了字，实际还挂着 zoomId」。

### 抄代码

- 路由模式：`openscreen/.../NewEditorShell.tsx` 约 1236–1315 行 `deleteSelection`。
- 不要抄它的 `removeRegion` 存储层。

### 风险与回归

- 极低。注意：删 clip 会顺带去掉落在该源时间范围内的 overlay（现有 `handleClipDelete` 行为），要在验收里写明。
- 旧 L6「别误删整段」被本方案覆盖，见 `14` D-A。
- 单测：无 `onClipDelete` 时不抛；有则调用。键盘：input 内不 preventDefault。

## WP-E · 边柄拉长 vs 整块平移（L8）

### 要解决的体验

和剪映 / Premiere 一样：

- 拖**两端的点** = 只动这一头，把这段时间**拉长或缩短**。
- 拖**块中间** = 整块搬家，时长不变。
- 叠层右缘拉过片子末尾 → **时间轴变长**。正片右缘不能超过源文件。
- 不再出现「抓端点却整块跑、或整块拖出轴尾当拉长」这种反专业行为。

### 改法

1. **命中分离**（抄 OS `pillAffordance`）  
   - 视觉帽与 `resizeHandleWidth` 都是 **6px**。  
   - 块宽 < `6+6+6` 时柄翻到块外，中间仍能 grab（`R20260907-02` 已定、未落地）。  
   - 根节点 `listeners` 不得盖住端点：端点 `pointerdown` 走 resize，或端点 `stopPropagation` 后交给 `dnd-timeline` 的 resize 热区。  
   - 去掉块上 `overflow: hidden` 对柄的裁切（柄可溢出）。

2. **引擎语义**  
   - `resolveResizeEnd`：允许 `end > totalMs`（至少对 annotation / zoom / caption / audio）；正片 `end` 夹在源时长。  
   - `resolveDragEnd`：**永远保持 duration**，并且**不要**再靠 `getClipDragTotalMs` 用整块位移撑轴。  
   - 现有测试 `allows the final clip drag to extend the timeline` 应改成：**失败或不再撑轴**；改由右缘 resize 测试覆盖「拉长轴」。

3. **单测**（对照 `openscreen/.../V4Timeline.geometry.test.tsx`）  
   - 左柄：start 变、end 不变。  
   - 右柄：end 变、start 不变。  
   - 中间：start/end 同 delta。

### 抄代码

- `openscreen/src/components/ai-edition/v4/V4Timeline.tsx`：`PILL_HANDLE_PX`、`pillAffordance`、`startPillDrag` 的 `"l"|"r"|"move"`。  
- 几何测试文件同目录。不必抄 ventilate / 音频 slip（后置）。

### 风险

- 低～中。只动命中与 clamp，不改编排映射。  
- 与 WP-D：先让「拉的是时长」；左裁后的靠拢仍是下一包。  
- 与 WP-C：换轨仍是垂直拖**中间**，不要让端点垂直拖误建轨。

## WP-F · 轨道配色收束（L9）

### 要解决的体验

时间轴看起来像专业剪辑台：炭灰/浅灰底，块是**低饱和洗色**，靠色相认「这是正片 / 缩放 / 字 / 声」，不要糖果满填、不要选中发光。

### 色真源（不另起盘）

抄 `R20260907-02` `03-规范` 已拍板的表，落到 CSS：

| 种类 | 填充 | 选中 |
|------|------|------|
| 正片 / 源音频 | `accent / 18` | 2px accent 边 |
| 缩放 | 紫 500 / 16 | 紫边 |
| 音频（外部） | 绿 600 / 16 | 绿边 |
| 字幕 | 玫 500 / 16 | 玫边 |
| 注释 / 变速 | 琥珀 600 / 16 | 琥珀边 |

浅、深都用同一套透明度，禁止浅色分支改成 `#60a5fa` / `#f472b6` 满填。

### 改法

1. `ItemGlass.module.css`：各 `glass*` 改为 `color-mix` / token，去掉 inset `box-shadow` 光圈。
2. 正片不要再用与闲置 `glassGreen` 相同的 `#183065`。
3. 时间轴画布背景用已有 `--editor-timeline`（浅色分割才看得见）。
4. 不改半径 3、不改行高、不抄 OS 11px 与 `accent-ring`。

### 风险

- 极低，纯皮。浅/深都要人眼扫一眼（`14` T12）。

## WP-G · 默认讲解声波形轨（L10）

### 要解决的体验

停录进编就能看见 **1 条**音频轨波形：哪段在讲、哪段静音，点波形对上画面。设置可关。不要默认三条把轴撑满。

### OpenScreen 对照（先查再抄）

- **有**：正片块内 `ClipWaveform` + `useAudioPeaks`（及大文件 `streamingAudioPeaks`），测试在 `V4Timeline.waveform.test.tsx`。
- **没有**：单独的「默认讲解声行」。导入 BGM 才另有音频 pill。
- **本仓已有**独立源音频行 + `AudioWaveform` + `selectDefaultSourceAudioTracks`（只留 1 条）。缺的是**默认看得见**。

因此：**先修本仓可见性，不要一上来整包替换引擎。** 解码失败或峰太糊，再移植 OS `useAudioPeaks` / 把 `ClipWaveform` 叠进正片（轨仍保留，因用户要的是轨道）。

### 改法

1. `showSourceAudio` 缺省 = `true`（读盘、新录、分割后的 clip 都带上）。
2. `showSourceAudioTrack`：有声源或正在出峰就显示 1 行，不要 `some(showSourceAudio)` 把旧课整轨掐掉。
3. 加载中骨架；无音轨再提示，禁止静默 0 行。
4. 继续 `selectDefaultSourceAudioTracks`（mixed 否则 mic）。
5. 点波形走现有 seek。合缝后 span 跟正片。

抄 OS 条件：本仓 `WaveformGenerator` / `useTimelineAudioPeaks` 确认出不来峰或条不可读时，再搬 `openscreen/src/hooks/useAudioPeaks.ts` 与 `ClipWaveform`。

### 风险

低。和 `R20260907-03` 同题，本夹收口，那边只留指针。不改编排模型。

## WP-B · 滚轮缩放与吸附（L4、L6、L7）

### L4 Ctrl+滚轮缩放

现状：`useTimelineRange.handleTimelineWheel` 在 `ctrlKey/metaKey` 时 return；`shortcuts.ts` 却宣传 Ctrl+Scroll。

改法：Ctrl/Meta+滚轮 → 以指针 x 对应的时间为锚，缩小/放大 `range.end - range.start`，锚点尽量留在指针下。Shift+滚轮继续平移。普通滚轮：有纵向溢出则滚轨道，否则平移（现有逻辑可留）。

抄：`openscreen/.../v4/V4Timeline.tsx` wheel effect（`passive: false`）。接到现有 `Range` 即可，不必引入 OS 的 `nav` store。

### L6 8px 吸附

在 `dnd/engine.ts` 的 resize/drag 落点上，对「0、总长、邻块边、播放头」做像素半径吸附（OS：`PILL_SNAP_PX = 8`）。现有邻块硬夹紧保留为**不得重叠**的上限。

### L7 新建块时长

抄 `openscreen/.../newRegionDuration.ts`：按当前 px/秒算一段固定屏幕宽度，Z/A/点击添加共用，避免放大轴时新块只有几像素、缩小轴时新块铺满。

风险：不碰 clip 模型。注意 125%/150% 系统缩放下仍好拖（与 `R20260907-02` T8 同类）。

## WP-C · 换轨（L5）

### 要解决的体验

注释（及外部音频）可以拖到上一行 / 下一行；没有下一行时，拖过当前行上沿或下沿就**长出一条空轨**。不能拖进正片 / 缩放 / 字幕行。

### 改法（OS 无此功能，按剪映）

1. `TimelineCanvas` 渲染 annotation / audio 时：`trackIndex` 从 `0..max(已有)+1` 都画 Row（最后一条为空占位）。空行显示淡提示即可，不做花活。
2. `onDragEnd` 已有 `resolveDropRowId`：落在 `row-annotation-n` 则 `handleAnnotationSpanChange(..., n)`。补测试：从 0 拖到占位 1。
3. 若 `dnd-timeline` 在行外 `over` 为空：用指针 y 相对行矩形判断「上一轨 / 下一轨」，写入 `trackIndex±1`（可复用 OS `pointer-drag.ts` 的 capture，非必须）。
4. 预览层 `position` 不动。换轨 ≠ 画布挪位置。

### 风险

- 空轨使时间线变高：与 `R20260908-02` 面板拖高相容；默认只多 1 行，避免一次铺 8 条空轨。
- 不改 `resolveDropRowId` 的跨类禁止。

## WP-D · 合缝（M1，点名但非接线级）

### 目标行为（剪映磁吸，用户点名补全）

培训师最常见：中间讲错 / 卡顿，**C 切两刀 → 选中中间正片 → Delete**。后面画面和字幕必须自己贴上来，不能再一段段拖。

| 动作 | 成片时间 | 各轨 |
|------|----------|------|
| 裁片头 / 裁片尾 | 区间从轴上消失，总长变短 | 后面（或仅轴缩短）**全轨**跟上 |
| 删**中间一段正片** | 前后正片首尾相接，中间无洞 | 缩放、字幕、注释、音频与正片**同一套左移** |
| 删除区间内整段字幕/缩放 | — | **一起删掉**，不留对着空白的字 |
| 字幕骑在删除区间上 | — | 重叠那截裁掉；两侧剩余跟画面靠拢 |
| 只删一条注释/缩放 | 正片时长不变 | 只去掉该块，**不** ripple 正片（R11） |

播放 / 导出仍对准**源时间**（删掉的源区间不再出现）。

### 为什么不能只改 `handleClipSpanChange` 三行

见 `03`：`startMs` 一身二职。把块画到左边会改源入点。

### 推荐设计（抄 OS 思想，不抄全文）

为 clip 增加时间线坐标，或在渲染/映射层用「压缩轴」：

```
源：   [====clip0====][gap][====clip1====]     （入出点不变）
显示： [====clip0====][====clip1====]         （resequence）
时长： sum(各 clip 显示时长)
```

纯函数（建议新文件，例如 `timeline/model/resequenceClips.ts`）：

- 输入：clip 列表（源起止 + speed）。
- 输出：每条的 `timelineStartMs/timelineEndMs`，从 0 首尾相接。
- 对照：`openscreen/src/lib/ai-edition/document/timeline.ts` 的 `resequenceClips`、`setClipSourceRange`、`removeClip`。

然后：

- `buildTimelineItems` 用时间线坐标画块。
- `getTimelineDurationMs` 改为压缩总长。
- 重写 `mapTimelineTimeToSourceTime` / `mapSourceTimeToTimelineTime`：按压缩轴走动，而不是「轴时间落在 startMs–endMs」。
- zoom / annotation / audio：落在被删成片区间内的去掉或切开；区间之后的随压缩轴左移。
- **字幕必须进同一套函数**（现状 `removedSegments` 不碰 `autoCaptions`）。caption 存源时间：先按被删**源区间**切/删 cue，再走投影。禁止只改正片、字幕仍挂旧源时间对着空洞。
- resize 左缘 = 改源入点并 resequence，不是只改同一个 `startMs`。
- Delete 正片走 `removeClip` + 全轨通风 + resequence；Delete 叠层走现有 `handleXxxDelete`，不调用全轨左移。

### 明确不抄

- OS 的 trim pill 在 RAW 标尺占位、播放跳过——用户不要这种「洞还在」。
- 整份 `timelineMap.ts`、ventilate 跨 clip 碎片。

### 拆提交

| 子包 | 内容 | 谁做 |
|------|------|------|
| D1 | 纯函数 + 契约测：压缩时长、映射往返、**删中间一段后字幕切开/删除** | AI |
| D2 | split / resize / Delete 正片走 resequence + 全轨通风 | 盯行数 |
| D3 | 投影、导出分段、跨段字幕回归 | 盯行数 |

### 风险

- 动金路径「编」。必须单测映射往返 + 一条导出分段用例。
- 旧项目文件只有 `startMs/endMs`：读取时视为源坐标，时间线坐标派生，不必立刻升 schema；若要持久化双坐标再单开。
