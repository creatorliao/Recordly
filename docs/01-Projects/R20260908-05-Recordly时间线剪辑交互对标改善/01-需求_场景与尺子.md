# 01 · 需求：场景与尺子

## 一、角色与目标锚点

| 项 | 内容 |
|----|------|
| 角色 | 培训师，录软件操作过程，停录后进编辑器修成片 |
| 金路径 | 启动录制 → 停止 → **编辑（时间线裁剪 / 叠字叠图 / 删废段）** → 导出 |
| 为什么改 | 时间线不像剪映：裁完不靠拢、中间删一段还要手推后面、字幕不跟画面一起裁、叠层换不了轨、Delete 不删选中 |
| 服务目标 | **G2** 录完到导出 ≤15 分钟；**G4** 体验对齐常见剪辑软件、不过度设计。不阻断 **G1** |
| 范围 | 仅 Windows；简体中文 + 英文；工作分支 `dev-creator`；不代合上游 PR |
| 对照 | 剪映 / CapCut 默认习惯；专业工具（Premiere / 剪映专业版）只取「删选中、磁吸合缝、换轨」三件套；OpenScreen 作**可抄代码**真源 |

## 二、用户点名（必须进清单前列）

1. **裁完不靠拢（含中间裁）**：裁片头、或**裁掉/删掉中间一段**后，后面所有轨道应自动靠过来，不必一段段手推。剪映磁吸：画面和字幕一起裁；删的那段里有字幕，字幕一并去掉；Delete 删正片区间后**全轨左移靠齐**。
2. **外在元素不能换轨**：文字 / 图 / 箭头等只能在自己那一行水平滑，上下拖到另一轨无效。
3. **Delete 不删选中**：选中时间线上的一块，按 Delete，剪映会删，Recordly 常常没反应。
4. **边上的点一拖变成整块搬家**：用户拖的是块左右两端可抓的点，预期是**只动这一头、把这段时间拉长或缩短**（正片改出入点，叠层改时长）。现在经常整块平移、时长不变，和剪映 / Premiere 完全相反。
5. **时间轴配色怪**：块色偏糖、浅色更像玩具；要和剪映 / Premiere 一类专业工具一样——炭灰底、低饱和实色、靠色相认轨而不是靠霓虹。
6. **默认要有一条音频轨画波形**：一眼看出哪段有声、哪段静音，顺着波形点到对应画面。不必默认铺系统声+麦克风两条。

## 三、产品方向（不过度）

做一个**够用、好用**的时间线控制模块，而不是第二套 Premiere。

- 默认行为对齐剪映：选中即删、**删/裁正片区间后全轨磁吸合缝**、叠层能换行；块中间拖是搬家，两端拖是改时长。画面与字幕按**同一成片时间**裁，不要各管各的。
- 新能力默认不改「录 → 停 → 编 → 导」顺序；老用户仍从时间线改片段。
- 能从 OpenScreen **直接抄或小改抄**的，排在前面；要换数据模型的，写清楚后置。
- 单工作包尽量 ≤500 行；磁吸合缝因模型债单独成包，禁止和视觉重做捆在一起。

## 四、验收尺子（确认后实施才用）

| # | 场景 | 通过 |
|---|------|------|
| R1 | 时间线或预览里已选中一块（clip / 缩放 / 字幕 / 注释 / 外部音频），焦点不在输入框 | Delete / Backspace 删掉**当前选中那一块**；有撤销 |
| R2 | 只有一条正片时，拖左缘裁掉片头 | 剩余正片靠到 0；**缩放/字幕/注释/音频全部左移**；轴变短；预览从新片头播 |
| R3 | 分割成三段，Delete **中间那段正片**（或裁掉中间一段） | 后一段正片**立刻靠上**前一段，中间无洞；后面所有轨道一起左移 |
| R9 | 中间被删的区间里有完整一句字幕、一段缩放 | 这些字幕/缩放**一起消失**，不要留在轴上对着空白 |
| R10 | 一句字幕横跨「保留 \| 删除 \| 保留」 | 落在删除区间的那截去掉；两侧剩下的字幕跟画面一起靠拢（可拆成两条或修出入点） |
| R11 | 只 Delete 一条注释/缩放，正片没删 | **只删该块**，正片和其他轨**不**被挤过来（剪映：磁吸跟的是成片时间，不是删一个箭头整段视频跳走） |
| R4 | 至少两条注释轨（或拖到轨上方空白） | 选中注释块**上下拖**能换到另一条注释轨；不能掉进正片 / 缩放 / 音频轨 |
| R5 | 设置里写着 Ctrl+滚轮缩放时间轴 | 按住 Ctrl 滚轮，以指针为中心放大缩小可见范围（现在文档有、实现缺） |
| R6 | 抓块**左/右端点**左右拖 | 一端固定、另一端走，**时长变**；光标 `col-resize`。正片右缘最多拉到源片长；叠层右缘拉过当前成片末尾时，轴变长。短块两端仍能单独抓住 |
| R7 | 抓块**中间**左右拖 | 整块平移，**时长不变**；光标 `grab`。禁止再用「整块拖出轴尾」当拉长时长的手段 |
| R8 | 浅色 / 深色各看一眼时间轴 | 正片蓝灰洗、缩放紫洗、音频绿洗、字幕玫洗、注释琥珀洗；**无渐变、无选中光晕、无浅色满填糖果块**；底用 `--editor-timeline`，和抽屉同一调 |
| R12 | 停录进编 / 打开旧课（片里有讲解声） | **默认正好 1 条**音频轨画出波形；静音处矮、有声处高；点波形能 seek 到该时刻画面。设置里可关。不要默认 3 条波形把时间轴撑满 |

非本夹尺子：面板能不能拖高、标尺字重不重、抽屉圆角——认 `02`/`03`/`04` 夹。

## 五、非目标（本轮不做）

- 多机位、嵌套序列、关键帧曲线、转场库、磁力时间线的「自由/磁吸」双模式开关（先一种默认合缝）。
- 时间线右键菜单、框选多选、复制粘贴块（写入后续，不挡前三包）。
- 把 OpenScreen 整份 `timelineMap` / RAW·COMPRESSED 双标尺原样搬进来。
- 改导出编码器、改录制管线。
- 为 Linux / macOS / 其他语种做专门修复。
