## 一、一句话

把「导出旁边的神秘预设」收成左边画面里的 **样式预设**：应用、取消应用、删除三件事分开；可以从来不选；套用只动课件脸，不动导出和本机路径。

## 二、心智模型（先统一，再画界面）

| 概念 | 含义 |
|------|------|
| 当前外观 | 这一课现在的壁纸/光标/缩放等，永远存在 |
| 样式预设 | 给这套外观起的名字，存在本机，多课可复用 |
| 已应用 | 用户**明确点过**某条名字，且还没取消 |
| 已修改 | 已应用之后，用户又改了被记住的项 |
| 未使用预设 | 没有已应用的名字。画面可以仍是刚才那套，只是不再挂名 |
| 删除 | 从本机列表拿掉这条名字。画面不动 |

**选中不再等于「指纹碰巧一样」。**  
指纹最多做一行弱提示：「当前外观与「冲冲冲」相同」，不自动打勾、不自动改顶栏标题。

这是对 Word「样式」+ 剪映「收藏」的对齐，不是对 OBS「必须有一个 Profile」的对齐。

## 三、入口放哪（拍板建议）

### 采用：左轨「画面」面板顶部

- 左轨本来就停在画面；壁纸、边框、缩放都在这页往下滚。
- **同一张卡**挂在「画面」（含 frame/crop 同页）和「光标」两页**顶部**（走查 D8：调完光标也要找得到保存）。
- 卡片标题：**样式预设**。副文案一行：「保存并套用画面、光标、缩放。不含导出、裁切、摄像头位置。」
- **不新增左轨图标**（G4，不过度设计）。
- **顶栏导出左边的预设触发器拿掉。** 顶栏右侧只留导出 + 侧栏开关。覆盖 `R20260906-14` D17 的「文字预设」。
- 项目 / 字幕 / 设置 / 摄像头 / 时间轴选中缩放项：不挂这张卡。

### 不采用

| 方案 | 为什么不 |
|------|----------|
| 继续挂在导出旁 | 你已否定；和导出档抢位置 |
| 只放进底部齿轮「设置」 | 剪课时少点齿轮；样式会变成「去设置里找收藏」 |
| 左轨再加一颗书签图标 | 轨上已有项目/画面/光标/摄像头/字幕/扩展/设置，再加一项是迷宫 |
| 画面 + 光标 + 设置三处各放一份 | 两处已经容易找不到，三处更差 |
| 文件菜单再挂「样式预设」当主入口 | 可作二期，本期不做，避免双入口 |

若确认时你更想「只放设置齿轮页」：也可以，规则相同，只换挂载页。**默认仍建议画面顶。**

## 四、界面与操作（完整但不膨胀）

画面顶部一张卡片，结构固定：

```text
样式预设
保存并套用画面、光标、缩放。不含导出。

[ 输入框：预设名称 ] [ 保存 ]

未使用预设          ●          ← 永远第一行；当前未应用时选中
冲冲冲              ✓  ⋯
冲冲冲（已修改）    ✓  ⋯       ← 脏了改这行文案
测试                   ⋯
```

### 4.1 未使用预设（取消应用）

- 列表**第一行**，名字就叫「未使用预设」。
- 点它 = **取消应用**：`activeId = null`，**画面保持不动**。
- 已应用且未脏：点它即可。
- 已应用且已脏：同样只摘名、保留改动（不要弹「放弃修改吗」——摘名本来就不是还原）。
- 顶栏不再显示预设名。侧栏这行打点/打勾即可。

这就是通用用户要的「回到没有任何预设的状态」，不用去改阴影、也不用删条目。

### 4.2 点一条具名预设 = 应用

- 套用该条快照（只含 §五 的字段）。
- toast：「已应用样式「冲冲冲」」，并带操作「撤销」（走查 D9）。
- 卡片在仍有「套用前一格」时显示「撤销刚才的套用」。
- 若当前已脏、再点**另一条**：直接套那一条（和剪映点另一个样式一样）；套用前一格改为刚离开的那张脸。
- 再点**当前已应用且未脏**的那一条：什么都不做（不要再 toast 一遍）。
- **Ctrl+Z 不会还原外观**（撤销栈只管时间轴）。误套的补救只有「撤销刚才的套用」，不是取消应用。

### 4.2.1 撤销刚才的套用（内存一格）

套用前记下 `{ look, previousActiveId }`。点撤销：把脸和已应用 id 设回这一格，然后清空这一格。  
取消应用、更新、另存、删除**不**自动清空这一格（取消只摘名，仍允许撤销回到套用前）。  
下一次套用会覆盖这一格。不写入工程、不进 localStorage。

### 4.3 保存 / 更新 / 另存

| 情境 | 按钮 |
|------|------|
| 未使用预设，输入新名字 | **保存** → 新建，并标为已应用 |
| 已应用且未修改 | 输入框 + **另存为**（可选再存一份）；不显示更新 |
| 已应用且已修改 | 第一行仍是输入框 + **另存为**；其下全宽 **更新「冲冲冲」**（D11 不确认） |
| 重名 | 禁止静默覆盖；提示已有同名 |
| 名称长度 | 最多 40 个字符（输入框 `maxLength={40}`） |

不做文件夹、不做拖拽排序（有余力再按创建时间，新的在上，保持现状即可）。

### 4.4 一行右侧是 ⋯，不是 X

⋯ 打开小菜单：

- **重命名**
- **删除** → 确认框：「删除样式「冲冲冲」？课里的画面不会变。」确认后才删。
- 已应用时再给一项 **取消应用**（与第一行同义，防止只看见 ⋯ 的人找不到）

删除当前已应用的那条：列表回到「未使用预设」，画面不动。

### 4.5 各区块「重置」保持原样

画面/光标里已有 Reset。那是「这一块恢复默认」，**不是**取消样式预设。  
本期**不**再做全局「恢复全部出厂外观」大按钮，避免和取消应用、和分块重置叠床架屋。

## 五、快照里装什么

**要（课件脸）：** 壁纸、阴影、背景模糊、缩放运动与缓动、光标全套、圆角、留白、画幅。

**不要（走查后收紧）：**

- 导出编码 / 后端 / 质量 / 帧率 / 格式 / GIF  
- 裁切区域  
- **摄像头框**（位置/大小/圆角——这是这一课构图，和裁切同类）  
- 自动字幕设置  
- Whisper 可执行文件路径、模型路径  

已存的旧预设：应用时**只读「要」的字段**，多出来的导出/路径/裁切/摄像头忽略。这样旧数据不会把导出、本机路径或摄像头气泡改掉。列表名字保留，不用逼人重建。  
新保存 / 更新：磁盘上也只写「要」的字段。

## 六、状态记在哪

| 数据 | 记哪 | 原因 |
|------|------|------|
| 预设列表 | 仍用本机 `recordly.editor.presets` | 多课复用，像 OBS 配置、不像某一课的字幕 |
| 这一课「已应用哪一条」 | **写入当前工程**（没有则视为未使用） | 明天打开同一课还认得名字；换另一课不会错挂 |
| 脏 | 运行时算：当前课件脸 ≠ 该条快照 | 不另存一份脏标记 |

不做跨课自动套用「上次用的样式」。打开新课默认 **未使用预设**，要套再点。符合「可选、不改老路径」。

## 九、综合决策（闸门 + 记分）

### 七问

1. **G？** G2（少重调外观）+ G4（少误删、少惊吓）+ 不挡 G1。  
2. **不过度设计？** 不新图标、不云同步、不导出预设产品。  
3. **回归？** 导出菜单原样；旧预设应用时忽略多余字段，导出不会被旧快照改掉。  
4. **用户真需要？** 是：复用课件脸，以及正当的取消。  
5. **会困惑吗？** 顶栏少一个字，需改手册一句；比「预设贴导出」更少困惑。  
6. **奇怪影响？** 取消不还原画面——必须在确认框和副文案里写清。  
7. **习惯对齐？** 对齐剪映收藏 / Word 样式 / 「无」；不对齐 OBS 强制当前档。

### 记分（过闸后）

| 维度 | 分 | 说明 |
|------|----|------|
| R 风险 | 4 | 不换引擎；M1 只动预设 hook/菜单；M3 动工程字段需小心读写兼容 |
| C 贡献 | 4 | 直接打在「编得省事、少误操作」 |
| E 效能 | 5 | 培训师每周复用同一张课件脸；取消是高频 |

S ≈ 0.40×4 + 0.35×4 + 0.25×5 = **4.25** → 优先。属体验修复，不是高价值高风险换引擎。
