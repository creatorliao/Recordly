## 三、状态机（实现必须对上）

```
activeId: string | null          // 用户明确应用；工程字段 appliedStylePresetId
dirty: boolean                   // active 存在且 serializeStyleLook(当前) !== 该条
revertSlot: { look, previousActiveId } | null   // 仅内存
hintMatchName: string | null     // 仅当 activeId===null 且恰好一条 look 相同
```

| 动作 | activeId | 画面 | revertSlot | 列表 |
|------|----------|------|------------|------|
| 点「未使用预设」 | `null` | 不动 | 不动 | 条目都在 |
| 点具名（非当前或当前已脏） | 该 id | 套 look | **写入套用前** | 不动 |
| 点当前且未脏 | 不变 | 不动 | 不动 | 不动 |
| 撤销刚才的套用 | `previousActiveId` | 恢复 look | 清空 | 不动 |
| 保存新名字 | 新 id | 不动 | 建议清空 | 头部插入 |
| 更新当前 | 不变 | 不动 | 建议清空 | 该条 snapshot/updatedAt 变 |
| 另存为 | 新 id | 不动 | 建议清空 | 头部插入 |
| 删除（确认后）当前条 | `null` | 不动 | 不动 | 去掉该条 |
| 删除非当前 | 不变 | 不动 | 不动 | 去掉该条 |
| 重命名 | 不变 | 不动 | 不动 | 只改 name/updatedAt |
| 打开课，工程 id 在列表里 | 该 id | 课里已有的脸，**不要再套一遍** | 空 | — |
| 打开课，工程 id 失效或无字段 | `null` | 不动 | 空 | — |

打开课时**禁止**为了对齐名字再 `applySnapshot`。名字只是标签。
