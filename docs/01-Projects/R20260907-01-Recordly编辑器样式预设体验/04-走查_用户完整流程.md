## 一、今天软件里实际能走的（对照现状）

我打开编辑器 → 顶栏导出左边看到书签「冲冲冲」→ 点开：

1. 想取消选中 → 只有 X → 我当取消点了 → 条目没了。  
2. 想回到「没选任何预设」→ 界面没这个动作。  
3. 我去改阴影，名字自己没了 → 我以为是 bug。  
4. 我以为这是导出预设，点完导出质量也可能变。

这些已在 [`02`](02-分析报告_现状与体验问题.md)。下面按**方案落地后**再走一遍，找方案自己的洞。

## 二、落地后：我怎么找到它

### 2.1 录完进编辑器（主路径）

停录 → 编辑器。左轨默认在「画面」，侧栏开着。  
**期望：** 画面面板最上面就是「样式预设」卡片，不用去导出旁边找。  
**顶栏：** 只有导出和侧栏开关，没有书签。我不会再把样式和导出当成一套。

### 2.2 侧栏被我关掉了

我点了顶栏侧栏开关，壁纸也一起没了。  
**期望：** 再点同一颗开关，左轨选「画面」，卡片还在。  
**不期望：** 为了找预设再把书签钉回导出旁边。  
（和调壁纸同一习惯，过得去。）

### 2.3 我正在调光标

左轨切到「光标」，改了大小。想把现在这张脸存下来。  
**原方案漏洞：** 卡片只在「画面」顶，光标页没有。我会去齿轮设置里翻，或以为功能没了。  
**回写 D8：** 「画面」和「光标」两页顶部放**同一张卡**（同一状态，不是两套）。摄像头 / 字幕 / 设置 / 时间轴选中缩放项的页不放。

### 2.4 我在「项目」格子、还没打开课

没有当前课时。  
**期望：** 项目页不出现样式卡（这里在选课，不是调脸）。  
打开一节课后，再进画面就能存、能套。

## 三、落地后：从零到复用

### 3.1 从来没存过

卡片在，第一行「未使用预设」是选中的。下面一句：「调好画面后起个名字保存，下一节课就能套用。」  
没有虚线「还没有预设」独占整块（那会让人以为功能坏了）。  
导出照常。金路径不断。

### 3.2 我存第一条「冲冲冲」

输入名称 → 保存。  
**期望：** 「冲冲冲」出现并打勾；「未使用预设」不再是选中。toast「已保存样式「冲冲冲」」。  
空名字：提示请输入，不存。  
前后空格： trim。超过 40 字：截或不让输入（工单写死 40）。  
与已有名只差大小写：仍算重名，不覆盖。

### 3.3 下一节课套用

打开新课（默认未使用预设）→ 画面或光标顶 → 点「冲冲冲」→ 壁纸/光标/缩放/画幅变了。  
**期望：** 裁切框还是这节课的；摄像头气泡还在我放的位置；导出质量、GIF、字幕、Whisper 路径都不变。  
**原方案漏洞：** 快照含摄像头框，套用会挪我的摄像头。裁切已排除，摄像头应同样排除。  
**回写 D12：** 快照不含摄像头。

### 3.4 这节课不用具名样式了

点第一行「未使用预设」。  
**期望：** 勾回到这一行；「冲冲冲」还在列表里；**画面完全不变**。  
⋯ 里也有「取消应用」，效果一样。

### 3.5 我点错了，套成了「测试」

Ctrl+Z：现在撤销栈只管时间轴，外观回不去。  
取消应用：只摘名，脸还是「测试」那张。  
各区块 Reset：回到出厂，不是套用前。  

**原方案漏洞：** 没有正当的「我点错了」。  
**回写 D9：** 每次套用前在内存记一格「套用前的脸 + 当时的已应用 id」。toast 带「撤销」；卡片上在还有这一格时显示「撤销刚才的套用」。点了就恢复那一格。取消应用不消耗这一格。再套一条则覆盖这一格。

## 四、落地后：改、更新、另存、删

### 4.1 套了之后改阴影

名称变成「冲冲冲（已修改）」。  
主操作变成「更新「冲冲冲」」；仍可另存为新名字。  
**更新不弹确认**（对齐 Word 更新样式），toast「已更新」。  
**回写 D11。**

### 4.2 脏了再点另一条

直接套过去，不弹「放弃修改吗」（D6）。套用前的一格变成「刚离开的那张脏脸」，所以还能「撤销刚才的套用」回到脏脸。

### 4.3 重命名

⋯ → 重命名 → 该行变输入框。回车确认，Esc 取消。重名则 toast，不改。

### 4.4 删除

⋯ → 删除 → **对话框**（不要 `window.confirm`，用已有 `Dialog`）：  
「删除样式「冲冲冲」？课里的画面不会变。」  
取消：还在。确定：列表少一条；若删的是当前已应用，回到未使用预设；画面不动。  
**没有 X。**

### 4.5 工程里记着一个已被我删掉的 id

隔天打开这节课。  
**期望：** 当未使用预设，不报错、不按指纹自动挂回另一条。  
**回写 D10。**

## 五、落地后：和别的功能会不会打架

| 我同时在做 | 期望 |
|------------|------|
| 导出进行中再套样式 | 不挡导出；套用只改预览脸。不为此做特殊锁（不过度） |
| 只改「已应用哪一条」、脸没变 | 课名旁未保存蓝点要亮；保存后写入工程 |
| 打开旧 `.recordly`（没有该字段） | 未使用预设；不因此标脏 |
| 新课 / 新录 | 未使用预设，不自动套「上次用的冲冲冲」 |
| 画面里点某区块 Reset | 只重置那一块；若已应用则会变「已修改」；不是取消应用 |
| 设置里的「专注 / 演示」运动配方 | 还在，不叫光秃秃「预设」抢义；本题不重做 |
| 顶栏导出 | 位置、流程不变（先选路再编码，跟 14 走） |

指纹弱提示（未使用，但脸碰巧和「冲冲冲」一样）：  
文案必须是「未使用预设。当前画面碰巧与「冲冲冲」一样。」  
**不要**因此打勾或改成已应用。

## 六、我还可能问的（方案必须先答死，执行中不要再问人）

| 问 | 答（已代决） |
|----|----------------|
| 为什么光标页也有一张卡？ | 脸含光标；只放画面会找不到保存（D8） |

| 摄像头为什么不跟着样式走？ | 那是这一课构图，和裁切同类（D12） |

## 七、走查结论

原方案方向对（取消≠删除、离开导出、未使用预设一等）。  
不补下面几条，培训师仍会卡住或被吓到：

1. 光标页也要同一张卡  
2. 误套要能撤销刚才那一次  
3. 摄像头框不要进快照  
4. 工程脏点要认「已应用 id」  
5. 已删 id / 旧工程要安静降级  
6. 删除用 Dialog，不要系统 confirm，不要 X  

已全部回写 03 代决 D8–D12 与 05 工单。没有未决选择题留给执行智能体。
