## 一、角色 / 金路径 / 为什么改 / G / 范围

| 项 | 钉死 |
|----|------|
| 角色 | 培训师，录 **Windows 软件操作** 给学员看 |
| 金路径（动词，不变） | **启动录制 → 停止 → 编辑 → 导出视频** |
| 为什么改 | 顶栏「预设」贴在导出旁，心智像导出档；列表里的 **X 看起来像取消，实际是删除**；选中后没有正当的「不用这份预设了」。培训师要改一项设置才能「逃出去」，不像剪映 / OBS / 资源管理器 |
| G1 | 编得动、导得出；套样式或取消样式都不打断导出 |
| G2 | 同一套课件外观能复用，少在侧栏里重调壁纸/光标/缩放；不靠隐晦操作 |
| G3 | 本夹不改字幕引擎、不改配音 |
| G4 | 少而稳；不新增左轨图标、不做云同步、不另造「导出预设」产品 |
| 范围 | 仅 Windows；zh-CN + en；`dev-creator`；不代合/不代关上游 |

**后说覆盖（按时间，后者为准）：**

1. 这是**编辑器外观/样式**的保存与套用，不是导出菜单的一部分。
2. 入口应在 **设置** 或 **左边控制栏**（画面 / 光标这些已经在调的地方），不要贴在导出旁边。
3. 「取消应用」和「删除预设」必须是两件事。取消是通用用户能看见、能点、能理解的动作。
4. 默认交互对齐剪映 / CapCut、OBS、Camtasia、Word 样式、Windows 下拉里的「无」：可以一直不选任何具名预设。
5. 不改变金路径动词顺序；老用户不必先学新流程才能导出。

## 二、你点名的场景（培训师一天）

### 场景 A · 套一份常用课件脸

侧栏里调好壁纸、留白、光标、缩放手感 → 起个名字存下来（例如「冲冲冲」）→ 下一节课打开编辑器 → 在同一处点「冲冲冲」→ 画面立刻是那张脸 → 再去导出。

失败样子：要先找到导出旁边一个书签才能存；或者套上以后不知道怎么只用「这一课的微调」、以为必须删掉那条预设。

### 场景 B · 这节课不用具名预设了

已经点过「冲冲冲」→ 列表显示它是当前项 → 培训师想：**不用这份预设了，但现在的画面可以留着**（或接着自己改）。

成功：看见「未使用预设 / 取消应用」，一点就回到「没有选中任何预设」，脸不动。  
失败：只有灰色 X；点了以为取消，结果整条预设从列表消失。

### 场景 B2 · 我点错了另一条

想套「冲冲冲」，手滑点了「测试」。  
成功：立刻「撤销刚才的套用」，脸和选中都回到点错之前。  
失败：只能取消应用（脸仍是「测试」）或各区块 Reset（回到出厂）。

### 场景 C · 真的不要这条预设了

列表里某条再也不用 → 明确的删除（垃圾桶 + 确认）→ 列表少一条。当前画面不跟着被清空。

失败样子：X 没有确认，手滑删掉「冲冲冲」。

### 场景 D · 套了之后改了一点

套了「冲冲冲」→ 把阴影调大一点 → 能看出来「基于冲冲冲，已改过」→ 可以 **更新这份预设**，或 **另存一份**，或 **取消应用（保留改动、不再挂名）**。

失败样子：改了一点之后名字自己消失，或反过来怎么改都摘不掉名字；必须去改一个隐晦参数才能「跳出」。

### 场景 E · 找得到、用得懂

培训师问同事「样式存在哪」：答案是 **左边「画面」或「光标」面板最上面**，和壁纸、光标在一块。  
不要答「在导出按钮左边那个书签」。调完光标不必先切回画面才能保存。

## 三、成功 / 失败

| 成功 | 失败 |
|------|------|
| 可以从来不选任何具名预设，照常剪、照常导出 | 只要存过一条，界面就永远像必须选中一条 |
| 「取消应用」清楚可见，不删列表里的条目 | 取消和删除共用一个 X |
| 点错另一条能「撤销刚才的套用」 | 只能 Reset 回出厂或干留着错脸 |
| 调光标时也能看见同一张卡并保存 | 只有画面页有卡，光标页以为功能没了 |
| 删除要确认，且只删条目、不还原/不清空画面 | 手滑即删；删了还以为设置会回去 |
| 入口在左边「画面 / 光标」顶，不在导出旁 | 顶栏导出左边仍挂「预设」当主入口 |
| 文案叫「样式预设」，不和运动预设、GIF 尺寸预设抢「预设」一词 | 三处都叫预设，培训师对不上号 |
| 套用只动外观（画面/光标/缩放等），不动导出路径、编码、本机 Whisper 路径 | 点一个样式，导出格式或本机路径被偷偷换掉 |
| 老用户导出路径不变 | 为了改预设，导出菜单被拆乱 |

---

## 四、不做什么（本夹）

- 不做导出预设（编码/帧率/格式另存一份）——以后真需要再开题
- 不新增左轨图标抢「项目 / 画面 / 光标」的位置
- 不做预设文件夹、云同步、商店、分享链接
- 不改运动预设（设置里的「专注 / 演示」那套）
- 不改采集档（省电 / 标准 / 高清）
- 不把样式预设做成必须选一项的「配置文件」（OBS Profile 那种永远有当前档，不是本题）
