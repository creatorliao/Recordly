
# 时间线优化：可拖拽腾出空间

## 原始诉求

你的目标是在合适的主题文件夹里面记录问题和需求，分析源代码、数据分析报告，并且给出解决方案：
时间线的那部分应该像剪映那样，可以把时间线的整体面板往上或往下拖拽。当面板上下移动时，播放的区域就会随之变化会腾出空间的时候，播放的区域会自动撑开了，有相应的动画另外两边收起，左边收左边的，右边收右边的。这一个收起的按钮现在搞反了，明明收的是右边的按钮图标，但是它产生变化了，却是右边的那个面板，这个有点奇怪面板里面的每一个 item、每一个按钮都应该按照我们最新的规范重新设计一下，不应该有那么大的圆角。整体风格要更加专业、客观、相对认真，就像类似剪映和其他同类的专业视频剪辑软件一样，不能像 AI 生成的，也不能像粗制滥造的东西。

所以，每一个面板都要全面检查，找到差距，然后全面修复完善。
1. 记录这些问题和需求到恰当的主题文件夹。
2. 调查这些问题的现状、根本原因以及解决方案。
3. 检查这些解决方案。
4. 一份一份地完善这些解决方案，并落实其中说到的内容。
5.规划好这些提交点，确保功能点不要太零散，而且能够回退
最后升级新的版本号，提交代码，构建出portable的安装版本

## 补充后的范围与验收标准

- 时间线面板顶部必须有可识别的水平拖拽抓手，拖拽时面板高度实时变化，预览区域反向自动撑开。
- 时间线支持折叠/展开，折叠后保留最小可用工具栏；双击抓手恢复默认高度。
- 拖拽过程不能因动画产生明显延迟，释放后允许短暂平滑过渡。
- 折叠按钮的图标、标题、aria-label 和实际控制面板必须一致；顶部按钮只控制设置面板，不改变左侧工具轨。
- 本轮优先修复时间线和相关工具条的专业密度与圆角；全量设置面板视觉重做另立任务，避免高风险扩散。
- 代码验证包括 lint、单元测试、类型检查、i18n 检查和 Windows portable 构建。
