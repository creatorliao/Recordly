# 解决方案

## 交互规格

1. 时间线顶部显示一条短水平抓手，光标为上下调整；拖动时实时改变时间线高度，预览区域同步伸缩。
2. 时间线顶部右侧提供折叠/展开按钮。折叠后保留紧凑的时间线工具栏和最小可用高度，预览区域获得最大空间；再次点击恢复上一次高度。
3. 双击抓手恢复默认 200px 高度；单击不改变高度。
4. 拖拽中关闭高度过渡，避免指针和面板产生延迟；释放后启用短过渡，保证状态变化平滑。
5. 最小高度 108px、最大高度 560px，防止时间线或预览区完全不可用。
6. 顶部按钮的标题、aria-label 和 pressed 状态明确指向设置面板，不改变左侧工具轨行为。
7. 本轮只收敛时间线工具栏和空态的圆角，不全量重构 SettingsPanel。

## 实现范围

- `EditorShell.tsx`：维护折叠状态和拖拽状态，向时间线面板传递控制回调。
- `EditorTimelinePanel.tsx`：增加抓手视觉反馈、折叠按钮和状态 aria 属性。
- `EditorPreviewPanel.tsx`：将时间线工具栏按钮由胶囊样式收敛为紧凑矩形样式。
- `EditorHeader.tsx`、中英文 `editor.json`：修正设置面板按钮语义。

## 验收

- 拖动顶部抓手时，预览区随时间线反向变化且无跳动。
- 折叠、展开、双击复位均可用；折叠后仍可操作时间线工具栏。
- 键盘和屏幕阅读器可识别分隔条和折叠状态。
- `npm run lint`、`npm run test`、`npx tsc --noEmit`、`npm run i18n:check` 通过。
- `npm run build:win:portable` 产出 `release/recordly-portable-<version>/`。

## 回退

功能代码集中在三个布局组件和两份主要语言文案中，可用单次 `git revert` 回退；不触碰项目数据格式和导出链路。
