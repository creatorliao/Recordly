# 需求：摄像头面板简化 + 画布拖位置

## 角色与范围

| 项 | 内容 |
|----|------|
| 角色 | 培训师，Windows 上成片里摆摄像头小窗 |
| 金路径 | 录 → 停 → **编** → 导 |
| G | **G2**（少点、少拧）+ **G4**（一眼能懂，对齐剪映/OBS 画中画习惯） |
| 非目标 | 不改录制 HUD 悬浮预览；不改导出编码；不删裁剪能力；不新开右侧栏 |

## 用户原话（合并两轮）

1. 打开「自定义位置」后，希望**在画布上拖摄像头**到位，而不是只调参数。  
2. 摄像头相关设计和按钮**太复杂**；若能画布拖，**未必还要那么多位置按钮**。  
3. **裁剪很好**，主要是**位置**设计过重。  
4. **摄像头素材**平时几乎不改，建议像「自定义位置」那样可收起。  
5. 要简洁美观、逻辑合理、符合认知；**该有的功能不能少**，可以隐藏/调整；缺 tooltip，看不懂。

证据：[附图-01](附图-01-自定义位置滑条.png)、[附图-02](附图-02-摄像头面板全貌.png)。

## 场景（培训师）

1. 开「显示」，确认小窗在预览里。  
2. 裁一下脸（裁剪区）。  
3. 把小窗挪到不挡字幕/按钮的位置。  
4. 偶尔改宽高、圆角、阴影、镜像、是否跟缩放。  
5. 极少：替换/移除摄像头素材文件。

## 成功 / 失败

| 成功 | 失败 |
|------|------|
| 一屏内主路径清楚：显示 → 大小 → 裁剪 → 位置（拖）→ 外观 | 九宫格 + 自定义开关 + 双滑条三套抢「摆位」认知 |
| 画布可拖；位置参数仍可查/可微调（不必永远摊开） | 只能拧水平垂直，或拖了导出位置不对 |
| 素材区默认收起，需要时再展开 | 长文件名+双按钮常占一截屏 |
| 开关/滑条有简短图贴或说明 | 无 tip，名词不知所云 |
| 裁剪、替换素材、九宫格贴角（若保留）能力仍在 | 为「简洁」删掉替换素材或裁剪 |

## 非目标

- 不做摄像头旋转、关键帧动画编辑器。  
- 不把素材管理做成独立项目页。  
- 不改默认圆角成片观感（规范：成片摄像头圆角不强制改方）。
