## S1 · 画布拖拽（核心）

见原拖拽规格，修订一点以贴合 D1：

1. `webcamOverlay.ts`：像素 ↔ `positionX/Y` 反算纯函数 + 单测。  
2. `VideoPlayback`：气泡在 `enabled && source` 时 `pointer-events: auto`，`grab/grabbing`。  
3. 拖中/松手：`positionPreset: "custom"` + X/Y；侧栏精确滑条若展开则跟随。  
4. `stopPropagation`，避免抢缩放焦点。  
5. 预览一句常显或拖时 tip：`可拖动调整位置`。

导出仍走同一 `getWebcamOverlayPosition` → 预览与成片一致。

## S2 · 位置区改版（`SettingsPanel`）

- 删除（或不再默认渲染）顶层「自定义位置」大开关行。  
- 位置块标题下：短说明 +（可选）当前模式文案：`自由摆放` / `贴右下` 等。  
- `Collapsible`「快捷贴角」：内嵌原 3×3；点击预设 → `applyWebcamPositionPreset`。  
- `Collapsible`「精确位置」：水平/垂直滑条。  
- 无独立 custom 开关：从九宫格点回预设即离开 custom；拖一下回到 custom。

## S3 · 素材折叠

- 默认 `footageOpen = false`。  
- 行样式对齐其他开关行：左「摄像头素材」，右折叠箭头或 Switch「管理」。  
- 展开：文件名、替换、移除（逻辑照旧）。  
- 无 `sourcePath` 时：折叠行副文案「未关联」，或自动展开一次（代决：副文案即可，不强制展开）。
