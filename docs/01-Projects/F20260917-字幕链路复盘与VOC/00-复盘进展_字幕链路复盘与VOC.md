### （P13 追加）转写链路「可直接照抄」的六条硬结论

> 完整台账与全部原始数据见 `P13-实测基线与最优参数_转写链路.md`。这里只放**改代码时必须知道**的六条。

| # | 结论 | 实测证据 |
|:--|:--|:--|
| 1 | **whisper-cli 默认 `-t 4`，不传 `-t` 就浪费一半 CPU** | 英文 206.4 s 素材：`-t4` **80.5 s** → `-t8` **52.4 s（+35%）** |
| 2 | **`--vad` 是性价比最高的一步（只要 885 KB）** | 中文：重复幻觉 **7→0**、错字 **8→2**，耗时还从 93.4 s 降到 **83.8 s** |
| 3 | **`-mc 0` 只治重复幻觉，不治错字** | 中文：幻觉 7→0，但近音错字 8→**10**；速度 93.4→74.3 s |
| 4 | **中文词级产物在 v1.8.4 全损，必须 v1.9.2+** | `-ojf` 的中文 token：v1.8.4 **38/141 是 `�`**；v1.9.2 **0/122 且逐字一致** |
| 5 | **GPU 只在 turbo 级模型上值得** | small：CPU 55.0 → GPU 45.1 s（**1.2×**）；turbo-q5_0：CPU 183 → GPU **83.5 s（2.2×）** |
| 6 | **口播录屏默认转的是「混音轨」，不是麦克风轨** | `generate.ts:119` 先 push 录制本体；mic 在 `audioCandidates.ts:13-18` 只排第二 |

**另外三条工程坐标**：
- 换大模型（small → turbo-q5_0）**内存几乎不涨**：882 → 932 MiB；代价全在时间（**≈2.4×**）。
- `turbo` 的中文**句末标点几乎为零**（句号 0 vs small 的 24）→ 必须配套补标点。
- ⚠️ **本机 CPU 计时方差达 2×**（同一配置 132→268 s），绝对秒数只当量级用。

- 合并推算：红杉 314s 片，字幕布局 **≈10.1s**（中文实际口径）占导出总量 **2.0%–4.6%**；若为空格分词语言则 **≈85.9s**

- CLI 实测：`rlex project patch` **能改**字幕样式标量（fontSize/bottomOffset/animationStyle 均成功），**不能改** `autoCaptions[]`（数组拒绝）与 `fontFamily`（不在白名单）
