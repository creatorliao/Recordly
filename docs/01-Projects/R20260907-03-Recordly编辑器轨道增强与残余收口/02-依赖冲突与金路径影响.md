## 二、与已有方案的交界（禁止互相踩）

| 已有决定 | 本夹怎么处 |
|----------|------------|
| A1 进门项目 | **不改**。禁止「停录跳画面」、禁止记忆 Tab |
| R14 P01 `showSourceAudio = true` | **保留能力**。只改 `sourceAudioTracks` **默认渲染哪些行**（mixed 优先，否则 mic；system 不默认铺）。属性板开关仍能开齐 |
| 甲 T-I 随内容高度 | 可拖高是覆盖值；清掉覆盖或新课 → 回到随内容 |
| 甲 T-H 不加左轨名列 | 不借 WP-A 再开名列 |
| `R20260907-01` 样式预设 | WP-C 只动下拉圆角皮肤，不改应用/取消/删除 |
| 甲 WP3 扩展空态 | WP-E 默认 **不做**；要做须单独点名，并改手册 |

源码事实（乙落地时仍要复核）：

- 新录制自动整轨 clip 写 `showSourceAudio: true`（`useTimelineProjection.ts`）
- 画布按 `showSourceAudioTrack && sourceAudioTracks.map` 铺行（`TimelineCanvas.tsx`）
- `buildTimelineSourceAudioTracks`：有 sidecar 时最多 **system + mic** 两行；否则 **mixed** 一行。走查说的「三行」是 clip 勾了源音频后旁路齐全时的观感上限，实现上常见 1～2 行。乙按「默认只铺优先的一条」写，不要假设永远有三行。

## 三、本夹内部顺序与互斥

```
WP-A 默认一条讲解声
WP-B 可拖高（可与 A 分 commit，勿同一 PR 缠皮）
WP-C 残余圆角（Settings 只动散落按钮 class，禁止整文件扫）
WP-D 删 TimelineToolbar + 运输条 hint + 扫残余 AnimatePresence
WP-E 藏扩展入口（默认跳过）
```

| 不要同时做 | 为何 |
|------------|------|
| WP-A 和「关 showSourceAudio」 | 倒退 P01，金路径「听得清」变差 |
| WP-B 和加回 stretch | 与甲直接矛盾 |
| WP-C 和改对话框 / Launch `--radius` | 出范围 |
| WP-E 和复活扩展市场 | P3，出范围 |

## 四、对金路径的影响

| 环节 | 影响 |
|------|------|
| 录 / 停 | 无 |
| 编 · 进门 | 无（A1 不动） |
| 编 · 时间轴 | 默认少 0～1 行波形；切割/缩放/点块出属性不变 |
| 编 · 长课 | 可选拖高，预览变矮——须可拖回 / 双击恢复随内容 |
| 导 | 至多菜单圆角；先选路径再导出不变 |

手册（落地后才改 `R20260906-01`）：

- WP-A：新课时间轴默认一条讲解声；要看系统声/麦，在片段属性打开。
- WP-B：轨道下缘可拖；新课不必拖。
- WP-E 若做：扩展入口怎么找。
