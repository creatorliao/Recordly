## 二、场景

### 场景 G · 停录后看讲解声在不在

甲已经把每行收成 28px。培训师要确认「我的声音在不在」，不要先辨认系统声 / 麦 / 混合三行。

成功：默认一条讲解声（mixed 优先，没有则 mic）。其余旁路不默认铺行，属性板仍能打开。  
失败：把 `showSourceAudio` 改回 false（P01 倒退）；或三条都藏光，听不清有没有录上。

### 场景 H · 字幕很多的一节课

效果道叠到甲的 max≈220 后要滚。培训师想把轨道区拖高一点，像剪映拖时间轴。

成功：下缘可拖，高度写入本次会话（或项目偏好）；新课默认仍随内容。  
失败：默认变成 392 矮预览；或拖高把 stretch / flex-1 加回来。

### 场景 I · 抽屉里残余胖按钮

甲已改滑条/色板/分段。Settings 里仍有 `h-10 rounded-xl`、导出菜单大圆角。

成功：同一套 `--ed-*` 半径 2。  
失败：整文件扫 `rounded-*` 扫到摄像头成片预览或 Launch。

## 三、成功 / 失败

| 成功 | 失败 |
|------|------|
| 新课默认 1 条讲解声波形，属性里仍能开齐 | 默认关波形，或误删旁路文件 |
| 长课可拖高，默认高度仍随内容 | 默认 15% 空膛或 OS 392 |
| 散落按钮与导出菜单吃甲的皮肤 | 改到 Launch / 成片摄像头 |
| 金路径动词不变，A1 仍在 | 为了「停录想剪」把默认 Tab 改回画面 |

## 四、不做什么

- 不改切割 / 缩放 / 字幕数据语义、不换时间轴引擎
- 不加 minimap、左轨名列、主题市场、AI、记忆 Tab（P3）
- 不改 Launch / R-HUD / 成片摄像头圆角
- 不在甲未完成时开工
