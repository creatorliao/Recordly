|------|------|--------------------------|
| `recording.start-attempt` / `capture.start` | 这次录的档位 | `preset/fps/bitrateBps`：验 1 应是 standard/30/10000000；验 3 应是 high/60 |

| `preview.media-error` | Chromium 解码/格式失败 | 成片编码（H2/H3） |
| `preview.suspend` `active:true` 且你没在导出 | 预览仍被停转 | yield 没撤干净 |
| `preview.texture-mount` 在点播放后连刷 | 纹理被反复拆 | 布局 effect 仍绑太死 |

## 第 1 包日志结论（beta.8，`recordly-20260906-200412-pid12656.log`）

验 1 仍坏。日志自己对过，不是猜：

1. **本机采集没起来**：`spawn …\app.asar\electron\native\bin\win32-x64\wgc-capture.exe ENOENT`，回退浏览器。`app.start` 写着 `isPackaged: false`（electron.exe 身份）。成片是浏览器录的 13.9s。  
2. **Pixi 被反复拆**：点播放后 `pixiReady` 立刻变 false，`preview.texture-mount` 连刷（seq 4→9），`play-guard` / `media-pause` 跟着来，`progress-check stuck:true`，`currentTime` 钉在 0.015。  
3. **根因（编辑器）**：`useProjectState` 的 `setError` 每次渲染都是新函数，Pixi 初始化 effect 把它当依赖 → 一点播放就拆画布。让路 / 只收 pause 环盖不住这条。  
4. **根因（采集）**：helper 路径见 `isPackaged` 才改写 unpacked，Portable 判成未打包，spawn 进 asar。见 `R20260906-04/10`。

让路回收、pause 环收紧**不是废代码**（官方对齐 + 防二次按死），但**不是这次闪屏的主开关**。本轮不再撤它们，改打主开关。
