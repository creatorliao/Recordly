# 15 · 执行中暂缓与跳过

## 暂缓 1 · 原生 WGC 采集缩小再编

| 项 | 内容 |
|----|------|
| 为什么暂缓 | 现有 `MFEncoder::writeFrame` 在尺寸不一致时是 **裁切**（CopySubresourceRegion），不是缩放。若把 4K 纹理解成 1080 输出，成片会只剩左上角。补 GPU 拉伸要动 C++ 着色器，风险高于本轮「降 fps + 限码率」。 |
| 试过什么 | 读 `mf_encoder.cpp` 的 resize 路径；确认 `width/height` 配置会直接当编码尺寸。 |
| 下一条是谁 | 本轮已落地：默认 **30fps + 约 10Mbps**；浏览器回退路径按档位限制 1080/720。原生 4K 屏仍按源分辨率采，但帧率和码率已降。 |
| 何时再看 | 真机日志里若标准档仍出现 4K 编码且整机卡，再做 GPU blit 缩放。 |
