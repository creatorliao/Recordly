# 01 · 问题：整机资源占用过高

> 2026-09-06 用户口述。只落盘，不改产品代码。

## 1. 现象

用 Recordly 时资源消耗很大，原因不清楚。严重时：

- 本机卡住；
- 或其它程序没法正常用。

与 `R20260906-09`（成片卡、鼠标跟不上）可以同时存在：整机卡了，采集和光标采样也更容易掉队。但本主题先盯**整机能不能干活**，不先修成片观感。

## 2. 目标锚点

| 项 | 内容 |
|----|------|
| 角色 | 培训师，录软件操作 |
| 金路径 | 启动录制 → 停止 → 编辑 → 导出 |
| 落点 | **G1** 录的时候电脑还能点被录软件；**G4** 不为炫画质把整机打满 |
| 范围 | 仅 Windows；`dev-creator` |

## 3. 用户另外要的

日志里要能看到**相关资源消耗**（见 `R20260906-11` 方案补丁）。没有数字，后面的「优化」只能猜。

## 4. 对工作流

未改录→停→编→导。优化落地时默认应「更省」，高画质做成可选，老用户不必先改操作。
