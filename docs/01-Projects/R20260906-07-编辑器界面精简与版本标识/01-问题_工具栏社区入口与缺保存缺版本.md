# 01 · 问题：Discord / 反馈 / 账号、缺保存按钮、标题无版本

> 2026-09-06 真机：顶栏有加入 Discord、添加反馈；左下角账号；打开项目旁没有保存；「Recordly 编辑器」后面没有版本号。

## 1. 现象 / 诉求

培训师内部分发不需要社区和账号。要能主动点保存。标题栏要带版本，方便对 portable 包。

## 2. 根因

`EditorHeader` 固定渲染 `DiscordLinkButton` / `FeedbackDialog`。  
`EditorSidebar` 左下角账号只 toast「即将推出」。  
保存只在项目下拉和 `Ctrl+S`，顶栏无图标。  
`document.title` 只有 `app.editorTitle`，未拼 `getAppVersion()`。

## 3. 方案

去掉三入口（不改金路径）。打开项目图标旁加保存。标题：`Recordly 编辑器 1.4.0-beta.x`。

## 4. 对工作流

保存从「菜单/快捷键」多一个顶栏按钮，旧方式仍可用。手册补一句。
