# 05 · 问题：硬编码英文与中英夹杂（全面收敛）

> 2026-09-06：界面默认简中时，仍有 toast、空状态、关窗/导出提示、部分设置控件是英文；上一轮部分弹框做成「中文 (English)」反而夹杂。

## 1. 根因

1. 不少 `toast.*("英文")`、JSX 英文、`setError("英文")` **没走** `t()`。  
2. `t(key, "English fallback")` 在 key 缺失时直接显示英文。  
3. 壁纸专名（Tahoe Light）按尺子不翻译。

## 2. 方案

- 用户可见文案进 `en` / `zh-CN`。  
- **简中 = 纯中文，英文 = 纯英文**，同一界面不再夹杂。  
- 不改内部 `throw new Error` / `console`（除非会弹到用户眼前）。

## 3. 已落地

- 导出/项目 toast、时间轴空状态、字幕生成提示、预览「编辑字幕」、宽高比/取色 aria。
- 编辑器加载失败页、导出过慢提示、时间轴缩放/字幕无法放置 toast。
- 录制：选源、权限、系统音频、麦克风、本机采集回退、保存失败，不再弹英文。
- 主进程保存/打开/导出/选文件对话框标题与过滤器名跟界面语言走（`uiLocale` 写入 app-settings）。
- 简中 = 纯中文；语言名「简体中文 / English」保留；壁纸专名不译。

## 4. 对工作流

只改文案，不改录→停→编→导。

## 5. 仍可能英文的地方

- 主进程内部 `message`（只打日志，不再直接 toast）。
- `throw` / `console` 技术错误。
- 系统文件框的「打开/取消」按钮跟操作系统语言，不跟应用。
