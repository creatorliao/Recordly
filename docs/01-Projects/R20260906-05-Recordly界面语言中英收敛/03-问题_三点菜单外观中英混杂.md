# 03 · 问题：启动窗三点菜单「外观」中英混杂

> 2026-09-06 真机：语言已选「简体中文」，三点菜单里 HUD / 文件夹 / 语言是中文，**APPEARANCE / Light / Dark / System 仍是英文**。  
> 同批时间轴提示「No cursor telemetry available」也是英文硬编码，一并改。

---

## 1. 现状

启动窗底栏三点菜单（`MorePopover`）：

| 区块 | 真机文案 | 期望（简中） |
|------|----------|--------------|
| HUD / 录制文件夹 / 打开视频 / 打开项目 | 中文 | 中文 |
| 外观分组标题 | `APPEARANCE` | 外观 |
| 三项 | `Light` / `Dark` / `System` | 浅色 / 深色 / 跟随系统 |
| 语言 | 语言 / 简体中文 / English | 保持 |

Studio 时间轴点「从光标建议缩放」时，气泡仍是英文 `No cursor telemetry available`（`zh-CN/timeline.json` 里已有译文，组件没用）。

## 2. 根因

`MorePopover` 用 `useScopedT("launch")`，查找的是 **`launch.*`**：

- `t("recording.appearance", "Appearance")` → `launch.recording.appearance`：**没有这个 key**
- `t("common.light", "Light")` → `launch.common.light`：**不是** `common.json`，也没有

缺 key 就走第二个参数英文兜底。  
上一轮把「外观 / 浅色 / 深色 / 跟随系统」写进了 `editor.json` 的 `editor.theme.*`，`SettingsPanel` 能用，**三点菜单没用这套 key**。

时间轴：`useTimelineZoomActions` 把英文句子写死在 `timelineNotifications.info(...)`，不走 i18n。

## 3. 方案

1. 三点菜单改读已有 `editor.theme.appearance|light|dark|system`（`useI18n().t`）。  
2. `launch.json` 中英各补一份同义 key，避免以后再有人用 scoped `recording.appearance`。  
3. 时间轴缩放提示改走 `timeline.zoom.noTelemetry` 等已有 key。

同批再验导出菜单：

| 处 | 真机 | 期望 |
|----|------|------|
| 顶栏 | Presets | 预设 |
| 编码分组 | ENCODING / Fast / Balanced / Quality | 编码 / 快速 / 均衡 / 画质 |
| 主按钮 | 导出Video | 导出视频 |

根因：`export.encoding*` 缺 key；`export.exportVideo` 把英文 `Video` 拼进中文模板。

## 4. 执行

已改产品代码（见 `R20260906-02/09` 本轮留痕）。  
**怎么验：** 简中下开三点菜单，外观四条应为中文；导出菜单编码与按钮应为中文；时间轴无遥测时提示应为「无光标遥测数据」。
