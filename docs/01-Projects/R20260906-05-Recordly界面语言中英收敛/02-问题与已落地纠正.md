# 02 · 问题与已落地纠正

> 2026-09-06 从 Portable 专题拆出。代码已改；本篇是语言主题的真源。

## 原先为什么是英文

- `DEFAULT_LOCALE` 是 `"en"`。  
- `localStorage` 键 `recordly.locale` 常被写成 `en`（或跟系统英文走）。  
- 启动窗 / 设置里的语言列表绑了 `es/fr/de/it/nl/ko/pt-BR/zh-TW`。  
- 字幕语言下拉是 Auto + 英西法德意葡中日韩，标签还是英文。  
- 窗口菜单 `File/Edit/View` 写死英文。

## 已改

| 处 | 改法 |
|----|------|
| `src/i18n/config.ts` | 默认 `zh-CN`；`SUPPORTED_LOCALES` 只剩 `zh-CN`、`en` |
| `I18nContext` | 只加载中英包；存储键改为 `recordly.locale.v2`，冲掉旧默认英文；缺 key 时先简中再英文 |
| `MorePopover` / `SettingsPanel` | 界面语言列表只显示「简体中文 / English」 |
| 字幕语言 | 只留「自动检测 / 简体中文 / English」 |
| `electron/main.ts` 菜单 | Windows 菜单改成中文（文件/编辑/查看/窗口） |
| `zh-CN`/`en` 的 `editor.json` | 补「外观 / 浅色 / 深色 / 跟随系统」 |
| `scripts/i18n-check.mjs` | 只对账 `en` 与 `zh-CN` |

磁盘上其他 locale JSON **未删**，界面不再列出。

## 怎么验

1. 忽略旧 `recordly.locale`，冷启动：启动窗、Studio、设置应为简体中文。  
2. 语言下拉只有两项。  
3. 字幕语言只有三项。  
4. 需要英文时，在设置里选 English；再切回简体中文。
