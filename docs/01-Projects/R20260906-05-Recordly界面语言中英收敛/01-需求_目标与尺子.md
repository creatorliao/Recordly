# 01 · 需求：目标与尺子

> 角色仍是培训师，金路径仍是录→停→编→导。本夹只解决 **界面语言**，不解决安装包 / ZIP。

## 三条尺子（你钉的）

1. **语言范围**：只关注简体中文和英文。磁盘上可以留着其他 locale JSON，界面不得再列出。  
2. **界面显示**：所有界面默认应是简体中文。整页英文不对。  
3. **列表精简**：不要出现西语 / 韩语 / 繁中等一长串选项；字幕语言同样收成中英（可加「自动检测」）。

## 成功 / 失败

| 成功 | 失败 |
|------|------|
| 冷启动启动窗、Studio、设置为简体中文 | 默认仍是英文，或被旧 `localStorage` 锁在 `en` |
| 界面语言下拉只有「简体中文 / English」 | 还能选出 Español、한국어 等 |
| 字幕语言只有自动检测 / 简体中文 / English | 仍是九国语言英文标签 |

## 不做

- 不为波兰语 / 俄语 / 印尼语 / 阿拉伯语 / 繁中补翻译或修 key（`i18n:check` 只对账 en 与 zh-CN）。  
- 不改壁纸资源专名（Tahoe Light 等）。  
- 不在本夹讨论 NSIS / ZIP / CMake。
