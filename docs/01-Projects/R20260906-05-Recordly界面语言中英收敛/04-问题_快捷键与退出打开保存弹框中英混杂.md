# 04 · 问题：快捷键、退出/打开/保存弹框中英混杂

> 2026-09-06：配置里快捷键动作名全是英文；退出未保存、保存项目、打开项目弹框标题/按钮已中文，说明和动作仍是英文 fallback。

## 1. 现象

- 快捷键帮助 / 自定义：`Add Zoom`、`Split Clip`、`Pan Timeline` 等硬编码英文。  
- 保存项目：标题「保存项目」，说明仍是 `Name this project…`（缺 `saveDescription`）。  
- 未保存：`在 return to recording / open another project 之前保存…`（动作标签写死英文）。  
- 打开项目：`Projects` / `Import` / `No preview yet` / `Current` / `No saved projects yet`。  
- 关编辑器窗口：系统原生 `Unsaved Changes` / `Save Close` / `Discard Close`，取消键却是中文「取消」。

## 2. 根因

`SHORTCUT_LABELS`、`FIXED_SHORTCUTS.label`、`ProjectBrowserDialog` 未走 i18n。  
`t(key, 英文)` 在 zh-CN 缺 key 时回落英文。

## 3. 方案

补齐 zh-CN / en key。快捷键动作 **中英并列**（例：`添加缩放 (Add Zoom)`）。弹框缺文案补中文（说明类可中英并列）。调用处传入已翻译动作，不再塞英文短语。

## 4. 对工作流

只改文案，不改快捷键默认键位、不改保存/打开逻辑。
