# 04 · 调查：字幕能力链路与断点

## 1. 产品能力（已经有的）

本地、不上传音频：

1. 用 FFmpeg 从成片 / 麦克风 sidecar / 系统声 sidecar 抽出 16 kHz 单声道 WAV。  
2. 调 **whisper.cpp** 的 `whisper-cli`：`-m 模型` `-f wav` `-osrt` `-ojf` `-l 语言`。  
3. 解析 JSON 词级时间；失败则退回 SRT。  
4. 再用 FFmpeg `silencedetect` 按停顿重切句子。  
5. 写入时间轴 `CaptionCue[]`，预览里叠字幕；导出可带 `.srt`/`.vtt` 旁路文件。

语言选项（面板写死）：`auto` / `zh` / `en`。培训师应默认 **简体中文**，不要靠 auto 在中英夹杂录音上赌。

引擎查找顺序（`resolveWhisperExecutablePath`）：

1. 用户偏好里保存的 exe（面板目前**没有**选 exe 按钮）  
2. **捆绑** `electron/native/bin/{arch}/whisper-cli.exe`（打包后走 asar.unpacked）  
3. 环境变量 `WHISPER_CPP_PATH`  
4. mac 的 Homebrew 路径（Windows 不走）  
5. `where whisper-cli.exe`

**断点不在第 2 步。** 捆绑引擎这条已经接上。

## 2. 用户点「生成字幕」实际发生什么

```
SettingsPanel「生成字幕」
  disabled = 正在生成 或 没有 whisperModelPath
    ↓
useAutoCaptionController.handleGenerateAutoCaptions
  解析视频路径（工程 / 当前录制）
  若 !whisperModelPath → toast「请先选择 Whisper 模型，或先下载 small 模型」
    ↓
IPC generateAutoCaptions({ videoPath, whisperExecutablePath?, whisperModelPath, language })
    ↓
generateAutoCaptionsFromVideo
  找引擎（可自动捆绑）
  读模型文件（必须已存在）
  抽音频 → whisper-cli → 解析 → 回写 cues
```

`whisperModelPath` 初始来自编辑器偏好（`editorPreferences`，默认 `null`）。启动时再问一次 `getWhisperSmallModelStatus()`：只有 **userData 里那份 ggml-small.bin** 存在，才自动填路径。

## 3. 断点图

```
[捆绑 whisper-cli.exe]  ✅ 已随包 / 已暂存
        │
        │  生成时自动 resolve
        ▼
[whisper-cli 进程]     ✅ 能启动（缺 VC++ 才会在这一步炸）
        │
        │  必须 -m 指向 .bin
        ▼
[ggml-small.bin]       ❌ 不随包；要 HTTP 下或手选
        │
        ▼
[whisperModelPath]     ❌ 空则按钮禁用 + toast
        │
        ▼
[抽音频]               ⚠ 成片无声轨会失败（和 Whisper 无关）
        │
        ▼
[时间轴字幕]           ✅ 模型齐了就能走
```

「没连通」说准确一点：

- **引擎 ↔ 生成 IPC**：通。  
- **捆绑目录 ↔ 模型路径**：不通（根本不找 `.bin`）。  
- **下载器 ↔ 国内网络**：脆（见 `03`）。  
- **「选可执行文件」↔ 界面**：回调在、按钮不在，反而容易让人去下模型。

## 4. 界面为什么一直推「下载」

`SettingsPanel` 字幕区：

- 有「选择模型」（本地挑 `.bin`）。  
- 没有模型路径 → 主按钮是「下载模型」。  
- 有路径 → 变成「删除模型」。  
- 「生成字幕」在没有路径时 **disabled**。

所以即使用户机器上已经有一份模型（例如上次 Portable 下过、或开发者自己放的），只要：

- 偏好没记下路径，且  
- 当前这个 userData 目录里没有 `whisper/ggml-small.bin`，

界面就当「没模型」，继续要你下载。

## 5. 和「讲解声」的关系（G3）

字幕听的是 **已保存文件里的音频**，不是实时麦。

- 录制时麦克风 / 系统声没进成片或 sidecar → Whisper 再强也是空字幕或报「没有可转写的音频」。  
- 这和「要不要下载模型」是另一条线，完善字幕时不要混成一个 bug。
