# 01 · 需求、目标与尺子

## 1. 角色与金路径

| 项 | 内容 |
|----|------|
| 角色 | 培训师，录软件操作，要给学员看带讲解的成片 |
| 金路径 | 启动录制 → 停止 → 编辑 → **一键出字幕** → 导出视频 |
| 为什么改 | G3「字幕 / 配音」现在卡在「还要自己下模型」，培训师不该当运维 |
| 范围 | 只 Windows；只 zh-CN + en；本夹先调查，方案确认前不改代码 |

## 2. 落到哪条 G

| 编号 | 是否相关 |
|------|----------|
| G1 完整路径可用 | 有。字幕不是金路径阻断，但「点了生成却灰着 / 失败」会让人以为产品坏了 |
| G3 字幕 / 配音 | **主目标**。一键字幕、讲解声可识别 |
| G2 减轻剪辑 | 有字幕才能少手打 |
| G4 不过度设计 | 默认开箱能用；高级「自选模型」可以留，但不能挡默认路径 |

## 3. 用户原话整理成需求

1. 解释 `.tmp/whisper-runtime`、`prebuilt-win32-x64`、`v1.8.4-windows-x64.zip` 是什么。  
2. 解释字幕整理和 Whisper 为什么总是下载不了。  
3. 解释：明明已经有 Whisper 运行，为什么做字幕还要再下载？是不是没连通。  
4. **希望**：模型随包装给用户，不要用户额外下载。  
5. **希望**：有运行时就能生成字幕，不要再拦一层「请先下载」。  
6. 先充分理解能力，再谈完善；本夹先记清、先调查。

## 4. 成功 / 失败（理解层面，不是本轮实现）

**理解成功**：能用一张表分清「引擎 / 模型 / 缓存 / 用户数据」；能指出界面为什么灰掉「生成字幕」；能回答「能不能打包」和体积代价。

**实现成功（将来拍板后）**：培训师打开编辑器 → 选中文 → 点生成 → 出字幕，**不必先点下载、不必会 Hugging Face**。

**失败**：继续把「有 whisper-cli.exe」当成「字幕已经能用」；或把构建缓存目录当成给用户的模型。

## 5. 不做（本轮）

- 不改下载器、不改打包脚本、不把 `ggml-*.bin` 打进仓库。  
- 不为 macOS / 其他语种单独设计。  
- 不把构建缓存 `.tmp/` 提交进 git。
