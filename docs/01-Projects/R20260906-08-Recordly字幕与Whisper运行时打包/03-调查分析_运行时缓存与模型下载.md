# 03 · 调查：运行时缓存与模型下载

## 1. 构建：引擎从哪来

`npm run build:whisper-runtime` → `scripts/build-whisper-runtime.mjs`

对 **Windows x64** 优先走官方预编译，避免本机必须装 VS/C++ 才能出字幕引擎：

1. 下载  
   `https://github.com/ggml-org/whisper.cpp/releases/download/v1.8.4/whisper-bin-x64.zip`  
   存成 `.tmp/whisper-runtime/v1.8.4-windows-x64.zip`（本机实测约 **3.9 MB**，脚本带 SHA-256 校验）。
2. 解压到 `.tmp/whisper-runtime/prebuilt-win32-x64/`。
3. 找到含 `whisper-cli.exe` 的目录，把 `whisper*` / `ggml*` / `*.dll` 拷到  
   `electron/native/bin/win32-x64/`。
4. 写 `whisper-runtime.json`（version=`v1.8.4`，binary=`whisper-cli.exe`）。
5. 若 zip 已暂存且清单+exe 都在，下次构建直接跳过。

预编译失败才回退源码编译（再下 `v1.8.4.tar.gz`、CMake）。本机当前是预编译成功路径，**没有** `src-v1.8.4`。

打包：`electron-builder` 把 `electron/native/bin` 放进 `app.asar.unpacked`（排除 bench/server 等工具）。`scripts/smoke-packaged-binaries.mjs` 会检查包里有没有 `whisper-cli.exe`。

**结论**：你看到的三个 `.tmp` 路径，全部是「给打包机下引擎」的缓存。和用户点「下载模型」是两条 HTTP、两种文件。

## 2. 运行：模型从哪来

| 项 | 值 |
|----|-----|
| 代码 | `electron/ipc/captions/whisper.ts` + `electron/ipc/constants.ts` |
| URL | `https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin` |
| 落盘 | `{userData}/whisper/ggml-small.bin` |
| 体积（公开规格） | **约 466 MB**（Whisper `small` 多语言模型，未量化） |
| 传输 | Node `https.get`，跟最多 5 次重定向 |
| 超时 | **30 秒**（`timeout: 30_000`） |
| 断点续传 | **无** |
| 镜像 / 代理 | **无** |
| 国内加速 | **无** |

状态探测只认这一个固定路径是否可读：`getWhisperSmallModelStatus()`。  
**不会**去看 `electron/native/bin`、extraResources、或 `.tmp`。

## 3. 为什么「总是下载不了」（按可能性）

1. **体积 × 超时**  
   466 MB 要在 30 秒内从 Hugging Face 拉完，国内几乎不可能。超时后 `req.destroy`，临时文件删掉，进度归零。表现就是「下了一下又失败」。
2. **Hugging Face 在国内不稳定或被拦**  
   无镜像、无系统代理配置读取。公司网 / 无代理时常见 `ECONNRESET`、`ETIMEDOUT`、403/401。
3. **TLS / 证书 / 拦截**  
   走裸 `https`，不走 Electron `session` 的代理或证书例外。
4. **和引擎下载成功形成对比**  
   构建时下的是 **GitHub Release 3.9 MB**，开发机往往已经能访问 GitHub（或已经下过 zip）。用户运行时下的是 **Hugging Face 466 MB**。一边成功不能证明另一边也能成功。
5. **开发态 userData 是 `Recordly-dev`**  
   `electron/appPaths.ts`：有 Vite 开发服务器时写到 `Recordly-dev`。你在 Portable 里下成功过的模型，**不会**出现在 `npm run dev` 的编辑器里，看起来又像「又要下一次」。

## 4. 本机事实（2026-09-06 扫盘）

| 位置 | 有无模型 `.bin` | 有无引擎 |
|------|-----------------|----------|
| `.tmp/whisper-runtime/` | 无 | 有 zip + 解压目录 |
| `electron/native/bin/win32-x64/` | 无 | 有 `whisper-cli.exe`、`whisper.dll`、`ggml*.dll` |
| 打包产物 `app.asar.unpacked/.../win32-x64/` | 按脚本只会带引擎 | 有（smoke 检查 exe） |

所以：**仓库和当前暂存目录里，从来就没有随包模型。** 下载按钮是唯一「官方」补模型路径（另可「选择模型」手挑本地 `.bin`）。

## 5. 本机代理已拉下模型（2026-09-06）

走本机 `127.0.0.1:1087`：直连 Hugging Face 超时，代理通道约 2 分钟下完。

| 项 | 值 |
|----|-----|
| 路径 | `.tmp/whisper-models/ggml-small.bin`（gitignore，不进仓库） |
| 大小 | 487 601 967 字节（465.0 MB，与 Content-Length 一致） |
| 来源 | `huggingface.co/ggerganov/whisper.cpp/.../ggml-small.bin` |

这只是构建缓存。要进 Portable、让界面不再逼下载，还要改 extraResources 和 `whisperModelPath` 自动解析。
