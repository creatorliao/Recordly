# 06 · 问题：字幕面板仍要下载 / 选择模型，生成是灰的

> 来源：2026-09-06 真机截图 + 口述。培训师角色，金路径含「一键字幕」（G3）。  
> 用户口径：**模型随包装好，界面不要「下载模型」「选择模型」；只要清除 / 生成。动画下拉要中文。**

## 1. 现象（截图当时）

1. 仍要求「**下载模型**」（蓝按钮还在）。
2. 「**选择模型**」点开后选不上，也找不到随包的 `ggml-small.bin`。
3. 「添加字幕」没反应。
4. 「**生成字幕**」灰色点不了。
5. 「动画」下拉是英文：Off / Fade / Rise / Pop。

## 2. 为什么会这样（对照代码，不是猜）

| 现象 | 原因 |
|------|------|
| 生成灰色 | `SettingsPanel` 曾写 `disabled={!whisperModelPath}`。状态没把路径填上，按钮就死。 |
| 仍要下载 | 同一套 UI：捆绑没被认到（`whisperModelIsBundled` 为假且路径空）就画「下载模型」。截图正是这个分支。 |
| 选择模型选不上 / 找不到包内模型 | 「选择模型」是系统文件框，滤 `*.bin`，默认不在安装目录。随包文件在 `resources/whisper/ggml-small.bin`，**不会出现在列表里**，本来就不是给培训师逛的入口。 |
| 添加字幕没反应 | 两条路：①「生成字幕」灰掉，自动识别走不通；②「悬停以在时间轴上添加」要「显示」打开且在字幕轨上悬停点一下。第一张截图「显示」是关的，悬停添加会被关掉。 |
| 动画英文 | 选项写死在 `CAPTION_ANIMATION_OPTIONS`（Off/Fade/…）。`zh-CN` 里已有「关闭 / 淡入淡出 / 上移 / 弹出」，当时没接上。 |

另外：beta.4 虽把模型打进 Portable，**界面仍留了下载/选择**。捆绑探测失败时，用户看起来和没打包一样。旧 zip（beta.1/2/3）根本没有捆绑探测。

## 3. 用户要的界面（已按此改产品）

字幕面板只留：

- 语言
- **清除字幕**、**生成字幕**（生成不再因「没选手选模型」变灰）
- 样式（动画中文、颜色、字体等）

不要：「下载模型」「选择模型」「删除模型」「已内置识别模型」占位。

模型默认用安装包 / Portable 里的 `ggml-small.bin`，用户不用选。

## 4. 操作方式变更提示

原先：先下载或手选 `.bin`，生成才亮。  
现在：打开字幕面板即可生成；手选/下载入口去掉。请用 **`1.4.0-beta.4` 之后重新打的包**，或开发态热更新后的界面；旧 zip 仍是老按钮。
