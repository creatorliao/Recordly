## 一、角色 / 金路径 / 为什么改 / G / 范围

| 项 | 钉死 |
|----|------|
| 角色 | 培训师，录 **Windows 软件操作** 给学员看 |
| 金路径（动词，不变） | **启动录制 → 停止 → 编辑 → 导出视频** |
| 为什么改 | 现在要先开软件、再点工具栏、再点录。课目录已经在资源管理器里了，希望右键就能进对的那一间房，或直接开录 |
| G1 | 录→停→编→导无阻断；右键能进工具栏或编辑器 |
| G2 | 少一次「先开 Recorly 再找录制」；录完到导出仍 ≤15 分钟 |
| G3 | 本夹不改字幕/配音 |
| G4 | 右键项少而稳；不堆 Win11 COM DLL；默认符合资源管理器 / VS Code / 7-Zip 习惯 |
| 范围 | **仅 Windows**。语言 zh-CN + en。`dev-creator`。不代合上游 |

通用做法仍可复用到别的内部客户端（换 exe 名和文案）。Recordly 落地必须带**录制动词**，不能只抄 VS Code 的「打开路径」。

## 二、后说覆盖（按时间，后者为准）

1. **开关在设置里，不在安装向导里当唯一入口。** 配置打开后，资源管理器右键才出现对应按钮；关掉立刻消失。安装包可以预勾设置，但不能「装完写死、设置改不了」。
2. **右键不只「用应用打开」。** 培训师有两种合法意图：  
   - **马上启动录制**（拉起录制工具栏并开始录）；  
   - **打开对应窗口**（录制工具栏待命，或编辑器打开项目/文件）。
3. **两间房跟 `R20260906-14` 一致**：录制工具栏 / 编辑器。右键是第三条进门，不另造第三间房。
4. **资源管理器给的是文件/文件夹路径，不是「正在讲的那个软件窗口」。** 第一期「开始录制」用**上次采集源 + 上次麦克风**（没有则默认显示器），路径只当项目/保存位置。不要假装右键能指定「录这个 exe」。
5. VS Code **只借鉴**：注册表形状、`%1`/`%V`、卸载删键、单实例把 argv 交给已开进程。不借鉴：安装器默认不勾、应用内没有开关、永远只有一个「Open with Code」。

## 三、你点名的场景（培训师一天）

### 场景 A · 课文件夹已经打开，马上开录

资源管理器停在「课01」文件夹（或空白处）→ 右键 → **Recordly → 开始录制** → 录制工具栏出现并开录（倒计时跟设置走）→ 讲完停止 → 进编辑器。

失败样子：只打开了空壳还要再点一次大红钮；或弹出第二份 Recordly 各录各的。

### 场景 B · 只要工具栏，先选源再录

右键 → **打开录制工具栏** → 条出来、**不要自动开录** → 人选窗口/区域/摄像头 → 再点录。

失败样子：和「开始录制」做成同一个按钮，来不及选源就录进桌面。

### 场景 C · 打开对应窗口（编辑器 / 项目）

- 对着 `课01.recordly` → **用 Recordly 打开** → 进编辑器该项目。  
- 对着导出的 `课01.mp4` → 走已有「打开视频」路径。  
- 对着课文件夹 → 进编辑器：夹内最近 `.recordly` 优先，否则空态并把该目录当作默认打开/保存位置。

失败样子：右键开了应用却丢了路径，还要再「打开文件」。

### 场景 D · 设置开关

设置 → Windows 集成（或常规）→ **在资源管理器右键菜单中显示 Recordly** = 开 → 立刻能看见菜单项（必要时刷新资源管理器）。关掉 → 项消失。Portable 与安装版同一套开关，都只写 **HKCU**。

失败样子：只有安装向导能勾；装完改不了；Portable 要管理员写 HKLM。

### 场景 E · 已经开着 Recordly

再右键「开始录制」：把已有实例拉到前台并执行该动词，**不**再起一个进程。若已经在录：只聚焦工具栏，不开第二路采集。

### 场景 F · 卸干净

安装版卸载、或设置关掉、或 Portable 关掉开关：注册表键删掉，右键不再留空项。

## 四、成功 / 失败

| 成功 | 失败 |
|------|------|
| 设置打开后，右键出现「开始录制 / 打开录制工具栏 / 用 Recordly 打开」 | 设置开了菜单没有；或只有「打开」没有开录 |
| 「开始录制」拉起工具栏并开录；「打开录制工具栏」只拉条 | 两个按钮行为一样 |
| 「用 Recordly 打开」带上路径进编辑器 | 只启动、路径丢了 |
| 已开实例走 `second-instance` | 双进程两套状态 |
| 关设置 / 卸载后菜单消失 | 卸了还留空项 |
| Portable 只写 HKCU | Portable 写 HKLM、要管理员 |

**不做（第一期）**

- Win11 精简菜单最外层的 IExplorerCommand COM DLL（`vscode-explorer-command`）。Win11 走「显示更多选项」。  
- 对着文件假装「录这个窗口」。  
- 为 Linux / macOS 做同类。  
- 右键里再塞导出、字幕、摄像头开关。
