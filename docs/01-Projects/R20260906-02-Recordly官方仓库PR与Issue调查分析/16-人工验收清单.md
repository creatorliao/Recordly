## 一、建议你怎么走查（顺序不要倒）

1. **对账（5 分钟，不开软件）**  
   打开 `15` §三：结果是「已合」的，才进入下面验收。  
   「暂缓/跳过」的记免验，点开对应 `S-xx` 看过不去的原因即可。
2. **小改动合并抽查（A-S）**  
   一次启动里顺手点完，不必每个 PR 重开软件。
3. **金路径总冒烟（A-G）**  
   走完整条录→停→编→导。这一条覆盖「本轮所有已合 PR 的回归」，关联列写本轮已合编号。
4. **大项专项（A-803 / A-785 / A-796）**  
   只对「已合」的做；没合的免验。
5. **轨道 B（A-B）**  
   仅当你说「开始做 B」且打出过安装包之后。关联：身份提交 `a2e32fa1`，不是社区 PR。
6. 每条在「结果」列写：`通过` / `不通过（现象：…）` / `免验`。  
   不通过的：把现象补进 `14` §三或新开 `15`（若要 revert），**不要只写在聊天里**。

**通过的总原则**：金路径没断；默认操作还在；新入口找得到；手册（若改过）和屏幕对得上。
