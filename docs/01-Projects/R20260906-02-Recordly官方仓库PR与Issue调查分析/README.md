## 一、结论速览

1. **社区提交很活跃**：目前有 **46+ 个 open PR**，绝大多数来自社区贡献者（非作者本人）。
2. **维护者速度极快，社区 PR 容易过期**：作者 `webadderall` 合自己 PR 往往几分钟到几小时，`main` 长期领先社区 PR，导致大量社区 PR 处于 `DIRTY`（需 rebase）或 `UNSTABLE`（CI 失败）状态。
3. **最值得立即合并的是「文档修复」类**：扩展系统已在 8/28 被整体移除，但 README/EXTENSIONS.md 仍在宣传已下线的 marketplace（`marketplace.recordly.dev` 返回 Cloudflare 525），这制造了一大堆重复 issue。
4. **音频问题是最需要关注的质量重灾区**：长录制崩溃、暂停后音画漂移、导出无音频等，横跨三平台。
5. **存在「Slop」标签**：维护者用 `Slop`（红色）标记疑似 AI 生成 / 低质量的 PR，这类 PR 需严格审查，不要轻易合并。

## 六、风险与观察

1. **社区 PR 时效性差**：维护者合自己 PR 极快，社区 PR 普遍 `DIRTY`/`UNSTABLE`。若你是维护者，合并社区 PR 前需帮对方 rebase 到最新 `main` 并重跑 CI。
2. **Slop 标签**：项目爆火后涌入疑似 AI 生成的垃圾 PR，维护者用 `Slop` 标记。合并任何带 `Slop` 的 PR 都要逐行审查，建议只看 `Checked`（已检查）标签的。
3. **扩展系统生死未定**：已从代码移除但文档未同步，这是当前 issue 洪水的最大来源，应尽快明确「永久移除 vs 临时下线」并同步文档。
4. **Mac 版发布滞后**：多个已修复的 macOS 关键问题（如 #821 录制崩溃）修复已在 `main` 但未切 Mac 版发布，macOS 用户会持续报已修复的问题。

## 七、给「作为用户」的你的实用提示

1. **别被 marketplace 报错困扰**：扩展商店打不开是服务端/功能下线问题，不是你的问题，忽略即可。
2. **长录制谨慎**：目前长录制（尤其 macOS）有崩溃/音频丢失风险，培训录课时建议**分段录制**（每段 15–20 分钟），或录制完先确认音频完整再离开。
3. **中文界面小瑕疵**：简体中文 locale 标签有已知小 bug（#823 已提修复），不影响主要使用。
4. **关注版本更新**：音频、导出、HUD 遮挡这些高频 bug 修复都很快落地到 `main`，建议关注 Release 及时更新。
