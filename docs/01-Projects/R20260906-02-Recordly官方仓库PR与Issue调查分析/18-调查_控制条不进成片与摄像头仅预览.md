## 1. 控制条：已经有，而且默认就是你要的

| 项 | 位置 | 代码 |
|----|------|------|
| **从录制中隐藏 HUD** | 启动窗三点菜单，眼睛带斜杠且高亮 = 开 | `MorePopover` → `setHudOverlayCaptureProtection` → `BrowserWindow.setContentProtection(true)` |
| 默认 | 开（`hudOverlayHiddenFromCapture = true`） | `electron/windows.ts` |
| 记住 | `%APPDATA%\Electron\hud-overlay-settings.json` 的 `hiddenFromCapture` | 点成「在录制中显示 HUD」会写盘，下次仍关着 |

开着时：控制条（以及同窗口里的悬浮头像）按设计 **不进主视频**。  
你录的时候仍能看见、能点暂停/停止。这正是「自己看、不成片」。

**不要和「−」搞混：** 减号只是把条从眼前收起来（`hideHud`），不是排除采集。

**判定：** 需求 ① 已满足 → **不改。**

若保护开着新录主视频里仍有控制条，那是采集没认排除（`17` §五），不是缺开关。

## 2. 摄像头：现有选项管的是什么

启动窗摄像头弹出层（`WebcamPopover`）：

| 选项 | 实际作用 | 管不管成片 |
|------|----------|------------|
| 选一个摄像头 / **关闭摄像头** | 开：录旁路 + 可显示取景器。关：两边都没有 | 关了则成片也不会自动贴（没有旁路） |
| **显示 / 隐藏悬浮预览** | 只控制 **你屏幕上** 那扇取景小窗。默认显示 | **不管成片。** 藏预览 ≠ 不成片；显示预览 ≠ 一定烧进主视频（主视频仍看 HUD 保护） |

文案「启用摄像头叠加 / 禁用摄像头叠加」说的是 **开不开摄像头这条链路**，不是「成片贴不贴」。容易误解。

Studio 右侧 **摄像头 → 显示**（`effects.show`）：

| 行为 | 代码 |
|------|------|
| 刚录完若有旁路，**自动打开**叠加 | `useInitialEditorSource`：`enabled: Boolean(session.webcamPath)` |
| 关掉「显示」后，预览和导出都不贴头像 | `VideoPlayback` / 导出都看 `webcam.enabled` |
| 偏好里默认 `enabled: false` | `DEFAULT_WEBCAM_OVERLAY`；被上面「有旁路就打开」覆盖 |

所以：**成片贴不贴，现成开关在编辑器，不在录制条。**  
没有「录的时候只监视器、永远不要旁路 / 永远不要自动贴」的单独项。

## 3. 用现有功能达到你要的组合（先这样做）

目标：录时看见自己 + 控制条和头像都不进成片。

1. 三点菜单：**从录制中隐藏 HUD**（开）。  
2. 摄像头：选设备，**显示悬浮预览**（开）——录时能看见自己。  
3. 停录进 Studio → 右侧 **摄像头 →「显示」关掉** → 再导出。

这样：

- 主视频：无控制条、无取景器（保护生效时）。  
- 成片：不贴头像。  
- 旁路文件可能仍在磁盘上，只是不合成进去。

每录完要关一次「显示」。没有「下次默认也不贴」的录制偏好。

## 4. 缺的是哪一块（若将来要加）

缺的不是控制条开关，而是：

> **录制偏好：摄像头仅作取景，不成片（不自动打开编辑器叠加；可选不写旁路）。**

| 方案 | 行数感 | 和现体验关系 | 本轮 |
|------|--------|--------------|------|
| A. 不改。手册写清 §三 三步 | 0 | 老路径不变 | **采用** |
| B. 编辑器记住「显示=关」，有旁路也不自动打开 | 小 | 默认仍可贴，只改「你关过一次」的记忆 | 你点头再做 |
| C. 启动窗加「仅预览，不成片」 | 中 | 新开关，默认关，避免老用户困惑 | 六问要过；你点头再做 |

C 才是「功能增强」。按工作法：默认可选、不改金路径。  
培训师「自己要对着镜头看口型、课件里不要大头」是合理诉求，但 **现有编辑器开关已能做到**，不是金路径断裂。

**判定：** 需求 ② 用现成选项能凑齐 → **不加功能。** 你已确认不必做 B/C。

## 6. 怎么验（不改代码）

1. 三点菜单是「从录制中隐藏 HUD」。  
2. 开摄像头 + 悬浮预览，录 20 秒（动一下鼠标方便对时间）。

4. 导出：成片无控制条、无头像。  
5. 若第 2 步主视频里已经有控制条或取景器 → 记 `14` T13，属采集排除失败，不是缺选项。
