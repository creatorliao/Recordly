## 变更 2 · 裁剪精度 1% → 0.1%（来自 PR #837）

| 维度 | 记录 |
|------|------|
| **① 修改了哪些内容** | `src/components/video-editor/SettingsPanel.tsx` 中裁剪（crop）相关的 4 个计算变量 + 4 个裁剪滑块 |
| **② 是怎么修改的** | ① 计算：`Math.round(crop.x * 100)` → `Math.round(crop.x * 1000) / 10`（top/left/bottom/right 共 4 处，保留 1 位小数）；② 滑块：`step={1}` → `step={0.1}`（4 处）；③ 显示：`formatValue` 由 `` `${Math.round(v)}%` `` 改为 `` `${(Math.round(v * 10) / 10).toFixed(1)}%` `` |
| **③ 有什么作用** | 裁剪步进从 1% 细化到 0.1%，能更精确地裁掉画面多余边缘 |
| **④ 对工作流的影响** | 裁剪滑块变细、可微调；纯数值精度变化，不影响导出管线、不影响已保存的 `.recordly` 项目（仍是 0–50 范围） |

- 提交：`10596ded`（与变更 1 同一次提交）
