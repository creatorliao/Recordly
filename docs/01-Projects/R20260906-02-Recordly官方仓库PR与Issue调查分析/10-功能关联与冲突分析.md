## 四、冲突 / 互斥（⚠️ 需你逐条拍板）

### 4.1 扩展系统已被移除（commit `0ce07b26`）——依赖扩展的 PR 全部失效

- **#694**（按键叠加「作为内置扩展」）→ 依赖扩展系统，现已不可用
- **#884**（marketplace 故障处理）→ 修复一个已不存在的功能

> **结论**：这两个 PR 现在合了也没意义，除非扩展系统回归。**建议直接关闭**。

### 4.2 「有了 CUDA 导出，就没了 Lightning/CPU 导出」——#794

- #794 GPU 加速导出（+25k 行）重写导出链路，合并后现有 Lightning/CPU 导出路径可能被替换
- 与 #769/#670（渲染后端修复）**冲突**（动同一块）
- 无 N 卡用户可能失去可用导出

> **已定**：不采用。真要 GPU 由你手工重做，且须双引擎或明确放弃 CPU。

### 4.3 「有了 Linux 原生 X11 捕获，就没了浏览器捕获兜底」——#842

- #842 用 FFmpeg x11grab 原生捕获替换 Linux 浏览器捕获
- 合并后浏览器捕获 fallback 可能被替换，Wayland 用户可能受影响
- 且 #842 标 Slop

> **已定**：不做（Linux，超出范围）。

### 4.4 「有了内联追加录制，就没了独立文件录制」——#689

- #689 改为内联追加录制，可能改变「每次录制一个独立文件」的现有行为
- 冷门，改动大

> **已定**：可共存。默认仍是独立文件；可选「继续录制（追加）」将来按此重做，不原样采用 #689。
