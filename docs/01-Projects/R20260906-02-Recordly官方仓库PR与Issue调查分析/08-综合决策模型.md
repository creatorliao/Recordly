# 08 · 综合决策模型（风险 · 效能 · 目标贡献）

> 公式仍有效。表中 #570/#769 等非 Windows 项 **不执行**。队列见 [`12`](12-综合完善方案.md)。

> 把「功能完善、不过度设计、体验良好、风险优先（低风险优先）」四条原则，落成一个可打分的决策模型。
> 每一个 PR 都打三个分，算出综合分，按分排序执行，**不凭感觉**。

---

## 一、三维评分（各 1–5 分，5 分最好）

### 风险 R（权重 40%，低风险优先）

| 分 | 标准 |
|----|------|
| 5 | 改动 ≤50 行，纯文案/配置/单文件，不碰核心链路 |
| 4 | ≤200 行，单模块，有测试或 CI 通过 |
| 3 | ≤500 行，涉及核心但局部，CI 通过 |
| 2 | >500 行，动核心链路，或 CI 失败(DIRTY/UNSTABLE) |
| 1 | >2000 行，或带 Slop，或无测试，高危 |

### 目标贡献 C（权重 35%，对齐培训师目标）

| 分 | 标准 |
|----|------|
| 5 | 直接服务 G1（路径可用）/ G3（字幕配音） |
| 4 | 服务 G2（省剪辑）/ G4（体验）明显 |
| 3 | 间接服务目标 |
| 2 | 弱相关 |
| 1 | 无关 |

### 效能 E（权重 25%，效果好）

| 分 | 标准 |
|----|------|
| 5 | 解决高频核心痛点，受益所有用户，提升显著 |
| 4 | 解决明显痛点，受益大部分用户 |
| 3 | 解决特定场景问题，受益部分用户 |
| 2 | 边际改善 |
| 1 | 几乎无感知 / 冷门 |

### 综合分

```
S = 0.40×R + 0.35×C + 0.25×E
```

### 决策阈值

| S 区间 | 动作 |
|--------|------|
| **S ≥ 4.0** | ✅ 立即合并（低垂果实 + 高价值低风险） |
| **3.0 ≤ S < 4.0** | 👀 审阅后合并 |
| **2.0 ≤ S < 3.0** | ⏸ 按需 |
| **S < 2.0** | ❌ 不合并 |

## 四、评分原则速记（决策时用）

1. **低风险优先**：R 权重最高（40%），改动越小分越高。
2. **贡献导向**：C 权重 35%，落不进 G1–G4 的 PR 直接出局。
3. **效果说话**：E 权重 25%，解决高频痛点 > 冷门功能。
4. **不过度设计**：改动 >500 行 R 分骤降，>2000 行基本判死。
5. **低垂果实 = 高 R + 高 E + 简单**，天然排最前。
6. **执行分工**：AI 只做小改动（≤500 行、低风险）；大而冒险的 PR（#794/#676/#438/#426/#712/#777/#733 等）由开发者手工逐一操控。
7. **语言范围**：只做简体中文 + 英文，不做其它语种。
