
唯一需要你开口的仍是：**「开始做轨道 A」或「开始做轨道 B」**。  
过程选择题一律用 [`14` §二](14-待确认代决策与待检验.md) 的代决策。

### 10.2 确认怎么发生（避免聊天里零碎问）

| 类型 | 做法 |
|------|------|
| 还能代决的 | 我先定，写入 `14` §二，你以后逐条「同意/改判」 |
| 特别困惑、必须人眼/真机 | 写入 `14` §三，不阻塞 |
| 过不去且能代决成「暂缓」 | **先记 [`15`](15-执行中暂缓与跳过.md)**，再跳下一条 |
| 连续两条金路径都 revert | 先记 `15`，再暂停，并在 `14` §三置顶「请先看」（D11） |

### 10.3 自动化做不到、故意留给你的

真麦 3 分钟（T1）、HUD 点边角（T4）、监控拦截（T3）、金路径手摸一遍（T10）。方案不把这些写成「AI 已冒烟通过」。
