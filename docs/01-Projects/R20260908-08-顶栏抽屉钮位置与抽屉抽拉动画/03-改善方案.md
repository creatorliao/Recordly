## S2 · 抽拉动画（`EditorSidebar.tsx`）

目标结构：

```text
[ 左轨 48 固定 ]
[ 抽屉轨道 overflow-hidden ]
   [ 面板宽 280；animate width 或 x ]
```

推荐规格：

- 时长 **200ms**，曲线接近 VS Code / Fluent（`ease-out` 或 motion `[0.22, 1, 0.36, 1]`）。  
- 打开：宽 0→280（内容从左露出）。  
- 关闭：宽 280→0。  
- 进行中可再次点击打断（motion 默认可）。  
- 关闭结束后：`aria-hidden`、不响应指针；**不要**在动画中途把预览 layout 抖两次。

依赖：项目已有 `motion/react`（左轨图标在用）。

明确不做：整页遮罩、从右侧飞入、弹跳 overshoot。
