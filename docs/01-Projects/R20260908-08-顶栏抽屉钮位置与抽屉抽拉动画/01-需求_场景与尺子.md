# 需求：抽屉钮位置 + 抽拉动画

## 角色与范围

| 项 | 内容 |
|----|------|
| 角色 | 培训师，Windows 编辑器里开关左侧控制抽屉 |
| 金路径 | 录 → 停 → **编** → 导 |
| G | **G4**（铬件位置像常见 IDE；动效不吓人） |
| 非目标 | 不改左轨 48px 图标逻辑；不改抽屉里业务控件；不为 mac 单独开功能（可顺带不崩） |

## 用户原话

1. 工具栏（菜单行）里放这个图标有点怪。  
2. 希望作为**独立按钮**放在**外面、项目顶部**，大小与**项目/应用图标**差不多，风格一致。  
3. 点击开合要有动画：像抽屉从左往右抽出、从右往左收起；不要突然「嘣」出来。

证据：[附图-01](附图-01-菜单栏内抽屉钮.png)（红框：文件左侧的侧栏图标）。

## 成功 / 失败

| 成功 | 失败 |
|------|------|
| 钮不再像「文件/编辑」的菜单项；一眼是窗口级开关 | 仍夹在菜单文字中间，或又挤回导出旁 |
| 体量与顶栏铬件协调（约与标题栏图标同级视觉重量） | 15px 弱图标或巨大突兀块 |
| 开合有约 150–250ms 宽度/位移过渡，可打断 | 仍是 `null` 硬切，内容闪一下 |
| 左轨点图标开/关、顶栏钮开/关一致 | 动画后状态与高亮错乱 |

## 非目标

- 不重做整窗自定义标题栏（除非拍板选「重方案」）。  
- 不做弹簧乱晃、不做遮罩模态抽屉。  
- 不改摄像头/字幕面板内容。
