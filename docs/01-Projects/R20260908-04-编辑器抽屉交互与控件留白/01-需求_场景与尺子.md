# 需求：抽屉交互与控件留白

## 角色与范围

| 项 | 内容 |
|----|------|
| 角色 | 培训师，Windows 上录完进编辑器成片 |
| 金路径 | 录 → 停 → 编 → 导 |
| G | **G4** 为主；抽屉关了不能挡预览效果（G1） |
| 非目标 | 不改录制/导出/字幕算法；不新开右侧属性栏 |

## 用户原话

1. 滑动条的文字和滑动条重叠。  
2. 控制面板文字大小不一致，下拉列表里文字突然变大。  
3. 右边预留了一大片空白，浪费空间。  
4. 时间线左右边缘不够优雅，甚至文字重叠；重新思考留白。  
5. 控制面板不够简洁：下拉叠阴影、整体高度太高。  
6. 播放区与各边缘留白：要跟其它元素黏连，用分割线区分，空间用满。  
7. 全面审查布局与交互，尤其抽屉和面板：  
   1. 抽屉关上之后，面板怎么也看不到效果，逻辑要重梳。  
   2. 抽屉按钮不该在右上角——它代表并控制的是左边面板。

## 成功 / 失败

| 成功 | 失败 |
|------|------|
| 滑条标签、轨、值三列不互相压字 | 中文长标签或 `30px` 仍压在轨上 |
| 触发器与下拉项同一字号（推荐 12px） | 关上 `text-xs`、打开 `text-sm` |
| 窗口右缘没有「空面板」；底栏在内容列底或通窗底 | 底栏当第三列，右边一大块白 |
| 标尺末刻度与折叠钮不叠；轨左右各约 8px **画布内**边，不是窗口空列 | 再挖 12px 窗口沟，或 0:08 被箭头挡住 |
| 点左轨图标必打开对应抽屉；关抽屉只藏板，预览效果仍在 | 关抽屉后再点图标毫无反应 |
| 开关抽屉的入口在左边（左轨） | 开关仍挨着「导出」 |

对照：VS Code（活动栏管左边栏）、剪映（预览/轨贴分割线、下拉无重影）。
