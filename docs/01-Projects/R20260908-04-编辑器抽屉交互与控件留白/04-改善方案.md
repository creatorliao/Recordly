## 目标结构（唯一）

```text
┌─ Header（文件旁：抽屉开关；右：画幅/裁剪/蓝底导出）─┐
│                                                    │
├─ 48px 通高 ─┬─ 抽屉 280（可无）─┬─ 预览（px-0）────┤
│ 点图标开板   │                  │ 1px 缝            │
│ 再点当前=关  │                  ├─ 运输条            │
│ 齿轮同逻辑   │                  └─ 时间轴（内边 8px）│
├──────────────┴──────────────────┴───────────────────┤
```

主行**只有两段**：`[左轨 | 抽屉?] + 内容列`。禁止 footer 再当第三列。  
底栏在**整窗最底**（后说修订：仅钉内容列底时左轨贴任务栏无收口，观感断）。

## S1 · 滑条不叠字（D1 · `SliderControl.tsx`）

现在：`grid-cols-[72px_1fr_44px]`，轨 `absolute left-[74px] right-[46px]` 相对整行。

改为：

```text
grid-cols-[88px_minmax(0,1fr)_52px]  gap-2  h-7
[ 标签 11px 截断 ] [ 相对定位的扁轨 高 4px ] [ 值 11px 右对齐 ]
```

- 轨、拇指的 `left/%` **只相对中间格**（中间格 `relative`），禁止相对整行 absolute。  
- 标签 `truncate`，`title` 给全文。值 `tabular-nums`，列宽 52 够 `100%` / `30px` / `350ms`。  
- 无胶囊、无投影、无槽内标签。

验收：字幕页「字号 / 行数 / 底部偏移 / 最大宽度 / 字幕框圆角 / 背景透明度」拉 0 与拉满，字与轨分离。

## S2 + S5 · 下拉字号与密度（D2、D5）

只动**编辑器抽屉内**的 Select（`SettingsPanel` 等），不改 Launch 全局默认，除非同一文件被迫共用。

| 件 | 锁定 |
|----|------|
| Trigger | `h-7`（28px）、`text-[12px]`、`rounded-[2px]`、无 ring 外发光 |
| Item | `text-[12px] font-medium`、`h-7`、`py-0` |
| Content | **无** `shadow-md`；`border` 1px；`rounded-[2px]` |
| 章节 | `space-y-2`（8px），不要 `space-y-4` 当默认 |
| 双按钮 | 「清除字幕 / 重新生成」高 28、半径 2 |

验收：打开「动画」「字体」，项与关上的字一样大；弹出层无投影。

## S3 · 底栏归位（D3 · `EditorShell.tsx`）

现在：`flex` 行 = 侧栏 + 内容列 + `footer`。

改为：

```text
div.flex.min-h-0.flex-1.flex-col
  div.flex.min-h-0.flex-1          // 行：只有侧栏 + 内容列
    EditorSidebar
    div.flex.flex-1.flex-col.min-w-0
      Preview
      Timeline
  footer.h-[22px].w-full.shrink-0 // 通窗底，仿 VS Code
```

左轨落在底栏之上（不再插进任务栏）。底栏 `border-t` 形成窗口下边界。  
**不**用窗口外圈留白去「画框」——那会浪费预览高度。

验收：拉宽窗口，右缘无空列；底栏横贯全窗；「已保存」在最底一行。

## S4 · 时间轴内边与折叠（D4 · 轨 + 标尺 + seek）

新增常量（建议 `timelineLayout.ts`）：

```text
TIMELINE_CANVAS_PAD_X_PX = 8
```

标尺、色块、播头、点击换算**共用**这 8px。`contentWidth = rect.width - 2*8`（若仍有 dnd `sidebarWidth` 再减）。折叠钮放在**右内边之内**，或标尺行右侧固定 16px 槽，不得压最后一刻度。

窗口 / 内容列 **不再** `pr-3`。

验收：片尾 `0:xx` 与箭头同时能读、能点；seek 点内边内侧应对准该时刻。

## S7 · 抽屉逻辑（D7 · `EditorSidebar` + 一点 UI state）

点左轨图标（含齿轮）：

1. 若抽屉关 → `setSettingsPanelVisible(true)` + `setActiveSection(id)`。  
2. 若抽屉开且点的是**当前** section → `setSettingsPanelVisible(false)`（section 可保持，便于再开还在这页）。  
3. 若抽屉开且点的是**另一** section → 只切页，保持开。

预览外观（光标、字幕、裁剪）不依赖抽屉是否挂载。

验收：关抽屉后成片效果仍在；再点「字幕」板立刻出现；再点一次「字幕」板关。
