# 调查：现状与根因

调查日：2026-09-08。只读。未改产品代码。

## 1. 壳层

`EditorShell.tsx` 标题栏下（2026-09-08 **复验源码仍如此**；WP-A 留痕写「底栏已在内容列底」与代码不符）：

```text
div.flex.flex-1          ← 横向（没有 flex-col）
  div.flex.flex-1        ← 仍是横向
    EditorSidebar        ← 左轨 48 + 可选抽屉 280
    div.flex-1.flex-col.border-r
      Preview + Timeline
    footer.h-[22px]      ← 与上两者并列，成为右列
```

底栏本应在窗口底或内容列底。现状是第三列，这是 PR-03 / 附图-02 / **附图-06** 的主因。  
空白顶上的「已保存 0:03 / 0:13」就是该 footer 的文案：列被拉通高后，22px 条贴在列顶。详见 [`06-调查_右侧空列与状态栏错位.md`](06-调查_右侧空列与状态栏错位.md)。

内容列有 `gap-1`、`border-r`。预览内部仍有 `px-1`（PR-06）。

## 2. 抽屉显隐

| 件 | 行为 |
|----|------|
| `settingsPanelVisible` 默认 true | `useEditorUiState` |
| 顶栏 `SidebarSimple` | 只翻转 visible |
| 左轨图标 | 只 `setActiveSection`，**不**开抽屉 |
| 抽屉关闭时 | `settingsPanelVisible ? … : null`，整板卸掉 |
| 再打开 | 仅顶栏钮，或空项目回调 |

因此关抽屉后点「字幕」：section 变了，板不出现 → PR-07。

## 3. 滑条

`SliderControl.tsx`：`grid-cols-[72px_minmax(0,1fr)_44px]`；轨/拇指 `absolute` 按整行算 `left-[74px] right-[46px]`。  
中文标签常 >72px；`30px` 常 >44px。字和轨叠在同一 y（PR-01、附图-04）。

## 4. 下拉

| 层 | 字号 / 皮 |
|----|-----------|
| Trigger（字幕动画） | 调用处 `text-xs` `h-7` |
| Trigger（字体） | `text-xs` `h-8` `rounded-md` |
| Trigger 默认组件 | `h-10` `text-sm` `rounded-md` |
| Item 默认 | `text-sm` `py-1.5` |
| Content 默认 | `shadow-md` `rounded-md` |

Portal 弹出不继承抽屉字号 → PR-02。阴影 → PR-05。

## 5. 时间轴右上

`EditorTimelinePanel` 折叠：`absolute right-1 top-0`，与标尺最后一刻度同槽 → 附图-03 `0:08` 被箭头挡住（PR-04）。

## 6. 顶栏钮

`EditorHeader` 右簇末项：`onToggleSettingsPanel` + `SidebarSimple`，紧挨导出（PR-08、附图-05）。
