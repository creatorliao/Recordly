# 调查：右侧空白 + 空白顶上的时间

调查日：2026-09-08。对照用户新截图（[附图-06](附图-06-右侧空列与顶上时间.png)）与当前 `EditorShell.tsx`。  
角色：培训师 · 金路径：录 → 停 → 编 → 导 · G4（把预览/时间轴空间用满）。

## 用户两问

1. 右侧为什么会有空白？
2. 空白上面为什么会有时间？是不是把状态栏位置搞错、把状态栏样式搞崩了？

## 结论（先说）

**位置搞错了，样式没有崩。**

「已保存 0:03 / 0:13」仍是原来的 22px 底栏（保存态 + 当前时刻/片长）。它被放进了**标题栏下方那一行横向 flex 的第三列**，所以：

- 右边多出一整列通高白底（像空侧栏）
- 底栏自己只有 22px 高，文字贴在这列**最顶端**
- 预览和时间轴吃不到这列宽度

不是另做了一个右栏，也不是状态栏 CSS 把字号/高度写坏。  
`09` 里 WP-A 曾写「底栏已在内容列底」，**与源码不符**：footer 仍是主行兄弟节点。

## 证据：当前 DOM（只读时的结构）

`src/components/video-editor/layout/EditorShell.tsx` 标题栏下：

```text
div.flex.flex-1          ← 横向（默认 flex-row）
  div.flex.flex-1        ← 仍是横向
    EditorSidebar        ← 左轨 48 + 可选抽屉
    div.flex-1.flex-col.border-r
      Preview            ← 预览 + 运输条（音量）
      Timeline           ← 时间轴
    footer.h-[22px]      ← 与上两者并列 = 第三列
      「已保存」 | 「0:03 / 0:13」
```

对应源码位置：主行约 307–392 行。`footer` 在内容列 `</div>` **之后**，与 `EditorSidebar`、内容列同级。

内容列上的 `border-r` 就是截图里那条竖分割线。线右边整列白底属于第三列占位，不是预览的 padding。

## 问 1：右侧空白从哪来

| 猜测 | 是否成立 | 依据 |
|------|----------|------|
| 故意预留右侧属性栏 | 否 | 需求非目标写明不新开右栏；右列没有 Settings / 属性组件 |
| 03 夹的 12px 窗口右沟没挖够 | 否 | 内容列已无 `pr-3`；空的是**整列**，不是 12px |
| 抽屉关了留下空壳 | 否 | 抽屉在**左边**；`settingsPanelVisible === false` 时整板不挂载 |
| 预览按画幅收窄、右边信箱 | 否 | 信箱应在预览框内；截图竖线在音量/时间轴右侧，线外无轨 |
| **底栏当了第三列** | **是** | footer 与侧栏、内容列横向并列；内容列 `flex-1` 只吃「减去第三列之后」的宽 |

第三列为啥看起来「那么宽、那么空」：

1. 父级是横向 flex，默认交叉轴 `stretch`：给第三项留了**整窗高**的槽。
2. footer 写了 `h-[22px]`，自己只高 22px，槽里其余全是父级 `bg-editor-bg` 白底。
3. footer 有 `shrink-0`、没有 `w-auto`/`self-start` 收窄到文案；作为带 `justify-between` 的 flex 项，主轴上会占住一块稳定列宽（再叠加通高白底），看起来像空面板。
4. 预览/时间轴拿不到这列像素，空间被浪费。

## 问 2：空白顶上的时间是什么

文案来自同一 `footer`，不是预览时钟、不是导出进度：

```text
{已保存 | 未保存} + formatStatusTime(currentTime) + " / " + formatStatusTime(duration)
```

| 截图 | 含义 |
|------|------|
| `已保存` | `hasUnsavedChanges === false` |
| `0:03 / 0:13` | 播放头 3 秒 / 成片 13 秒 |

为啥在「上面」而不是窗口底：

- 状态栏**位置**被当成第三列，不再在内容列最底。
- 列被拉通高后，22px 的 footer 落在交叉轴**起点（顶）**。
- `justify-between` 把「已保存」和时刻分到该列左右；裁切右缘时会看成顶上一条 `已保存0:03 / 0:13`。

样式本身仍是：高 22、字 12、`text-muted-foreground`、等宽数字。**皮没崩，槽放错了。**

## 与已锁定方案的关系

`04` / D3 已锁定：footer **离开横向主行**，钉在**内容列最底**；左轨通到窗底；禁止第三列、禁止窗口右沟。

目标（只动壳层，不改录/导/字幕算法）：

```text
[ 左轨 | 抽屉? ] [ 预览 ]
               [ 运输条 ]
               [ 时间轴 ]
               [ 底栏 22px：已保存    0:03 / 0:13 ]
```

拉宽窗口后右缘不应再出现空列；时刻应在时间轴正下方。

## 非目标（本修复）

- 不新建右侧属性栏去「填满」空列（那是继续浪费主画布）。
- 不改保存/播放时间算法，只改 footer 挂载位置。
- 不把 03 夹的窗口右沟加回来。
