# 03 · 规范：编辑器专业视觉系统

> **规范真源**。所有编辑器表面的新 class / token 以本文件为准。  
> 气质：Premiere / 剪映 / OpenScreen 密度 / VS Code —— **专业、客观、密**。  
> 禁止：大圆角卡片、投影悬浮、正圆色板、隐滚动条、杂志风字距、时间轴糖渐变。

本规范覆盖 **整个编辑器页面**（顶栏、左轨、抽屉、预览、时间轴、状态栏、本页对话框）。  
**本轮实施**：B1（抽屉）+ **WP5（轨道密度）**。对话框、导出菜单、时间轴拖高、OS 的 AI 功能不在本轮。见 `04`、对照 [`06`](06-调查_时间轴与OpenScreen对照.md)。  
审查修订（滑条单行、抽屉槽瞬时、禁止双线缝）见 [`05`](05-审查_方案自审与修订.md)。

---

## 1. 原则（六条）

1. **接缝，不是岛屿。** 区域用 1px 分割线相接，不靠阴影和空隙做出层次。
2. **直角是默认，圆角是例外。** 壳层半径 0。只有「可点的小控件」和「媒体内容」允许 2–3px。
3. **密度跟桌面工具走。** 一行控件 28px；轨道效果道 24、正片 52。禁止 40px 胖滑条、禁止把两行轨道 stretch 成各 64。
4. **空间还给成片。** 左轨保持 48；抽屉统一窄边；工作区不垫 16px 空气；轨道行高固定，多出来的像素给预览。
5. **溢出必可滚，条必可见。** 细、淡、不抢；禁止 `custom-scrollbar` 藏条。
6. **一种蓝，一种灰。** 强调只用品牌蓝 `#2563EB`。不要发光、不要第二套紫高光。

## 2. Token（建议落点 `src/components/video-editor/editorTheme.css`）

沿用现有 `--editor-*` 面色和 `--brand-accent`。本夹新增的是 **半径 / 密度 / 滚动条 / 接缝**，不是换肤。

| Token | 值 | 用途 |

| `--ed-radius-media` | `3px` | 项目缩略图、壁纸/色块、**时间轴块** |

| `--ed-accent` | `#2563EB` | 选中条、激活分段、主按钮 |

| `--ed-tl-audio` | `28px` | 音频 / 源音频（给波形） |

## 3. 圆角等级（对照表）

| 元素 | 现在常见 | 规范 | 禁止 |
|------|----------|------|------|
| 抽屉外框 | `rounded-2xl` 16 | **0** | 任何 ≥8px 外轮廓 |
| 左轨选中条 | `rounded-full` 高 22 | **0**，高与图标格齐平（36） | 胶囊条 |
| 项目缩略图 | `rounded-[5px]` + 重影 | **3px**，1px 边，无悬浮投影 | hover 上浮 |
| 滑条整行 | 标签画进 40 高胶囊 | **单行** 28：标签 \| 扁轨 \| 值 | 堆成两行、圆球拇指、发光 |
| 分段控件 | 容器 12 + 激活 8 | 容器 2，激活块 2、无弹簧 | pill / layoutId 胶囊 |
| 色板 / 渐变格 | 10px 或正圆 | **3px 方**，间距 4 | `rounded-full` 色点 |
| 开关 | iOS 圆轨道 | **保留**（系统习惯，七问⑦） | 不要改成方块开关 |
| 主/次按钮 | `rounded-xl` 常见 | 2px，高 28 | 满宽大胶囊 |
| 对话框 | `rounded-2xl` | 本轮不改结构；新皮用 2px | — |
| 预览里的摄像头画面 | 成片效果，跟 `webcam.roundness` | **不改产品默认值** | 不要把成片摄像头掰成直角 |
| 时间轴效果块 / 正片块 | 半径 8 + 浅色大渐变 | **3px 实色** | 渐变糖、OS 的 11px 片段卡、发光选中 |

「不要傻圆形」指的是 **壳和色板**，不是把成片里的摄像头强制切方，也不是改系统开关。

## 4. 布局与抽屉

### 4.1 工作区接缝

```
[顶栏 30]
[左轨 48 | 抽屉 280 | 预览 1fr ]
[时间轴 ………………… ]
[状态栏 22]
```

- 工作区：`padding: 0; gap: 0`
- 上排与时间轴、左列与预览、**预览画布与运输条**：只留 `--ed-split`（预览列现有 `gap-3` 一并去掉）
- 左轨、抽屉、预览 **同高**，上顶顶栏下沿、下贴时间轴上沿
- 分割线不叠两根：左轨只描 **右边**；抽屉不描左边、只描 **右边**；预览壳半径 0、不描多余左边
- 抽屉打开时预览被向右挤（文档流，不是遮罩）。槽位宽 **瞬时** 切换，预览只重排一次

### 4.2 左轨

- 宽 48，图标 24，上下分组不变（工具在上，齿轮钉底）
- 选中：左侧 2px 直角条，高度 = 图标格（36），贴轨左缘
- 未选：透明度 0.55（已有），hover 背景用 `foreground/6` 直角，不要大圆底

### 4.3 抽屉行为

- 外壳 **只准一套**：`EditorDrawer`。项目 / 设置 / 扩展 / 注释板都是抽屉里的内容，禁止自己再套 `rounded-2xl + shadow-xl`
- 从左轨右缘抽出：槽位宽瞬时 `0 ↔ 280`；面板 `translateX(-100% → 0)`，160ms ease-out。看起来是左→右，**不要**对宽度做 160ms 插值（预览会连续重排）
- 无圆角、无投影、背景 `--editor-panel`
- 标题行 32px：左标题、右动作，底部分割线。280 宽下「项目 / 新建录制 / 导入」保持文字按钮，不改成纯图标
- 内容区：`padding: 8px`；`overflow-y: auto` + **可见细滚动条**（不用 `scrollbar-gutter: stable`）
- 左轨点 clip / zoom / audio / caption 时没有对应图标——**保持现状**（不发明假高亮）；抽屉仍显示设置内容

### 4.4 项目网格

- 2 列，格间距 8px
- 缩略图 16:10，半径 3，**1px 边**，无卡片阴影、无 hover 位移
- 文件名 12px regular，单行省略
- 「当前 / 上次」角标：直角 2px，不要全大写 tracking

## 5. 控件配方

### 5.1 滑条（属性行，Premiere 单行）

```
[ 模糊          ] [===========|----] [ 3.5px ]
  标签 72        轨 flex-1           值 44
```

- **一行**高 28。禁止「标签在上、轨在下」——那会比现在的 40 还高，更胖
- 不要把标签画进轨里当胶囊
- 轨高 3px，半径 2；拇指 6×12 竖条，半径 1，**无光晕、无 scale、无紫 accent**
- 填充 `foreground/12`；蓝只给拇指/焦点
- 标签 12px，值 12px tabular，右对齐

### 5.2 分段（图片 / 视频 / 颜色 / 渐变）

- 高 28，四等分，1px 外框，半径 2
- 激活：蓝底白字 **方块**，无 spring
- 未激活：灰字，hover 略深底

### 5.3 色板 / 壁纸

- 8 列，间隙 4px，格子正方形，半径 3
- 选中：2px 蓝框（inset），不要放大、不要圆点勾

### 5.4 区块标题

- 12px medium，**不要** 10px + `uppercase tracking-widest`
- 右侧「重置 / 高级」：12px，品牌蓝，无字距夸张

### 5.5 开关行

- 左文案 12px，右 Switch（系统圆轨道保留），行高 28
- 不要再包一层 `rounded-lg` 灰底大垫

## 6. 滚动条

新建 utility：`.editor-scrollbar`（**不要**再给抽屉挂 `.custom-scrollbar`）。

| 平台 | 规则 |
|------|------|
| WebKit | 宽/高 6px；thumb 圆角 2px；track 透明 |
| Firefox | `scrollbar-width: thin`；`scrollbar-color: thumb track` |
| 显隐 | 内容溢出即显示；不自动 hidden |
| 位置 | 贴抽屉右内缘叠加，**不用** `scrollbar-gutter: stable`（280 太窄，会吃掉色板） |

时间轴现有极细条：能共用 token，本轮不重做时间轴滚动逻辑。

## 7. 运动

| 场景 | 做 | 不做 |
|------|----|------|
| 打开抽屉 | 槽瞬时；内容 160ms `translateX` | 插值宽度、上下 fade、blur、spring |
| 切换 Tab 内容 | 可选 80ms 透明度 | `y: ±8` 跳动 |
| 滑条拖动 | 跟手，无 transition | 拇指 scale 1.15 / 1.25 |
| 项目格 hover | 边框略亮 | 上浮 + 阴影变重 |

---

## 8. 字体与文案密度

- 继续 `--app-font-sans`，不换字体
- 抽屉标题 13px medium
- 控件标签 12px；辅助说明 11px、行高 16
- 中文不用全大写字距；英文区块标题 Title Case，不用 `TRACKING-WIDEST`

## 9. 深色

同一套半径/密度/滚动条。只换已经存在的 `--editor-*` 面色。禁止深色另开圆角体系。

## 10. 对照口诀（评审时用）

问：VS Code 侧栏、Premiere 效果板、剪映时间轴、资源管理器预览窗会怎么做？  
答：直角框、1px 线、细滚动条、方色板、扁滑条；轨道正片在底、效果道瘦。  
若答案是「圆角卡片 + 投影 + 藏滚动条 + 64px 糖块」——一律不采用。

## 11. 时间轴 / 轨道

对照账：[`06`](06-调查_时间轴与OpenScreen对照.md)。学 OpenScreen 的 **行高、柄、正片钉底、块宽=时长**；不学它的 11px 圆角、藏滚动条、AI 工具。

```
[运输条 32]          ← 仍在预览正下方，与标尺贴死（一条眉，不要 gap-3）
[标尺 28]
[效果道 24] × N      ← 缩放默认在；字幕/注释有才出现
[讲解声 28] × 0–N    ← 本夹只定行高 28；默认铺几条见后续夹，不在本规范改产品默认
[正片道 52]          ← 永远在最底
```

走查补强（[`07`](07-走查_三视角完善意见与优先级.md) P0/P1）：

| 规则 | 做 | 不做 |
|------|----|------|
| 行高 | 固定 token；**删除 stretch 与 `Row` 的 `flex-1`** | 只改公式、行还在灌满 |
| 面板 | **高度随内容**：min ≈ 标尺+缩放+正片（~108），max ≈ 220（或与 15% 取大者封顶）；余量给预览 | 删 stretch 后仍 `height:15%` 留灰膛；抄 OS 默认 392 |
| 块 | 效果块 22 高、正片块吃满 52 道；半径 3；实色（缩放紫、裁切红、正片蓝、音频绿、字幕玫，饱和度降到和抽屉一个调） | 85% 行高 + 渐变 |
| 宽 | 宽 = 时长，`min-width: 1px`（正片/效果同 OS 原则） | 用 % 做最小宽 |
| 柄 | 6px；宽度 < 18px 时柄翻到块外，中间仍能拖移（几何学 OS `pillAffordance`） | `resizeHandleWidth={28}` |
| 行序 | 正片（及贴在它底下的源音频）钉底；效果在上 | 维持 Clip 在顶 |
| 标签 | **不加**左轨名列。块内 **11px 图标 + 文案**，窄了只留色/图标 | 新开 56–64px 列；9px uppercase 叠在块上 |
| 播头 | 2px 品牌蓝；头视觉 8×8，**热区 ≥12**；无光晕、无 hover scale | 菱形旋转 + glow；热区跟视觉一样小 |
| 运输条 | 高 32，钮 28 半径 2；**圆播放键保留**；去「添加图层」胶囊 | 搬到时间轴头（本轮不搬） |
| 滚动 | 行多了在轨道区纵滚；`.editor-scrollbar` **叠加不占宽**（避免标尺错位） | `display:none` 藏条；或占 16px 槽 |
| 空道 | 缩放空道保留；源音频行出现时高度 28（几行都按此） | 本夹去改「新课默认一条」——那是可见行数，进 `R20260907-03` |
| 可拖高面板 | 本轮不做（P2，进后续夹） | 先把行高和空膛做对 |

色（浅/深都用实色，不要 `linear-gradient`）：

| 种类 | 填充（浅） | 边/选中 |
|------|------------|---------|
| 正片 / 源音频 | `accent / 18` | 边 `accent / 40`，选中 2px accent |
| 缩放 | 紫 500 / 16 | 选中紫 500 |
| 裁切 | 红 500 / 16 | 选中红 500 |
| 音频 | 绿 600 / 16 | 选中绿 600 |
| 字幕 | 玫 500 / 16 | 选中玫 500 |
| 注释 / 变速 | 琥珀 600 / 16 | 选中琥珀 |
