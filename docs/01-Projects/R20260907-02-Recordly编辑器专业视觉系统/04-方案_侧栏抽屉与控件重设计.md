## 一、角色锚点（本夹）

培训师停录进编辑器 → 先看见 **项目** → 点课或点左轨去调画面 → 导出。  
本夹改「进门落点」、左侧抽屉接缝/控件皮，以及 **时间轴密度与行序**。金路径动词不变；切割/缩放算法不变。

## 三、默认 Tab（A1 · 行为钉死）

**「进入编辑器」= 编辑器 Electron 窗挂载**（`windowType === "editor"` → `EditorWindow` → `VideoEditor`）。回录制会 `switchToRecording` 关窗；再进是新挂载，又是项目。

| 时机 | 行为 |
|------|------|
| 冷启动 / 停录进编 / 从启动窗打开编辑器 | `activeEffectSection = "projects"`，抽屉开着 |
| 空工作区 `onEmptyWorkspace` | 已是项目，保持 |
| 从项目格子打开、导入、片源就绪 | **不**再切到画面；Tab 维持当前（刚进来就是项目） |
| 本会话点了画面 / 光标 / … | 停在用户点的 Tab |
| 时间轴点片段 / 缩放 / 音频 / 字幕 | **仍切**对应板（会话中上下文，不是进入） |
| 公告 `OPEN_EDITOR_SECTION_EVENT` | 仍听 |
| clip / zoom / audio / caption 无左轨图标 | 不发明假高亮 |

落地后手册补一句：打开编辑器先看到项目列表；调画面点左侧魔杖。
