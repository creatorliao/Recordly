## 一、Recordly 轨道现在长什么样

### 1.1 壳

| 件 | 源码 | 观感 |
|----|------|------|
| 面板高 | `EditorTimelinePanel`：`height: 15%`，`minHeight: 160` | 无论几条轨道，先占掉一块大底板 |
| 标尺 | `TIMELINE_AXIS_HEIGHT_PX = 32` | 略高 |
| 行最小高 | `TIMELINE_ROW_MIN_HEIGHT_PX = 28` | 名义最小；实际被拉开 |
| 行怎么长高 | `flex-1` + `getTimelineViewportStretchFactor`：`max(1, 行数/2)` 把内容区拉高 | **2 条默认行均分 ~160−32，一行约 64px** |
| 块本身 | `Item.tsx`：高 **85%** 行高，`minHeight: 22`，`border-radius: 8` | 一行里一块大糖果 |
| 浅色块 | `ItemGlass.module.css` 上下渐变（蓝/粉/紫/绿） | AI 味、和抽屉规范打架 |
| 缩放柄 | `TimelineWrapper` `resizeHandleWidth={28}` | 块中间只剩一条细缝能拖移，短块几乎只能被当成缩放 |
| 行标签 | `Row.tsx`：`text-[9px] uppercase tracking-widest` 浮在行上 | 压在片段上，杂志字距 |
| 行缝 | `marginBottom: 2` | 还行 |
| 播头 | 2px 蓝线 + **旋转 45° 方块** 16 盒 + 发光 | 抢、圆溜 |
| 运输条 | 在 `EditorPreviewPanel`：`gap-3` + **圆形**播放/剪刀/添加图层 | 和轨道之间又空 12px；`TimelineToolbar.tsx` **没有任何引用**（死代码） |
| 默认行 | 永远有 **Clip + Zoom**；字幕开了再加一行；新录制默认 `showSourceAudio: true` 可叠 **最多 3 条**源音频 | 开字幕的新课常是 **6 行** |
| dnd `sidebarWidth` | 从未 `setSidebarRef`，**实测为 0** | 没有左轨名列；9px 字叠在块上 |

关键公式（`timelineLayout.ts` + `TimelineCanvas.tsx`）：

```
stretch = max(1, rowCount / 2)
height = max(100%, minContent, 32 + (100% - 32) * stretch)
```

两行时 stretch=1，160px 面板里两行各 ~64。这是「轨道太胖」的第一因，不是 28 这个最小值。

第二因：新录制常开字幕 + 3 条源音频 → `rowCount = 6`，`stretch = 3`，内容高约 `32 + 128×3 = 416`，在 160 视口里必滚，**每一行还被公式拉高**，不是压扁。

### 1.2 不便（代码能解释的）

1. **胖**：行被 flex 撑满 15% 底板；块还吃行高的 85%。
2. **不好点**：28px 缩放热区，短缩放/字幕几乎点不到「移动」。
3. **看不清种类**：浅色渐变糖块 + 9px 全大写标签叠在块上。
4. **主片不在底**：Clip 画在最上面，Zoom / 字幕 / 注释 / 音频往下堆——和剪映、Premiere、OpenScreen 相反，培训师找「正片」要抬头。
5. **工具条重复且圆**：预览下运输条圆形按钮；时间轴自带的 `TimelineToolbar` 没挂上。
6. **和抽屉规范不一致**：半径 8、发光、渐变，刚订的 `--ed-radius-media: 3` / 禁投影对不上。

### 1.3 本夹原先口径

`01` 写过「不改时间轴剪辑语义」。那是指 **不改切割/缩放/字幕数据模型**。  
后说要求轨道也纳入视觉系统——**皮、密度、行序、热区**进本夹；切割对错、建议缩放算法 **仍不做**。

## 二、OpenScreen（应对齐的密度，不是抄功能）

真源：`src/components/ai-edition/v4/EditorShellV4.module.css`、`V4Timeline.tsx`、`audioTracks.ts`、`NewEditorShell.tsx`。

| 件 | OpenScreen | 备注 |
|----|------------|------|
| 面板 | 可拖，**min 160 / max 560**，记住高度 | 和我们 min 160 碰巧相同；他们行 **不** 被 stretch 灌满 |
| 工具条 | `.tlToolbar` **40**，钮 **28×28** 半径 6 | 播放也在时间轴头（TransportBar） |
| 标尺 | `.tlRuler` **28**，主刻 9 / 次刻 5，字 10 mono | |
| 效果车道 | `.tlLane` **24**，圆角 6，底 `surface-1` | 缩放/注释/变速/裁切共用这种瘦道 |
| 效果块 | `.lanePill` **高 22**，`top: 1`，**宽=时长（min 1px）** | 禁止用 % 做最小宽（会把短块画成假时长） |
| 缩放柄 | **6px**；太窄时柄翻到块外，移动仍可点 | 专门解决「短块没法拖」 |
| 音频行 | `AUDIO_ROW_HEIGHT_PX = 26`，垫 3，缝 3 | 为波形略高于效果道 |
| 正片道 | `.tlClips` **66** | 唯一允许高的一条 |
| 正片块 | `.tlClip` 半径 **11**、边 1.5 | **半径偏圆，我们不抄**（和本夹去 AI 圆角冲突） |
| 行序 | `column-reverse`：**正片钉在底**，效果道在上，矮面板时往上滚 | 剪映同结构 |
| 空道提示 | 11px、`--meta`，刻意比内容更淡 | 五条空道不能一起喊 |
| 滚动条 | **藏掉**（防占宽导致标尺/播头错位） | 我们抽屉规范要细可见条；轨道用 **叠加细条**，不占布局宽 |
| AI / 智能增强 / Full Camera | 有 | **不移植** |

设计稿 `design/components/editor/TimelinePill.jsx`：块高 22、半径 6、字 11——和 CSS 一致。

## 三、剪映 / 专业工具（习惯，不是像素抄）

| 习惯 | 剪映 / CapCut、Premiere | 我们应对齐 |
|------|-------------------------|------------|
| 正片在最底 | 是 | 把 Clip 行挪到底 |
| 效果/字幕/音频在上、更瘦 | 是 | 效果道 24，正片 52 左右 |
| 块宽 = 真实时长 | 是 | 保持 min 1–6px，禁止按百分比抬最短块 |
| 短块仍能拖/缩 | 是 | 柄 6px；太窄柄外置（学 OS 几何，不学它的圆） |
| 运输条在预览和时间轴之间 | 剪映是 | **位置保留**，只瘦、去圆胶囊 |
| 面板可上下拖 | 剪映是 | 本轮可不做（OS 有；先把行高做对） |
| 糖渐变 / 大圆角卡片 | 不是专业默认 | 实色 + 半径 3 |

## 四、差距 → 该到哪

| # | Recordly 现在 | OpenScreen / 剪映 | 本夹该到哪 |
|---|---------------|-------------------|------------|

## 五、风险

| 改 | 风险 | 控 |
|----|------|----|
| 去掉 stretch、固定行高 | 现有 `timelineLayout.test.ts` 要改期望 | 测的是公式，一起改 |
| Clip 行到底 | 老用户空间记忆变 | 对齐剪映；手册一句 |
| 柄 28→6 | 缩放要瞄得更准 | 窄块外置补点；习惯对齐专业软件 |
| 不抄 OS 藏滚动条 | 条若占宽会错位 | 叠加、不占 layout |
| 一次改 Canvas + Item + 玻璃 + 运输条 | 可能近 500 行 | 单列 **WP5**，不和抽屉 WP 混在一个 commit 里也可 |

不过度：不做时间轴高度拖拽、不做 OS 导航条、不移植 AI、不改切割语义。

## 六、补记（对照完成后的两份源码深挖）

与 [`Explore OpenScreen timeline UI`](2d2d1b8a-33f7-4ce2-8e56-92e7aab17978)、[`Explore Recordly timeline UI`](503976a7-9ef3-4e34-a069-393f14b46234) 对账后，方案里改了三处口径：

| 事实 | 原方案风险 | 改定 |
|------|------------|------|
| OpenScreen **默认板高 392**（可拖 160–560） | 若抄 392，预览更小，和「轨道太胖」相反 | **不抄默认 392**；先保持 15%/min 160，只删 stretch |
| V4 **没有**左轨名列；旧 Shell 才有 64px 列。本仓 `sidebarWidth === 0` | 「加 56px 标签列」既不像 V4，也吃横向 | **不加标签列**；行名用淡字或不写，靠颜色认轨 |
| 开字幕的新课常 **6 行**（clip+zoom+caption+3 源音频） | 只改两行 64px 不够 | 源音频钉在正片旁、行高固定 28；3 条波形不再被 stretch 灌满 |
| OS 播头是独立紫 `#6c55ff`（避开 mint 效果块） | 抄紫会和本仓品牌蓝打架 | **继续 `#2563EB`**，只去掉菱形和光晕 |
| OS 运输条在时间轴头 40px；本仓在预览下且 `TimelineToolbar` 未挂 | 搬位置改操作 | **位置不动**（像剪映） |
| 本仓时间轴已是系统滚动条（没挂 `custom-scrollbar`） | 再藏条会和抽屉规范相反 | 换成叠加细条，**不**学 OS `display:none` |
| `ClipMarkerOverlay` 按行高 7.5% 留空 | 行高固定后应对齐 1px | WP5 一并改 |
