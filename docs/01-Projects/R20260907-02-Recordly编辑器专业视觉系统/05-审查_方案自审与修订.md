## 三、核对过、无需改方案的

| 项 | 结论 |
|----|------|
| 左轨 48 / 2px 条 / 底齿轮 | 沿用 R14，只把条从胶囊改直角 |

| 280 标题行 | 「项目 + 新建录制 + 导入」中英都塞得下，不必改成纯图标 |
| 8 列色板 @ 280 | 内边 8、间隙 4 → 格约 29px，够点 |
| 时间轴剪辑语义、导出、Launch | 仍不做 |
| 现成测试 | 仓库里没有 `activeEffectSection` 测；WP2 要补窄测，不是「改已有」 |
