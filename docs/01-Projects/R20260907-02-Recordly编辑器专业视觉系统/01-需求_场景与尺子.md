## 一、角色 / 金路径 / 为什么改 / G / 范围

| 项 | 钉死 |
|----|------|
| 角色 | 培训师，录 **Windows 软件操作** 给学员看 |
| 金路径（动词，不变） | **启动录制 → 停止 → 编辑 → 导出视频** |
| 为什么改 | 进编辑器经常落到「画面」而不是项目库；抽屉像漂浮胶囊、圆角大、空隙浪费；控件一股 AI 味、太胖；内容超出时被截断、滚动条被藏掉；**时间轴行被撑得很胖、块不好点、和剪映/OpenScreen 不像** |
| G1 | 进得去、找得到上次课、侧栏能看完所有控件；**轨道点得中、种类看得清** |
| G2 | 打开编辑器先看见项目格子；抽屉和时间轴变瘦，空间还给预览 |
| G3 | 本夹不改字幕引擎、不改配音 |
| G4 | 专业、客观、严丝密缝；不做新功能、不加新 Tab、不换引擎 |
| 范围 | 仅 Windows；zh-CN + en；`dev-creator`；**只动编辑器**（录制条 / Launch HUD 不在本夹） |

**后说覆盖（按时间，后者为准）：**

1. **每一次进入编辑器**（编辑器窗挂载），默认激活的工具栏 Tab 是 **「项目」**，不是「画面 / 魔杖」。同一次打开里点开一节课也不自动跳到画面。
2. 每个 Tab 的内容板应是 **抽屉**：从左往右抽出，和左轨 **严丝密缝**，占满边角，不搞傻圆形外轮廓。
3. 展示不完必须能 **往下滚**；滚动条要 **看得见、细、协调**，不能截断当没有。
4. Tab **内部**控件也要重做：去掉到处都是的大圆角，去掉「胖」的行高和空隙。
5. 先为 **整个编辑器页面** 定义一套视觉规范，再按规范改。呈现应是专业、客观，不是 AI 圆溜溜。部件之间严丝密缝，不留奇怪空隙。
6. **时间轴 / 轨道**也要纳入同一套皮：现在太胖、不好用。对照本地 `D:\code\openscreen` 的密度与行序，手感对齐 **剪映 + OpenScreen + Premiere**。抄密度和结构，**不抄** AI 增强、不抄 11px 大圆角片段卡。

## 二、你点名的场景（培训师一天）

### 场景 A · 刚停录 / 从启动窗进编辑器

停录或点「打开编辑器」→ 左侧「项目」图标是激活态 → 右边抽屉是项目格子（上次课一眼看见）→ 点格子进课，或点「新建录制 / 导入」。

失败样子：一进编辑器是「画面」抽屉（模糊、渐变色块），要再点一次项目才能找课。

### 场景 B · 空工作区进来找上次课

没有当前成片 → 仍默认「项目」→ 格子里第一张是上次 → 一点就开。

失败样子：空态被别的 Tab 挡住，或项目抽屉被藏起来。

### 场景 C · 拉开抽屉调画面 / 光标 / 摄像头 / 字幕

点左轨图标 → 抽屉从左轨右缘滑出 → 上贴顶栏、下贴时间轴、左贴轨、右贴预览，**没有一圈空气和阴影**。内容比抽屉高时，**细滚动条**能拉到底。

失败样子：一块圆角卡片漂在中间；底都被圆角吃掉；滚不到最后一组控件。

### 场景 D · 在抽屉里调参数（培训师的手感）

滑条、分段、色块、开关排得紧，像 Premiere / Camtasia / VS Code 属性板，不像手机 App 胶囊。色块是方的，滑条是扁的，不是圆球拇指。

失败样子：每个滑条 40px 高、圆角 12–16、色块又圆又稀，一屏只看得见两组。

### 场景 E · 关/开侧栏

顶栏「切换侧栏」仍能把抽屉收掉（只留 48px 轨）。再开，抽屉从左往右出来。金路径（预览、时间轴、导出）不被新入口打断。

### 场景 F · 在时间轴上剪一节课（后说）

停录进编 → 底下是瘦轨道：最底一条是正片，上面是缩放/字幕等瘦道 → 能看清哪段是缩放、哪段是字 → 短块仍能拖移或拉边 → 点块仍打开左边对应属性。预览比现在更大（轨道不再灌满 15% 的空气）。

失败样子：两行各 64px 的渐变糖块；短缩放只能被当成拉边；正片在最顶，找片要抬头；和剪映完全不像。

## 三、成功 / 失败

| 成功 | 失败 |
|------|------|
| 每次冷进编辑器（含刚停录），左轨落在「项目」 | 默认仍是「画面」，或片源一就绪就跳走 |
| 抽屉与左轨共边、直角、无投影悬浮 | `rounded-2xl` + `shadow-xl` 浮在 `p-4` 空隙里 |
| 内容超出必有细滚动条，能滚完全部控件 | `custom-scrollbar` 把滚动条藏掉，底被截 |
| 控件瘦、方角、密；色块方形 | 滑条 40px + 胶囊分段 + 圆形色板 |
| 老用户仍是：点左图标开对应板、点导出先选路 | 为了改皮，换掉金路径或加第三列导航 |
| 深色主题同一套半径/密度，只换面色 | 只改浅色，深色仍圆胖 |
| 轨道：效果道约 24、正片约 52、正片在底、短块能拖 | 行被 stretch 灌到 ~64；糖渐变；柄 28px 吃掉块 |
| 切割/缩放/字幕 **数据行为**与现在一致 | 为了瘦，改掉切割语义或换时间轴引擎 |
