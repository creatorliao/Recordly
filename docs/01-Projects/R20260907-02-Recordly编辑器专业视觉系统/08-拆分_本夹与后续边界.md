## 一、为什么是两份，不是三份

曾想过「抽屉一刀、轨道一刀、收口一刀」。否决。

| 若拆成三份 | 问题 |
|------------|------|
| 先做抽屉、后做轨道 | 第一刀交出去仍是胖时间轴；培训师刚点名的就是轨道太胖。WP1 去 `p-4 gap-3` 立刻改轨道周围，两刀会各挤一次预览 |
| 先做轨道、后做抽屉 | 轨道贴边时底色还是错的（P0-4）；两套皮并存（P0-6） |
| 第三份专收 P3 | 没有金路径价值；另开夹等于给过度设计留坑 |

所以：

| 方案 | 夹 | 一句话 |
|------|----|--------|
| **甲 · 现在** | 本夹 `R20260907-02` | 整页专业皮一次交差：进门、接缝、轨道点得中、预览变高 |
| **乙 · 随后** | `R20260907-03` | 甲做完再动：默认铺几条讲解声、可拖高、残余圆角、死代码 |
| **不单开** | — | P3（minimap / 392 / 左轨名列 / 全站 radius / AI / 记忆 Tab） |

## 二、依赖 · 矛盾 · 互相影响 · 金路径

### 1. 功能依赖（必须同刀或先后钉死）

| 后项 | 依赖前项 | 所以 |
|------|----------|------|
| WP5′ 行高 token 看得见 | WP1 时间轴底色 + 去垫 | 同刀：WP1 先于或并行 WP5′ |
| 去 stretch 不留灰膛 | 同时去掉 `Row` `flex-1` + 面板随内容 | **必须同刀**（P0-1 + P0-2） |
| 柄 6 能点 | 视觉帽与 `resizeHandleWidth` 同号 | **必须同刀**（P0-3） |
| 块内图标 | 去渐变后只靠淡实色 | 同刀：否则认不出缩放/字幕 |
| 运输贴标尺 | WP1 去掉预览列 `gap-3` | 同刀 |
| overlay 条 | 去藏条之后刻度不错位 | 同刀（否则 V17 空话） |
| 可拖高 | 先有「随内容」高度 | **乙**，甲做完再加手动覆盖 |
| 默认一条讲解声 | 先有固定 28px 行 | **乙**：甲先把三行也收瘦，乙再收敛条数 |
| 删 `TimelineToolbar` | 运输条 32 已稳定 | **乙** |
| WP4 散落圆角 | `editorTheme.css` 已存在 | **乙** |
| 快捷键 hint | 运输条 32 布局已定 | **乙** |

### 2. 前后矛盾（甲乙都不得推翻）

| 矛盾 | 处理 |
|------|------|
| A1「进门项目」vs「停录想剪」 | 甲保持 A1；用正片钉底 + 预览变高补「眼睛在片上」。乙**禁止**改回默认画面 / 禁止记忆 Tab（P3-6） |
| 走查「默认一条讲解声」vs `R20260906-14` P01「新录制默认出波形」 | **不是关波形。** 甲保持 `showSourceAudio = true`（有讲解声可见）。乙只改 **默认铺几行**（mixed/mic 优先一条，其余不默认铺）。波形引擎、可关开关都不动 |
| 「面板随内容」vs「可拖高」 | 甲只做随内容。乙在其上加可选拖高，**默认仍随内容**，不把默认改回 15% / 392 |
| 去 stretch vs 行还要灌满 | 甲同时删 stretch 与 `flex-1`。乙禁止加回 stretch |
| 扩展空态收紧 vs 藏扩展 Tab | 甲只收紧空态文案（仍能点到）。乙才考虑藏入口——藏了会少一个左轨，须当操作变更写手册 |

### 3. 互相影响

| 甲若带着乙的行为一起做 | 后果 |
|------------------------|------|
| 甲里同时「收瘦三行」+「藏成一行」 | 分不清是皮修好了还是轨被藏了；回退时两条线缠在一起 |
| 甲里做可拖高 | 和「随内容禁空膛」抢默认高度，验收说不清 |
| 甲里做 WP4 整文件扫圆角 | SettingsPanel ~3800 行必超 500，冲掉滑条/色板这刀 |

| 乙若抢在甲前做 | 后果 |
|----------------|------|
| 先藏两条音频 | 三行各 ~64px 的胖块还在，藏了只是少两行胖，根因没修 |
| 先可拖高 | 仍建立在 15% + stretch 上，拖的是空膛 |
| 先删 TimelineToolbar | 运输条还是圆胶囊高条，后人更找不到工具在哪 |

### 4. 对金路径（录→停→编→导）

| 项 | 甲 | 乙 |
|----|----|----|
