## 一、三条线各自看见什么

### 1. 专业开发

方案方向对（token 单文件、抽屉唯一壳、不插值宽度、不换引擎），但有三处 **按现在写法会做错**：

1. **只删 `stretchFactor` 不够。** `Row.tsx` 仍是 `flex-1`。公式改了，行还会被父级灌满 15% 底板，24/52 token 等于没写。
2. **柄 6px 是两套系统。** 视觉帽在 `ItemGlass`，热区在 `dnd-timeline` 的 `resizeHandleWidth={28}`。只改一边：要么点不中，要么点到的和看到的不是一块。必须同号，并给「宽 < 18px」写测。
3. **SettingsPanel ~3800 行 + 三条 return 壳。** WP3 若在文件里散改 `rounded-*`，必超 500、必漏 `isBackgroundPanel` / 注释早退。只能：外皮交给 `EditorDrawer`，内核只动 `SliderControl` / `SectionLabel` / 色板 class。
4. **6 行新课。** 删 stretch 后高度变成 `28+24+24+28×3+52+缝 ≈ 220`，仍高于 min 160，会滚——这没问题。问题是若面板继续 `height: 15%`，下面会空出一截灰膛，行却不再去填，看起来像「坏了的时间轴」。
5. **叠加滚动条。** Electron/Chromium 经典条会占宽，标尺和块会错一截（OS 才藏条）。实现必须 overlay 或把标尺/画布锁成同一内容宽，验收里要写「拖播放头对准刻度」。
6. **死代码 `TimelineToolbar`。** 不删也可以，但运输条一改，后人会以为时间轴头还有第二套工具。P2 再删。

### 2. 专业设计

整页目标（接缝、直角、密）对。布局上方案还差 **「删垫之后谁来当层次」**：

1. **白底 + `foreground/10` 分割线几乎看不见。** 去掉 `p-4` 阴影后，顶栏/抽屉/预览/时间轴会糊成一张纸。浅色要把 `--ed-split` 提到大约 `foreground/16`，时间轴区用已有却没用的 `--editor-timeline`。
2. **15% 空膛。** 行高瘦了、面板还按 15% 站着，正片底下会空一大块——比现在的「胖行」更业余。面板应 **跟着内容长，上限封顶**，多出来的像素还给预览。
3. **运输条 + 标尺是两条眉。** 剪映是「预览下一条控制，再贴轨道」。可以保留位置，但应做成 **一条 32–36 的时间轴眉**（播放 | 添加 | 时码），标尺紧贴其下，不要再空 12px，也不要再搞一轮圆胶囊。
4. **无轨名 + 六种浅色实底。** 设计上比糖渐变克制，但培训师会问「哪条是字幕」。不要开 56px 列（V4 也没有）；块里留 **11px 图标**，靠色 + 图标认轨。
5. **正片 52 vs 效果 24** 层级对。不要抄 OS 正片 66 和半径 11，否则刚丢掉的 AI 味会从轨道回来。
6. **圆播放键** 可以留（全世界都这样）。「添加图层」胶囊必须方。预览里摄像头圆角是成片，不动。
7. **扩展 Tab** 是空房间。全面修复不必删入口，但空态要贴顶、短、像「已关闭」，不要居中大海报。

### 3. 高频培训师（一天录三节课）

金路径上的真实摩擦：

1. **停录进编先看项目**（A1，已钉）——找上次课方便；但 **这一节刚录完** 的人，眼睛在预览和时间轴，不在项目格子。不要再自动跳到「画面」，但必须让 **正片已经躺在时间轴底、能直接拖**，否则像少了一步。
2. **三条源音频波形** 不是他们要的。他们要「讲解声在不在」。三条 28px 叠在正片上，比一行胖块还烦。默认 **一条讲解声** 就够。
3. **短缩放拖不动** 是日常骂点。柄 6 + 外置是对的；播头也要好抓，视觉可以小，热区不能只剩 8×8。
4. **点时间轴还要能改字、能出属性**——方案已保留，必须当回归，不能为了瘦行弄丢。
5. **导出仍在顶栏。** 布局再密，导出不能藏。不在本夹改导出，但走查时确认顶栏不被抽屉挤没。
6. **笔记本 125%/150%。** 6px 柄、24px 行，培训师常见缩放下必须真机点一遍。

## 二、建议的整体布局（目标框，不是新功能）

在已钉的 48 左轨 + 280 抽屉 + 接缝 0 垫之上，把「中 + 下」收成专业剪辑桌面：

```
[ 顶栏 30：文件 / 编辑 | 课名 | 导出 ]
[ 48 | 280 抽屉 |           预览（吃剩余高度）              ]
[    |          | 时间轴眉 32：添加 · 缩放 · 分割 | 播放 | 音量 ]
[    |          | 标尺 28                                      ]
[    |          | 效果道 24 × N（缩放默认在；字幕/注释有才出现）]
[    |          | 讲解声 28 × 0–N（甲只定行高；默认一条是乙）  ]
[    |          | 正片 52 ─────────────────────────────────── ]
[ 状态栏 22：未保存 | 时码 ]
```

和现方案的差别（只动布局，不改金路径）：

| 现方案 | 建议 |
|--------|------|
| 时间轴 `15%` / min 160，删 stretch 后可能空膛 | **高度 = 内容**，min ≈ 标尺+缩放+正片（~108），max ≈ 220 或 15% 取大；余量给预览 |
| 运输条在预览列、标尺在时间轴，中间曾有 gap-3 | 运输条仍在预览正下，但与标尺 **贴死**，视觉上是一条眉 |
| 源音频可 3 行 | 甲：行高 28；乙：默认 1 条讲解声 |
| 行无图标 | 块内 11px 图标 |
| 分割 `foreground/10` | 浅色加强到约 `/16`，时间轴铺 `--editor-timeline` |

时间轴 **仍不做**：拖高、minimap、AI、换引擎。那是 P2/P3。
