## 一、编辑器壳层怎么拼（事实）

```
EditorShell
├─ EditorHeader          顶栏 30px（R14 已抄 VS Code）
├─ 工作区 .relative.flex.min-h-0.flex-1.flex-col.gap-3.p-4
```

关键数字（`EditorShell.tsx`）：

| 件 | 现在 | 观感 |
|----|------|------|
| 工作区外圈 | `p-4`（16px）+ `gap-3`（12px） | 左轨、抽屉、预览、时间轴彼此悬空，边角空一圈 |

| 扩展抽屉 | 同设置：`rounded-2xl shadow-xl` | 同上 |

| 片源就绪 | `onSourceReady → setActiveEffectSection("scene")` | 打开项目 / 导入 / 停录进编都会被拽回画面 |

## 二、默认 Tab：为什么「每次进编辑器」会落到画面

| 路径 | 代码 | 结果 |
|------|------|------|
| 编辑器挂载 | `useEditorUiState.ts:48` 初始 `"scene"` | 冷启动就是画面 |
| 空工作区 | `VideoEditor.tsx` `onEmptyWorkspace` → `"projects"` + 打开抽屉 | 只有空态才落到项目 |
| 片源就绪 | `onSourceReady` → `"scene"` | 打开格子、导入、刚录完的片一进来，**又跳回画面** |

`onSourceReady` 的调用点（`useProjectOpenActions.ts`）：从项目库打开、导入媒体/项目、以及其它「源已就绪」路径。所以即使用户先看见项目，点开一节课也会被拽到魔杖 Tab。这和口述「每一次进入默认项目」直接冲突。

时间轴选中片段 / 缩放 / 音频 / 字幕仍会把 `activeEffectSection` 切到对应项——这是**会话中**的上下文切换，不是「进入编辑器」。规范应保留，避免点时间轴却打不开对应属性。

## 三、抽屉为什么像「漂浮胶囊」而不是抽屉

三套抽屉皮肤不一致：

| | ProjectsPanel | SettingsPanel / ExtensionManager |
|--|---------------|----------------------------------|
| 宽 | 300 | 332（min 280） |
| 外轮廓 | 直角 + 右边线 | `rounded-2xl`（16px）+ `shadow-xl` |
| 贴轨 | 是 | 否：圆角在左上/左下切出缝 |
| 贴顶/底 | 被壳层 `p-4` 掏空 | 同左，再加投影 |

壳层 `p-4 + gap-3` 让整页都「浮」：左轨不顶窗、抽屉不顶预览、时间轴与上排之间空 12px。这就是口述里「边边角角没利用、很额外的空隙」。

动画：设置板内容用 `motion` 做 **上下淡入**（`y: 8`），不是抽屉的 **左→右抽出**。关抽屉是直接 `settingsPanelVisible ? … : null`，没有宽度过渡。

## 四、内部控件为什么「AI 味、太胖」

规范对照见 `03`。这里只记源码事实。

### 4.1 滑条 `SliderControl.tsx`

- 整行 `h-10`（40px）+ `rounded-xl`（12px）+ 内填色块再 `rounded-[10px]`
- 拇指是一条带 **发光阴影** 的竖线，不是工业软件那种扁轨 + 小方块
- 一行只装一个参数，画面 Tab 里连续 4～6 条就占掉半屏

### 4.2 分段「图片 / Video / 颜色 / 渐变」

- 容器 `rounded-xl` + `p-1`，激活块 `rounded-lg` + 弹簧 `layoutId` 胶囊
- 文案 `text-[10px] font-semibold tracking-wide`，像营销分段不属性板

### 4.3 色板 / 壁纸格

- `wallpaperTileClass`：`rounded-[10px]`，8 列还带 hover 阴影
- 部分色板在真机里呈现为 **正圆**（用户截图 4）
- 删除钮 `rounded-full` 红点（小控件可保留圆，但色块本体不应圆）

### 4.4 区块与留白

- `SettingsPanel` 内容区 `p-4`（16px），区块 `space-y-4` / `gap-2`
- `SectionLabel`：`text-[10px] uppercase tracking-widest` —— 字母间距过大，像时尚杂志栏目标签
- 扩展空态：正中大图标 `rounded-2xl` + 大段说明，中间全是空气
- 项目格子：缩略图 `rounded-[5px]` + **重投影** + hover 上浮 `translate-y-0.5`，像商店卡片不是资源管理器列表/网格

### 4.5 全局 `--radius: 0.5rem`

`index.css` 的 shadcn 默认半径 8px。开关、Select、Button 会吃到这套，抽屉里再叠 `rounded-xl / 2xl`，整页偏圆。

### 4.6 滚动条被故意藏掉

```184:191:src/index.css
	.custom-scrollbar {
		scrollbar-width: none; /* Firefox */
		-ms-overflow-style: none; /* IE/Edge */
	}
	.custom-scrollbar::-webkit-scrollbar {
		display: none; /* Chrome, Safari, Opera */
	}
```

设置板、注释板、预设菜单都挂了这个 class。内容一高，**看起来像截断**，只能靠触控板闷滚。这和口述「应该有滚动条、细、协调」相反。

## 六、关联与冲突（先记，不擅自动手）

| 关系 | 说明 | 处理 |
|------|------|------|
| 与 R14 左轨 | 48px、2px 条、底齿轮 **沿用** | 本夹只改条的圆角（胶囊→直角）和抽屉 |
| 与 R14「设置板漂浮」 | R14 阶段 P04 没要求去掉 `rounded-2xl` | **本夹覆盖**：抽屉改贴边 |

| 与样式预设 R07-01 | 入口方案未落地 | 本夹不改交互；控件皮肤共用 token |
| 与金路径 | 只改默认落点和皮 | 录→停→编→导 动词不变 |
| 与 Launch | 录制条仍圆角体系 | **本夹不动**，避免一次改两间房 |

## 七、风险与规模（过闸用）

| 块 | 预估 | 风险 |
|----|------|------|
| 默认 Tab + 去掉源就绪跳转 | <30 行 | 低。行为变了，要写进手册一句 |
| 壳层去垫 + 抽屉直角贴边 + 抽出动画 | ~80–150 行 | 中。预览宽度会变宽一点（好事） |
| token + 细滚动条 | ~80 行 CSS | 低 |
| `SliderControl` / 分段 / 色板 / SectionLabel | ~150–250 行 | 中。SettingsPanel 很大，只改共用件最稳 |
| 扫完 SettingsPanel 所有 `rounded-xl` | 易 >500 | **高**。方案分期：先共用件，再扫残余 |

不过度设计：不加新 Tab、不改时间轴语义、不把 Launch 拉进来。
