# 03 · 省时剪辑技巧（减轻剪辑工作量）

> 这一篇专门回应你的诉求：**「录制完成后，能帮我减轻剪辑工作量」**。
>
> 结论先说：Recordly 的一大设计目标就是**让你几乎不用做传统剪辑**。很多「剪辑活」它在你录制时就已经帮你准备好了。

---

## 一、核心思路：把「剪辑」变成「确认」

传统做法：录完 → 打开剪辑软件 → 手动找重点 → 手动加缩放 → 手动美化光标 → 手动加字幕……

Recordly 的做法：

1. 录制时**自动记录你的光标活动**（在哪停顿、在哪点击）。
2. 录制后**自动据此建议缩放位置**，你只需一键应用。
3. 光标、边框、字幕这些「美化」都是**面板里点几下**的事，不是逐帧去修。

所以你的剪辑工作量大头，被「自动缩放建议」和「一键美化」吃掉了。

---

## 二、自动缩放：最省事的功能

### 2.1 它是什么

你操作软件时，镜头会自动「放大」到你正在点的地方，让学员看清菜单和按钮。这是培训视频的**灵魂**——不用你再手动切镜头。

### 2.2 两种用法

| 用法 | 在哪 | 说明 |
|------|------|------|
| **自动为新录制应用缩放** | 设置 → 效果 | 打开新录制时，自动建议跟随光标的缩放（新手建议直接开） |
| **从光标建议缩放** | 时间线/缩放面板 | 手动触发，让 Recordly 根据你录制中的光标活动（停顿点、点击点）生成缩放建议 |

> 界面提示语会引导你：如果录制里光标移动数据不够，它会提示「录制中未包含足够的光标移动数据」，这时可以「尝试在关键操作附近有停顿或点击的录制」——**也就是说，录的时候在重点处多停一停、点一点，自动缩放效果会更好。**

### 2.3 配套微调

- **连接缩放**（设置 → 效果）：把连续的缩放区域平滑连成一次连续镜头移动，观感更顺。
- **运动预设**（设置 → 动画预设）：
  - **专注**：更利落，适合演示、讲解、日常录屏（培训推荐）。
  - **平滑**：更柔和，适合发布会风格。

---

## 三、光标润色：让画面显得专业

培训视频里，光标是观众的「视线引导」。Recordly 可以：

| 能力 | 作用 |
|------|------|
| **显示光标** | 开/关渲染后的光标叠加层 |
| **光标大小** | 调大，让学员一眼看到你在点哪 |
| **光标平滑** | 让光标轨迹顺滑（消除抖动） |
| **光标运动模糊** | 快速移动时带拖影，更自然 |
| **点击弹跳** | 点击时有个弹跳动画，强化「点这里」 |
| **光标摆动** | 光标自然摆动，更生动 |
| **循环光标** | 便于导出循环片段 |
| **光标样式** | macOS / Windows 11 / 圆点 / 等多种样式 |
| **点击效果** | 涟漪 / 聚光 / 回声（点击处加特效，让点击更醒目） |

> 培训师建议：**调大光标 + 开启点击效果（涟漪/聚光）**，学员最容易跟上你的操作。

---

## 四、修剪：把「废段」一键删掉

录完总有废段：找文件、卡壳、接电话……用**修剪**处理：

1. 按 `T`（或点剪刀图标），在时间线上标出一段**红色修剪区域**。
2. 拖动红色区域边缘，精确覆盖要剪掉的部分。
3. 导出时，红色区域会被自动删掉。

> 编辑器顶部有「**修剪的工作方式**」图文帮助，第一次用可以先看一眼。

---

## 五、变速：拖沓的地方快进

- 按 `S` 加**变速区域**，把啰嗦/等待的部分快进，重点部分正常速或慢放。
- 适合「演示里有一段冗长的加载/安装过程」，快进掉，学员不困。

---

## 六、注释：边看边提示

- 按 `A` 加**注释**：文本、图片、箭头、模糊。
- 适合在关键步骤上打「注意」「点击这里」等文字，或把敏感信息**模糊**掉（培训视频里遮学员信息/内部数据很实用）。

---

## 七、边框一键美化：让成片有「成品感」

与其花时间调画布，不如直接用内置样式：

- **壁纸 / 纯色 / 渐变**背景
- **留白（内边距）**、**圆角**、**模糊**、**阴影**
- **宽高比预设**（适配不同平台：16:9 横屏课件、9:16 竖屏等）

点几下，原始录屏立刻变成带精致边框的演示视频。

---

## 八、给培训师的「省时套路」总结

1. **录之前**：开「自动为新录制应用缩放」。
2. **录的时候**：在重点操作处**停顿、点击**，给自动缩放留素材。
3. **录之后**：先修剪废段（T）→ 应用自动缩放建议 → 调大光标 + 点击效果 → 套个边框 → 加字幕（见 04 篇）。
4. **导出**：MP4 高质量。

这四步下来，一节课从录完到导出，熟练后可能就几分钟。
