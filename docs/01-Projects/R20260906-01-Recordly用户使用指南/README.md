## 二、一句话认识 Recordly

**Recordly 是一款开源桌面「录屏 + 剪辑」一体应用**，专门为做演示、讲解、产品视频的人设计。

它解决的是这个痛点：你以前录完屏，可能还要把素材丢给剪辑软件去补缩放、美化光标、加背景、加字幕。Recordly 把这一整套都内置了——**录完直接进编辑器，动几下鼠标就能导出一段像样的教学视频**，全程免费。

支持平台（上游产品）：macOS 14+、Windows 10 (Build 19041+)、Linux。  
**本仓库当前开发与分发焦点是 Windows**；下面仍按上游能力写全，避免和官方说明书打架。轨道 A 若改了操作方式，会在对应篇加「变更提示」。

## 三、功能全景（一次看全它到底会什么）

按「录制 → 编辑 → 导出」三段来归类：

### 录制阶段
- 录制**整个屏幕**或**单个应用窗口**
- 录**麦克风声音**和**系统声音**
- 可选**摄像头**（录时悬浮取景；成片贴不贴看编辑器「显示」，详见 `02` §三点）
- **倒计时**延迟（点了录制后缓冲几秒再开始）
- 录制中可**暂停/继续**；**−** 只收起控制条。成片不要控制条：三点菜单保持「从录制中隐藏 HUD」（默认开）

### 编辑阶段
- **拖拽式时间线**：缩放、修剪、变速、注释、音频区域
- **自动缩放建议**：根据你录制时的光标活动，自动挑出该放大的位置（减轻剪辑工作量的关键）
- **光标润色**：平滑、运动模糊、点击弹跳、摆动、循环，还能换光标样式
- **摄像头叠加**：气泡位置预设、镜像、圆角、阴影、随缩放联动
- **画面边框**：壁纸 / 纯色 / 渐变 / 模糊 / 留白 / 圆角 / 阴影 + 宽高比预设
- **注释**：文本、图片、箭头、模糊
- **裁剪**：裁掉画面多余部分
- **音频**：调音量、标准化、加额外音频（配音）
- **自动字幕**：本地语音识别（Whisper），一键生成字幕，可调样式
- **项目保存**：存成 `.recordly` 文件，随时回来接着改

### 导出阶段
- **MP4**（常规视频）或 **GIF**（轻量分享/循环）
- 质量选择（低 / 中 / 高 / 原始）
- GIF 帧率、循环开关、尺寸预设
- 宽高比和输出尺寸控制
- 导出后在系统文件管理器里定位文件
