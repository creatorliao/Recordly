# 02 · 操作教程：从启动录制到导出视频

> 这一篇是「手把手」版，带你走完一条完整路径：**启动 → 选源 → 录制 → 停止进编辑器 → 编辑 → 导出**。
> 建议跟着实际操作一遍，遇到没见过的按钮就回来对照。

> **变更提示（本次更新）**：编辑器顶部新增两个入口——「**返回录制**」（相机图标）和「**项目**」菜单（文件图标）。
> - 以前 Windows 上只能**关掉编辑器窗口**退回录制，现在多了「返回录制」按钮和快捷键 `Ctrl+N`；
> - 以前 Windows 上**没有保存/打开项目入口**（只能靠 macOS 系统菜单），现在「项目」菜单 + 快捷键 `Ctrl+S`（保存）/ `Ctrl+Shift+S`（另存为）/ `Ctrl+O`（打开项目）都有了。
> **旧习惯不变**：直接关编辑器窗口仍然可以退回录制。关窗未保存时用编辑器内弹框（保存/放弃/取消），不再弹出系统原生英文框。顶部磁盘图标也可保存。已去掉 Discord、反馈、账号。
>
> **变更提示（用法澄清，产品未改）**：成片不要控制条 ≠ 条上的「−」。请开三点菜单「从录制中隐藏 HUD」（默认开）。录时看摄像头、成片不要头像：悬浮预览开着，进编辑器后关掉右侧摄像头「显示」。详见 §三。
>
> **变更提示（采集/导出默认更省）**：三点菜单新增「采集画质」。**默认是标准档（约 1080p / 30fps）**，减轻整机卡住。要更清、更顺，选「高清」。导出默认质量从「源画质」改为 **Good**；旧项目里已保存的 source 不会被改掉。出问题把三点菜单「打开日志文件夹」里**最新一份**交给支持。
>
> **变更提示（未录也可以打开编辑器）**：录制条上「打开编辑器」（**拍板**，不再是魔杖）现在**一定进完整编辑器**。还没有刚录的课时，不再出现「没有可加载的视频」整页；会打开空项目，左侧自动切到「项目」选项卡，点历史课、点标了「上次」的那一格，或点「新建录制 / 导入」。有刚录的课则仍直接打开这一课。三点菜单「打开项目」走同一条路。原操作（停录自动进编辑器）不变。
>
> **变更提示（录制条再对齐）**：录制键改成透明底上的小红点（录中变方块并带计时），不再是大红圆。没选源就点录制，会先弹出选源，**选完自动开录**；关掉选择器则不录。条上可切横条/竖条（默认横）。条上「笔记」打开讲稿/提词器小窗，**不进成片、不是旁白**。系统截图里默认看不见控制条（三点里可关）。

## 〇、开始前须知（平台差异）

| 平台 | 注意点 |
|------|--------|
| **Windows** | 系统要求 Windows 10 Build 19041+；老版本可能录屏里会残留真实鼠标光标。**本仓分发与开发焦点在此。** 窗口标题/进程名可能显示为 Electron（防拦截），功能仍是 Recordly。**对内分发用目录包即跑**（见下），不依赖安装包。 |
| **macOS** | 需要 macOS 14+；首次使用会要求**屏幕录制权限**和**辅助功能权限**（系统会弹设置页，开启后重启应用） |
| **Linux** | 目前**不支持隐藏真实光标**；系统声音通常需要 PipeWire |

首次使用若提示授权，按提示去系统设置开启即可。

> **怎么拿到能跑的程序（变更提示）**：对内分发默认给 **文件夹** `recordly-portable-<版本>`（构建后在仓库 `release/` 下）——**进入目录 → 双击 `electron.exe`** 即跑，**不必再解压**。文件夹名与过去解压 zip 之后的一样。不再以安装包（NSIS）为主分发。自动更新已移除，不会自动从网上下载安装包。

## 一、启动应用

双击打开 Recordly。你会看到一个悬浮的**启动 HUD**（一个可拖动的小控制条/面板）。

---

## 二、选择录制源（录什么）

在 HUD 里选择源：

- **屏幕**：录制整个显示器。
- **窗口**：只录某一个应用窗口。**好处**：成片干净，不会录到桌面弹窗等其他内容；**注意**：只能录「可见（非最小化）」的窗口。

> 培训师建议：**优先选「窗口」**，把你要讲的软件单独框出来。

选中后点「**共享**」（或「分享」）确认。

---

## 三、配置录制选项

在正式开始前，把这几项按需设好：

| 选项 | 作用 | 培训师建议 |
|------|------|-----------|
| **麦克风** | 录你的讲解声 | 讲操作时**开** |
| **系统音频** | 录软件本身的声音 | 视内容需要，一般**开** |
| **摄像头** | 开了才能看见取景器，并单独录一份旁路 | 只要**自己看着说话**、成片不要大头：开摄像头 + 显示悬浮预览，停录后在编辑器关掉「显示」（见 §三点） |
| **倒计时延迟** | 点录制后缓冲几秒再开始 | 新手建议设个 3 秒，给自己准备时间 |

> 注意：麦克风在**录制过程中无法切换**（界面会提示「录制过程中无法切换麦克风」），所以开始前先确认好开关。

### 三点菜单：控制条不进成片（已有，默认开）

点启动条右侧 **三个点**，确认这一项是开着的（眼睛带斜杠、那一行高亮）：

| 文案 | 开着时 | 关着时 |
|------|--------|--------|
| **从录制中隐藏 HUD** | 控制条和悬浮取景器**只在你屏幕上**，按设计**不进主视频** | 变成「在录制中显示 HUD」——条和取景器会烧进录像 |

这是「不成片」的开关。默认就是开。若你点过一次关掉，下次还会记住。

**不要和条上的「−」搞混：**

| 按钮 | 作用 | 管不管成片 |
|------|------|------------|
| **−（隐藏 HUD）** | 条从眼前收起来，方便操作软件 | **不管。** 只是你暂时看不见条 |
| **三点菜单「从录制中隐藏 HUD」** | 采集时排除整扇 HUD 窗 | **管。** 成片里不要控制条，开这个 |

### 摄像头：录时能看见自己，成片不贴头像（两步，都已有）

1. **录之前**：摄像头弹出层选设备，保持 **「显示悬浮预览」**（默认就是显示）。你对着镜头能看见自己。  
2. **停录进编辑器**：右侧 **摄像头 →「显示」关掉**，再导出。成片不嵌头像。旁路文件可能还在磁盘上，只是不合成进去。

| 选项 | 在哪 | 作用 |
|------|------|------|
| 显示 / 隐藏悬浮预览 | 启动窗摄像头弹出层 | 只控制**你屏幕上**那扇取景窗，**不管成片** |
| 摄像头 →「显示」 | 编辑器右侧 | **管成片。** 开=预览和导出都贴头像；关=都不贴 |
| 关闭摄像头 | 启动窗 | 取景和旁路都没有，成片也不会自动贴 |

刚录完若开过摄像头，「显示」会**自动打开**（因为有旁路）。成片不要头像时，**每次进去关一次「显示」**即可。没有「只预览、永远不成片」的单独项，用上面两步就够。

---

## 四、开始录制

1. 点「**录制**」按钮。还没选源时，会先让你选屏幕/窗口，选完再开始（有倒计时则先倒数）。
2. 如果设置了倒计时，会先显示倒计时，结束后正式开录。
3. 录制开始后，HUD 会变成**录制控制条**：红点闪烁 + 计时（显示「录制中」）。

然后你就可以**正常去操作你的软件、正常讲话**了。

---

## 五、录制中的控制

录制控制条上的按钮：

| 按钮 | 作用 |
|------|------|
| **打开编辑器**（拍板，仅未录时） | 进完整编辑器。有刚录的课就打开这一课；没有则进空项目，左侧「项目」选项卡选历史课或新建 |
| **笔记** | 打开讲稿/提词器（自动滚、字号、镜像）。只给自己看，不进成片 |
| **横/竖条** | 条上切换；默认横条。竖着时源名只留图标 |
| **暂停 / 继续** | 临时停一下，再按继续（适合中途去处理事情） |
| **停止**（红色方块） | 结束录制，进入编辑器 |
| **麦克风图标** | 录制中不可切换（仅提示） |
| **− 隐藏 HUD** | 把控制条从眼前收起来，不挡操作。**不是**「不进成片」 |
| **取消**（X） | 放弃这次录制 |

---

## 六、停止录制 → 进入编辑器

点「**停止**」后，Recordly 会显示「正在准备录制 / 正在打开编辑器」，随后**自动进入编辑器**。

还没录过也可以在条上点「**打开编辑器**」：会进完整编辑器。没有当前课时，左侧自动打开「**项目**」选项卡——点一格历史课（第一格标「上次」），或「新建录制」「导入」。以前那种「没有可加载的视频」整页已经去掉。

编辑器里你会看到：
- **左侧**：工具轨；第一项是「项目」格子（封面 + 课名）
- **中间**：预览画面（空项目时是提示，选课后出画面）
- **下方**：时间线
- **右侧 / 侧栏**：设置面板（场景 / 字幕 / 缩放 / 光标 / 摄像头 / 边框 / 裁剪）
- **顶部**：文字菜单「文件 / 编辑」（含返回录制、最近打开、保存）；右侧是导出和侧栏开关。**样式预设**在左边「画面」或「光标」面板最上面，不再在导出旁边。

## 七、编辑（核心操作速览）

### 7.1 时间线区域类型

在时间线上，你可以添加这些「区域」：

| 区域 | 快捷键 | 作用 |
|------|--------|------|
| 缩放 | **Z** | 放大某个区域（重点强调） |
| 修剪 | **T** | 标记要删掉的片段（红色区域导出时被剪掉） |
| 变速 | **S** | 快进 / 慢放某段 |
| 注释 | **A** | 加文本 / 图片 / 箭头 / 模糊 |
| 拆分片段 | **C** | 把素材切成两段 |
| 关键帧 | **F** | 打关键帧 |
| 添加图层 | 工具栏「添加图层」 | 添加额外内容（含音频） |

> 删除选中的区域：`Ctrl + D`（macOS 为 `Cmd + D`）。

### 7.2 右侧面板能干什么

- **场景**：总览/主设置入口
- **字幕**：一键生成字幕 + 字幕样式（详见 `04` 篇）
- **缩放**：手动缩放或自动缩放
- **光标**：光标外观、平滑、点击效果、样式
- **摄像头**：「显示」开关 = 成片贴不贴头像；还可调位置/大小/圆角/阴影
- **边框**：壁纸/纯色/渐变/模糊/留白/圆角/宽高比
- **裁剪**：裁掉画面多余部分

> 新手第一步：先把**该剪掉的片段**用「修剪」标出来，成片立刻干净很多。修剪的具体用法，编辑器顶部有个「**修剪的工作方式**」帮助按钮，会图文讲解。

### 7.3 随时保存 / 返回录制

编辑过程中可随时把工作**保存为 `.recordly` 项目文件**，下次打开继续改。

| 操作 | 入口 |
|------|------|
| **保存项目** | 顶部磁盘图标，或「项目」菜单 → 保存项目，或 `Ctrl+S` |
| **项目另存为** | 顶部「项目」菜单 → 项目另存为…，或 `Ctrl+Shift+S` |
| **打开项目** | 顶部「项目」菜单 → 打开项目…，或 `Ctrl+O` |
| **新建录制** | 顶部「返回录制」相机按钮，或 `Ctrl+N` |

> 「返回录制」会先问你**是否保存未保存的改动**（保存 / 丢弃 / 取消），再回到录制界面；正在导出时不能返回，需等导出完成。

## 八、导出视频

1. 在编辑器里打开**导出**面板（设置面板里的「导出」）。
2. 选择格式：
   - **MP4 视频**：常规视频（推荐给学员的课件用这个）
   - **GIF 动画**：轻量分享、循环播放
3. 按需调参数：

| 参数 | 说明 |
|------|------|
| 质量 | 低 / 中 / 高 / **原始** |
| 帧率 | GIF 可调帧率 |
| 循环 | GIF 是否循环播放 |
| 尺寸预设 | 原 / 中 / 大 |
| 输出尺寸 / 宽高比 | 控制成品分辨率 |

4. 点「**导出 MP4**」（或「导出 GIF」）。
5. 等待渲染完成（界面显示进度，GIF 编译可能较慢）。
6. 完成后点「**在文件夹中显示**」定位成品。

## 九、完整路径回顾（速记版）

```
启动 → 选「窗口/屏幕」→ 共享
     → 开麦克风/系统音频（+摄像头/倒计时）
     → 点「录制」
     → （倒计时）→ 边操作边讲解
     → 暂停/继续 / −收起控制条（按需）
     → 成片不要条：三点菜单保持「从录制中隐藏 HUD」
     → 成片不要头像：编辑器右侧摄像头关掉「显示」
     → 点「停止」→ 自动进编辑器
     → 修剪(T)/缩放(Z)/变速(S)/注释(A)/字幕/边框
     → 导出 MP4 → 在文件夹中显示
```
