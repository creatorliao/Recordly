# 02 · 操作教程：从启动录制到导出视频

> 这一篇是「手把手」版，带你走完一条完整路径：**启动 → 选源 → 录制 → 停止进编辑器 → 编辑 → 导出**。
> 建议跟着实际操作一遍，遇到没见过的按钮就回来对照。

> **变更提示（本次更新）**：编辑器顶部新增两个入口——「**返回录制**」（相机图标）和「**项目**」菜单（文件图标）。
> - 以前 Windows 上只能**关掉编辑器窗口**退回录制，现在多了「返回录制」按钮和快捷键 `Ctrl+N`；
> - 以前 Windows 上**没有保存/打开项目入口**（只能靠 macOS 系统菜单），现在「项目」菜单 + 快捷键 `Ctrl+S`（保存）/ `Ctrl+Shift+S`（另存为）/ `Ctrl+O`（打开项目）都有了。
> **旧习惯不变**：直接关编辑器窗口仍然可以退回录制。

---

## 〇、开始前须知（平台差异）

| 平台 | 注意点 |
|------|--------|
| **Windows** | 系统要求 Windows 10 Build 19041+；老版本可能录屏里会残留真实鼠标光标。**本仓分发与开发焦点在此。** 内部安装包窗口标题/进程名可能显示为 Electron（防拦截），功能仍是 Recordly。 |
| **macOS** | 需要 macOS 14+；首次使用会要求**屏幕录制权限**和**辅助功能权限**（系统会弹设置页，开启后重启应用） |
| **Linux** | 目前**不支持隐藏真实光标**；系统声音通常需要 PipeWire |

首次使用若提示授权，按提示去系统设置开启即可。

---

## 一、启动应用

双击打开 Recordly。你会看到一个悬浮的**启动 HUD**（一个可拖动的小控制条/面板）。

---

## 二、选择录制源（录什么）

在 HUD 里选择源：

- **屏幕**：录制整个显示器。
- **窗口**：只录某一个应用窗口。**好处**：成片干净，不会录到桌面弹窗等其他内容；**注意**：只能录「可见（非最小化）」的窗口。

> 培训师建议：**优先选「窗口」**，把你要讲的软件单独框出来。

选中后点「**共享**」（或「分享」）确认。

---

## 三、配置录制选项

在正式开始前，把这几项按需设好：

| 选项 | 作用 | 培训师建议 |
|------|------|-----------|
| **麦克风** | 录你的讲解声 | 讲操作时**开** |
| **系统音频** | 录软件本身的声音 | 视内容需要，一般**开** |
| **摄像头叠加** | 画面角落露脸小窗 | 想露脸讲解时**开** |
| **倒计时延迟** | 点录制后缓冲几秒再开始 | 新手建议设个 3 秒，给自己准备时间 |

> 注意：麦克风在**录制过程中无法切换**（界面会提示「录制过程中无法切换麦克风」），所以开始前先确认好开关。

---

## 四、开始录制

1. 点「**录制**」按钮。
2. 如果设置了倒计时，会先显示倒计时，结束后正式开录。
3. 录制开始后，HUD 会变成**录制控制条**：红点闪烁 + 计时（显示「录制中」）。

然后你就可以**正常去操作你的软件、正常讲话**了。

---

## 五、录制中的控制

录制控制条上的按钮：

| 按钮 | 作用 |
|------|------|
| **暂停 / 继续** | 临时停一下，再按继续（适合中途去处理事情） |
| **停止**（红色方块） | 结束录制，进入编辑器 |
| **麦克风图标** | 录制中不可切换（仅提示） |
| **隐藏 HUD** | 把控制条藏起来，不遮挡操作、不进成片 |
| **取消**（X） | 放弃这次录制 |

---

## 六、停止录制 → 进入编辑器

点「**停止**」后，Recordly 会显示「正在准备录制 / 正在打开编辑器」，随后**自动进入编辑器**。

编辑器里你会看到：
- **中间**：预览画面
- **下方**：时间线
- **右侧**：设置面板（场景 / 字幕 / 缩放 / 光标 / 摄像头 / 边框 / 裁剪）
- **顶部**：左侧是「返回录制」（相机图标）、「打开项目」（文件夹图标）、「项目」菜单（文件图标）等入口；右侧是预设、导出等

---

## 七、编辑（核心操作速览）

### 7.1 时间线区域类型

在时间线上，你可以添加这些「区域」：

| 区域 | 快捷键 | 作用 |
|------|--------|------|
| 缩放 | **Z** | 放大某个区域（重点强调） |
| 修剪 | **T** | 标记要删掉的片段（红色区域导出时被剪掉） |
| 变速 | **S** | 快进 / 慢放某段 |
| 注释 | **A** | 加文本 / 图片 / 箭头 / 模糊 |
| 拆分片段 | **C** | 把素材切成两段 |
| 关键帧 | **F** | 打关键帧 |
| 添加图层 | 工具栏「添加图层」 | 添加额外内容（含音频） |

> 删除选中的区域：`Ctrl + D`（macOS 为 `Cmd + D`）。

### 7.2 右侧面板能干什么

- **场景**：总览/主设置入口
- **字幕**：一键生成字幕 + 字幕样式（详见 `04` 篇）
- **缩放**：手动缩放或自动缩放
- **光标**：光标外观、平滑、点击效果、样式
- **摄像头**：气泡叠加的位置/大小/圆角/阴影
- **边框**：壁纸/纯色/渐变/模糊/留白/圆角/宽高比
- **裁剪**：裁掉画面多余部分

> 新手第一步：先把**该剪掉的片段**用「修剪」标出来，成片立刻干净很多。修剪的具体用法，编辑器顶部有个「**修剪的工作方式**」帮助按钮，会图文讲解。

### 7.3 随时保存 / 返回录制

编辑过程中可随时把工作**保存为 `.recordly` 项目文件**，下次打开继续改。

| 操作 | 入口 |
|------|------|
| **保存项目** | 顶部「项目」菜单 → 保存项目，或快捷键 `Ctrl+S` |
| **项目另存为** | 顶部「项目」菜单 → 项目另存为…，或 `Ctrl+Shift+S` |
| **打开项目** | 顶部「项目」菜单 → 打开项目…，或 `Ctrl+O` |
| **新建录制** | 顶部「返回录制」相机按钮，或 `Ctrl+N` |

> 「返回录制」会先问你**是否保存未保存的改动**（保存 / 丢弃 / 取消），再回到录制界面；正在导出时不能返回，需等导出完成。

## 八、导出视频

1. 在编辑器里打开**导出**面板（设置面板里的「导出」）。
2. 选择格式：
   - **MP4 视频**：常规视频（推荐给学员的课件用这个）
   - **GIF 动画**：轻量分享、循环播放
3. 按需调参数：

| 参数 | 说明 |
|------|------|
| 质量 | 低 / 中 / 高 / **原始** |
| 帧率 | GIF 可调帧率 |
| 循环 | GIF 是否循环播放 |
| 尺寸预设 | 原 / 中 / 大 |
| 输出尺寸 / 宽高比 | 控制成品分辨率 |

4. 点「**导出 MP4**」（或「导出 GIF」）。
5. 等待渲染完成（界面显示进度，GIF 编译可能较慢）。
6. 完成后点「**在文件夹中显示**」定位成品。

---

## 九、完整路径回顾（速记版）

```
启动 → 选「窗口/屏幕」→ 共享
     → 开麦克风/系统音频（+摄像头/倒计时）
     → 点「录制」
     → （倒计时）→ 边操作边讲解
     → 暂停/继续 / 隐藏HUD（按需）
     → 点「停止」→ 自动进编辑器
     → 修剪(T)/缩放(Z)/变速(S)/注释(A)/字幕/边框
     → 导出 MP4 → 在文件夹中显示
```

## 十、默认快捷键速查表

| 操作 | 默认快捷键 |
|------|-----------|
| 添加缩放 | `Z` |
| 添加修剪 | `T` |
| 添加变速 | `S` |
| 添加注释 | `A` |
| 拆分片段 | `C` |
| 添加关键帧 | `F` |
| 删除选中 | `Ctrl/Cmd + D` |
| 播放 / 暂停 | `空格` |
| 循环切换注释 | `Tab` / `Shift + Tab` |
| 平移时间线 | `Shift + 滚轮` |
| 缩放时间线 | `Ctrl/Cmd + 滚轮` |

> 快捷键可在编辑器里**自定义**（「快捷键」按钮 → 自定义）。
