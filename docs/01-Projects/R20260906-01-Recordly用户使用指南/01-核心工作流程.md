# 01 · 核心工作流程是什么

> 这是你使用 Recordly 必须建立的第一张心智地图。记住一句话就够了：
>
> **录制（录屏） → 编辑（修整/美化） → 导出（成片）**

---

## 一、三阶段总览

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  ① 录制      │ ───▶ │  ② 编辑      │ ───▶ │  ③ 导出      │
│  录下操作过程 │      │  修整、美化、  │      │  输出 MP4 或 │
│  （屏幕/窗口） │      │  加字幕、配音  │      │  GIF 成片    │
└─────────────┘      └─────────────┘      └─────────────┘
```

对培训师来说，最典型的应用方式就是：

1. 打开你要讲的那款软件；
2. 用 Recordly 录制你的操作过程（边操作边解说）；
3. 录完自动进入编辑器，把多余片段剪掉、把重点处放大、加个边框/字幕；
4. 导出 MP4，发给学员。

全程不离开 Recordly 这一个软件。

---

## 二、阶段一：录制（Record）

**你在做什么**：选好「录什么」，然后点录制，正常操作你的软件。

- 选择录制源：**整个屏幕** 或 **某一个窗口**（窗口录制的好处是成片干净、不录到桌面其他内容）。
- 配置声音：是否录**麦克风**（你的讲解声）、是否录**系统声音**（软件本身的声音）。
- 可选：开**摄像头**，录时用悬浮预览看自己。成片要不要头像：进编辑器后右侧摄像头「显示」开或关（详见 `02`）。
- 可选：设置**倒计时延迟**，点录制后给你几秒准备时间。
- 录制中可**暂停/继续**；**−** 只把控制条收起来。成片不要控制条：三点菜单保持「从录制中隐藏 HUD」（默认开）。确定录完了点**停止**。

**关键点**：点「停止」之后，Recordly 会**自动把你带进编辑器**——不需要手动去找文件。

---

## 三、阶段二：编辑（Edit）

**你在做什么**：把录下来的素材「收拾成能看的课」。

编辑区 = **时间线** + **右侧设置面板**。几个最常用的动作：

| 想做什么 | 怎么做（概念层） |
|----------|------------------|
| 剪掉不要的片段 | 在时间线上**加修剪区域**（快捷键 T），导出时这些区域会被删掉 |
| 突出重点区域 | **加缩放**（快捷键 Z），或让 Recordly **自动根据光标建议缩放** |
| 调整节奏 | **加变速区域**（快捷键 S），把拖沓的部分快进 |
| 加说明文字/箭头 | **加注释**（快捷键 A）：文本、图片、箭头、模糊 |
| 美化光标 | 在「光标」面板调平滑、点击弹跳、样式 |
| 美化画面 | 在「边框/背景」面板加壁纸、渐变、圆角、留白、阴影 |
| 露脸小窗 | 在「摄像头」面板上传/调整气泡叠加 |
| 加字幕 | 在「字幕」面板一键**生成字幕**（本地语音识别） |
| 配音/背景乐 | 在时间线加**额外音频区域**，或在「音频」面板调音量 |

**关键点**：编辑随时可以**保存为 `.recordly` 项目文件**，下次打开接着改，不会丢。

---

## 四、阶段三：导出（Export）

**你在做什么**：把编辑结果渲染成成品文件。

- 选格式：**MP4**（常规视频）或 **GIF**（轻量分享、循环播放）。
- 调参数：质量（低/中/高/原始）、帧率、GIF 循环、尺寸预设、宽高比。
- 点导出，等渲染完成，然后**在系统文件管理器里定位成品**。

---

## 五、把三段串起来看一次（培训师视角）

假设你要录一节「如何在 Excel 里做数据透视表」：

1. **录制**：选「Excel 窗口」为源，开麦克风，开系统声音，点录制，边讲边操作。
2. **编辑**：
   - 用自动缩放，让镜头自动跟着你的光标聚焦在关键菜单上；
   - 把开头找文件、结尾发呆的部分剪掉；
   - 给画面加一个干净的边框；
   - 一键生成字幕，让学员没开声音也能看懂。
3. **导出**：MP4、高质量，导出后发给学员。

这一整套下来，你**几乎没有离开过 Recordly**，也不需要额外学剪辑软件。
