# Recordly 单页速查卡（培训师版）

> 一句话：**录屏 → 编辑 → 导出**，全程一个软件，专为演示/讲解视频设计。  
> 本仓开发/分发焦点是 **Windows**；内部安装包进程名可能是 Electron（防拦截），功能不变。
>
> **变更提示**：对内主发 **目录包即跑**（打开 `recordly-portable-<版本>` → 双击 `electron.exe`，不用先解压），不以安装包为主分发；自动更新已移除。编辑器顶部新增「返回录制」（相机）和「项目」菜单（文件图标）；Windows 也能 `Ctrl+S` 保存项目、`Ctrl+O` 打开项目、`Ctrl+N` 返回录制了。成片不要控制条用三点菜单「从录制中隐藏 HUD」，不要用「−」。成片不要头像：编辑器摄像头关掉「显示」。
>
> **变更提示（未录也可以打开编辑器）**：条上「打开编辑器」一定进完整编辑器。没有当前课不再出「没有可加载的视频」整页，而是空项目 + 左侧「项目」选项卡（点历史课 / 「上次」/ 新建录制 / 导入）。有刚录的课仍直接打开这一课。

## 1. 完整路径（照着走一遍）

```
启动 → 选「窗口/屏幕」→ 共享
     → 开麦克风 + 系统音频（可选：摄像头、倒计时）
     → 点「录制」→ 边操作边讲解
     → 暂停/继续、−收起控制条（按需）
     → 点「停止」→ 自动进编辑器
     → 修剪/缩放/字幕/边框（见下）
     → 导出 MP4 → 在文件夹中显示
```

**记住**：点「停止」后自动进编辑器，不用手动找文件。

**保存 / 返回录制**：顶部磁盘图标 = 保存（与 `Ctrl+S` 相同）；「项目」菜单仍可另存为/打开；「返回录制」（相机）会问是否保存。未保存时关窗口也用同一套弹框，不再弹出系统原生英文框。已去掉 Discord / 反馈 / 账号。标题栏带版本号。

## 2. 录制（重点）

| 项 | 说明 |
|----|------|
| 选源 | 培训建议选**窗口**（成片干净，只录该软件） |
| 采集画质 | 三点菜单：默认**标准 1080p30**；要 4K60 选「高清」。默认更省，避免整机卡 |
| 麦克风 | 录讲解声；**录制中不能切换**，开始前确认 |
| 系统音频 | 录软件本身声音 |
| 摄像头 | 录时：开摄像头 +「显示悬浮预览」。成片不要头像：编辑器右侧摄像头关掉「显示」 |
| 倒计时 | 新手设 3 秒，给自己准备时间 |
| 控制条不成片 | 三点菜单保持「从录制中隐藏 HUD」（默认开）。**−** 只是收起条，不管成片 |
| 控制 | 暂停/继续、停止（红方块）、−收起条、取消（X） |

## 3. 编辑速查（时间线）

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 添加缩放 | `Z` | 放大重点区域 |
| 添加修剪 | `T` | 标记删除片段（红色区域导出时剪掉） |
| 添加变速 | `S` | 快进/慢放 |
| 添加注释 | `A` | 文本/图片/箭头/模糊 |
| 拆分片段 | `C` | 切成两段 |
| 添加关键帧 | `F` | 打关键帧 |
| 删除选中 | `Ctrl/Cmd + D` | 删除 |
| 播放/暂停 | `空格` | — |
| 循环切换注释 | `Tab` / `Shift+Tab` | — |
| 平移时间线 | `Shift + 滚轮` | — |
| 缩放时间线 | `Ctrl/Cmd + 滚轮` | — |

**右侧面板**：场景 / 字幕 / 缩放 / 光标 / 摄像头 / 边框 / 裁剪。

## 4. 省时剪辑（减轻工作量）

| 招 | 怎么做 |
|----|--------|
| **自动缩放**（最省事） | 设置开「自动为新录制应用缩放」；或时间线「从光标建议缩放」 |
| 录出好缩放素材 | 重点处**停顿、点击**，自动缩放更准 |
| 连接缩放 | 设置→效果，连续缩放连成一次顺滑镜头 |
| 运动预设 | 培训选「专注」（利落） |
| 光标润色 | 调大光标 + 点击效果（涟漪/聚光） |
| 修剪废段 | `T` 标记，导出自动删 |
| 变速拖沓段 | `S` 快进 |
| 边框美化 | 壁纸/纯色/渐变 + 圆角/留白/阴影 + 宽高比预设 |

---

## 5. 字幕与配音

| 需求 | 做法 |
|------|------|
| **自动字幕** | 字幕面板 → 首次「下载模型」→ 选语言 →「生成字幕」（本地 Whisper 识别，不联网） |
| 字幕样式 | 字体/字号/颜色/背景透明度/圆角/动画（淡入/上移/弹出） |
| 字幕改错 | 逐条编辑文字、起止时间，可拆分/合并/删除 |
| **配音（现场）** | 录制时**开麦克风**，边操作边讲（最常用） |
| **配音（后期）** | 时间线「添加图层」加**音频区域**导入配音/配乐，音频面板调音量/标准化 |

## 6. 导出

| 项 | 选择 |
|----|------|
| 格式 | **MP4**（课件）/ GIF（轻量循环） |
| 质量 | 低 / 中 / 高 / **原始** |
| 其他 | GIF 帧率、循环、尺寸预设（原/中/大）、宽高比 |
| 收尾 | 完成后「在文件夹中显示」 |

## 7. 平台坑（提前看）

- **Windows**：需 Build 19041+；老版本录屏可能残留真实光标。
- **macOS**：需 14+；首次要求**屏幕录制 + 辅助功能**权限，开启后重启。
- **Linux**：不支持隐藏真实光标；系统声音通常需 PipeWire。

## 8. 培训师省时套路（总口诀）

```
录前开自动缩放 → 录时重点处停顿点击
→ 录后：修剪废段(T) → 套自动缩放 → 调大光标+点击效果
→ 套边框 → 生成字幕 → 导出 MP4 高质量
```
