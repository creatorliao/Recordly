# 04 · 字幕与配音教程

> 这一篇回应你的诉求：**「如果能加上字幕或配音，那就更好了」**。
>
> 好消息：**字幕和配音，Recordly 都能做**，而且字幕是**本地自动生成**，不用手动逐句敲。

---

## 一、字幕：本地自动识别，一键生成

### 1.1 原理（一句话）

Recordly 内置 **Whisper**（本地语音识别引擎），它会「听」你录制里的语音，自动把说话内容转成字幕。**全程在你自己电脑上完成，不联网上传音频。**

### 1.2 生成字幕的步骤

> **变更提示（1.4.0-beta.4 界面收敛）**：识别模型已打进 Portable 的 `resources/whisper/`。字幕面板**没有**「下载模型」「选择模型」「语言」。打开就能点「生成字幕」，默认按**简体中文**识别。请进入 `recordly-portable-<版本>` 文件夹后再双击 `electron.exe`；若别人仍给你 zip，先完整解压，不要从压缩包窗口直接运行。

1. 在编辑器右侧打开「**字幕**」面板。
2. 点「**生成字幕**」（生成中会显示「生成中...」）。
   > 注意：Windows 上如果提示缺少运行库，按提示安装 Microsoft Visual C++ x64 Redistributable 后重启即可。
3. 生成完成，字幕会出现在画面和时间线上。

以后想重来：可「**重新生成字幕**」或「**清除字幕**」。时间轴上「悬停添加」要先打开面板里的「**显示**」，再在字幕轨上悬停点击。

### 1.3 字幕样式（让字幕好看）

字幕面板提供完整样式控制：

| 设置 | 作用 |
|------|------|
| 字体 / 字号 / 行数 | 字幕文字外观 |
| 文字颜色 / 背景透明度 / 字幕框圆角 | 颜色与底框 |
| 动画 | 关闭 / 淡入淡出 / 上移 / 弹出 |
| 底部偏移 | 字幕离画面底部的距离 |
| 最大宽度 | 字幕换行宽度 |

### 1.4 字幕微调（个别句子改字/时间）

生成的字幕可以**逐条编辑**：

- 修改**文字、开始时间、结束时间**
- **拆分 / 合并 / 删除**某条字幕

> 识别偶有错字，用「编辑文字」改一下即可，不用重新生成。

## 二、配音：两种方式

### 方式 A：录制时直接录你的讲解（最简单）

录制阶段**打开麦克风**（见 `02` 篇），你边操作边讲解的声音就会直接进成片。这是培训师**最常用**的配音方式——录屏和配音一次完成。

### 方式 B：后期在时间线加「额外音频」（配音/背景乐）

如果录完了想补配音、或加一段背景音乐：

1. 在时间线工具栏用「**添加图层**」添加**音频区域**（导入你的音频文件，如提前录好的配音 MP3、背景乐）。
2. 拖动音频区域到对应时间段。
3. 在「**音频**」面板调整：

| 设置 | 作用 |
|------|------|
| 音量 | 调大/调小 |
| 标准化 | 把音量自动拉到统一水平 |
| 剪辑源音频 | 单独控制**系统声音**和**麦克风**两路的音量 |

> 这样就能实现「画面是录屏 + 声音是后期配音/配乐」的组合。

## 三、给培训师的组合建议

| 场景 | 推荐做法 |
|------|----------|
| 现场讲解型课程 | 录制时开麦克风直接讲 + 生成字幕（字幕兜底，方便静音观看） |
| 精修型课程 | 先录纯操作，后期加配音音频区域 + 生成字幕 |
| 需要配乐的演示 | 录屏 + 额外音频区域加背景乐（音量调低，别盖过人声） |

---

## 四、相关提醒

- 生成字幕前，确认录制里**确实有可识别的语音**；纯操作无讲解的视频，字幕会是空的。
- 字幕识别质量受**口音、语速、环境噪音**影响，个别字句需要手动微调。
- 配音/配乐与源音频的音量平衡，用「音频」面板的**音量**和**标准化**来调。
