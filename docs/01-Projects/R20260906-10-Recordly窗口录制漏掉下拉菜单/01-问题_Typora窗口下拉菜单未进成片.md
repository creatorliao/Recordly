# 01 · 问题：Typora 窗口下拉菜单未进成片

> 2026-09-06 用户点名 + 真机截图。先记现象与根因，**方案见 `03`。产品代码未改。**

## 1. 现象

在 Recordly 里录 **Typora** 操作时：屏幕上已经点开了菜单栏「**主题(T)**」的下拉列表（Github / Newsprint / Night / Pixyll / Whitey），成片里**整块下拉都没有**。不是裁掉一角、也不是只有阴影没了，是列表本身完全不在录像里。

截图特征（用于定性，不是个别主题皮肤问题）：

- 窗口标题：`2027年度目标与规划方案 (框架稿) .md - Typora`
- 菜单栏是 Windows 原生助记符风格：`文件(F)` … `主题(T)` …
- 下拉有圆角、明显投影，叠在正文之上，看起来像浮在主窗外面的一层

这是培训师金路径上的内容缺失：讲「怎么点菜单」时，学员在成片里看不见点开了什么。

## 2. 复现（当前判断）

| 项 | 内容 |
|----|------|
| 被录软件 | Typora（Electron，Windows 原生菜单栏） |
| 本机 OS | Windows 10.0.19044（21H2） |
| 高概率选源 | HUD「**窗口**」→ 选 Typora（使用指南也写「培训师优先选窗口」） |
| 操作 | 点菜单栏某一项，下拉展开 |
| 期望 | 成片里能看见完整下拉 |
| 实际 | 下拉整块缺失，主窗正文仍在 |

尚未用「同一段操作、窗口源 vs 屏幕源」做对照（见 `03` 闸门）。同类症状预期也会出现在：Office / 资源管理器 / 记事本等 **Win32 原生菜单**，以及部分 Electron 的原生 `Menu`。

## 3. 目标锚点

| 项 | 内容 |
|----|------|
| 角色 | 培训师，录软件操作 |
| 金路径 | 启动录制 → 停止 → 编辑 → 导出 |
| 落点 | **G1** 成片能看见实际点到的菜单；**G2** 不必因菜单没录上而重录 |
| 范围 | 仅 Windows；`dev-creator`；不代合上游 |

## 4. 对工作流

未改录→停→编→导步骤。当前规避（不改代码）：同一台机器改选 HUD「**屏幕**」再录一次，用来确认菜单是否出现。正式改法见 `03`。
