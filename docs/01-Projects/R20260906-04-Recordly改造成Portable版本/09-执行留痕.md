## 变更 1 · 目录包不再打 zip，分发收进 `release/`

| 维度 | 记录 |
|------|------|
| **① 修改了哪些内容** | `scripts/build-win-portable.mjs`；`scripts/smoke-packaged-binaries.mjs`；`.gitignore`（`/preload.mjs`）；手册 `R20260906-01` 的 `02`/`04`/`05`；Areas `20260906-03`；本夹 `00`/`03`/`12`/`13` |
| **② 是怎么修改的** | portable 从 `--win zip` + `release-portable/` 改为 `--win dir`，经 `release/.portable-staging` 改名为 `release/recordly-portable-<version>`。根目录漏网 `preload.mjs` 忽略并删除，不进仓 |
| **③ 有什么作用** | 构建完直接得到与过去解压后同名的文件夹，不必再解压约 680MB zip；分发只看一个 `release/`。`dist` 与 `dist-electron` 不合并（两套 Vite 产物，改路径碰启动） |
| **④ 对原工作流程的影响** | 录→停→编→导不变。打开方式从「解压 zip → 进目录 → 双击 exe」改为「打开 `release/recordly-portable-<版本>` → 双击 `electron.exe`」。需要网传时再手工压缩该文件夹 |

- 调查 / 方案：`12`、`13`
- 未做：未删除本机已有的 `release-portable/*.zip`（可手工删腾盘）
