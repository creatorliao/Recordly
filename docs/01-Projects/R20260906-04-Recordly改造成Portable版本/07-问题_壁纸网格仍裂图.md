# 07 · 问题：背景「图片」网格仍整页裂图

> 2026-09-06 再验：场景背景仍是裂图图标 + 被裁切的英文 alt（`Tab` / `Mid` / `iDa` = Tahoe / Midnight / iPad）。  
> 上一轮 `05` 已让 `getAssetPath` 在 HTTP 窗口返回 `/wallpapers/…`，真机仍裂。

## 1. 现象

打包 Studio → 背景 → 图片：约 24 格裂图。`listAssetDirectory` 能列出文件（格子有名字），`<img>` 读不到图。

## 2. 根因

缩略图仍优先走 **本机 HTTP `/wallpapers`**。两条都会裂：

1. `generate-wallpaper-thumbnail` 若收到 `/wallpapers/foo.jpg`，在 Windows 上被当成盘符根路径，读盘失败。  
2. HTTP 映射一旦 404（extraRoot 启动瞬间不对、回退 `loadFile`），`<img src="/wallpapers/…">` 没有后备。

裂图 `alt` 是壁纸专名，按尺子不翻译。

## 3. 方案

主进程把 `wallpapers/…` 或 `/wallpapers/…` **解析到 `getAssetRootPath()/wallpapers`**，用已有 IPC 出 JPEG data URL。网格不再依赖 HTTP img。

## 4. 对工作流

只修背景预览，不改录→停→编→导。

## 5. 后续
