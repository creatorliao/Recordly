# 08 · 问题：光标仍记不下来，进编辑器没有自动缩放

> 2026-09-06 再验：录完进 Studio 仍无缩放块；建议缩放仍判无遥测。  
> `06` 已避免「空 pending 删 sidecar」，真机仍空。

## 1. 现象

鼠标动过、点过，时间轴没有自动缩放。

## 2. 根因

| 层 | 事实 |
|----|------|
| 空写 | `writeCursorTelemetry([])` **仍会删除** `*.mp4.cursor.json`。编辑器或二次 finalize 写空数组，会把刚落下的 sidecar 删掉。 |
| 清 pending | persist 成功后立刻清空 pending。若随后换了成片路径再 persist，内存里已经没样本。 |
| 自动缩放 | 算法已能在无点击时用停留启发式；**没有 sidecar 就什么都没有**。 |

## 3. 方案

空 payload **不删**已有 sidecar；persist **不清空** pending（下次开录才清）；同一批样本写到 finalize 路径与 `currentVideoPath`（若不同）。

## 4. 对工作流

录完应能自动出缩放建议。不改操作步骤。
