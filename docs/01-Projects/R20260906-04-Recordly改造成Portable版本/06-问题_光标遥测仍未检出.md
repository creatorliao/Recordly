# 06 · 问题：进 Studio 仍提示无光标遥测 / 鼠标缩放不出现

> 2026-09-06 再验：时间轴点建议缩放，气泡「No cursor telemetry available / Record a screencast first…」。  
> 三点菜单里本来就没有「遥测 / 鼠标」开关——鼠标数据在录制时采集，进 Studio 后表现为时间轴缩放块，不在启动窗菜单。

---

## 1. 现状

- 录完进 Studio，自动缩放块没有。  
- 手动「从光标建议缩放」判定 `cursorTelemetry.length < 2`。  
- 上一轮已：helper 输出 `INTERACTION`、算法认停留、本机重编 `cursor-monitor.exe`。

## 2. 根因（叠在一起）

| 层 | 事实 |
|----|------|
| 落盘 | `persistPendingCursorTelemetry` **只写 `pending`**。若先 `set-recording-state(false)` 把 `active` 清掉、pending 又被某次空 persist 清掉，sidecar 就是空的或不存在。 |
| 空写 | `writeCursorTelemetry([])` **会删掉** 已有 `*.cursor.json`。二次 finalize（mux / store）在 samples 已清空时会把刚写下的遥测删掉。 |
| 提示 | 无数据时的英文是硬编码，看起来像「功能没做中文 / 没接上」。 |

采集本身（Electron 定时 `move` + helper 按下/抬起）在 `set-recording-state(true)` 后是开的；真机「完全没数据」更像 **sidecar 没落到编辑器正在读的那条视频路径，或被空写删掉**。

## 3. 方案

1. persist 时：pending 空则先从 active 快照；有样本才写；**空 payload 不删已有 sidecar**。  
2. 读取时：当前视频路径读不到，再试 `currentVideoPath`。  
3. 时间轴提示走 i18n（见 `R20260906-05/03`）。

## 4. 执行

已改 `electron/ipc/cursor/telemetry.ts`、读取 handler、时间轴提示。  
**怎么验：** 新包录 15 秒以上（移动鼠标、点一下、拖一下）→ 进 Studio，时间轴应有缩放块；建议缩放不应再报「先录一段」。
