# 05 · 问题：Studio「图片」网格仍整页裂图

> 2026-09-06 再验 portable：场景背景 24 格仍是裂图；格子里露出被裁切的英文 alt（`Tab` / `Mid` / `iDa`），那是 **Tahoe Light / Midnight / iPad** 裂图后的替代文字，不是另一套翻译。

---

## 1. 现状

- 网格约 3×8，每格浏览器默认裂图图标。  
- `extraResources` 里 `resources/assets/wallpapers` 文件在；`rendererServer` 已把 `/wallpapers` 指到该目录。  
- 上一轮「映射 extraResources」打进包后，真机仍裂。

## 2. 根因

打包窗口是 **HTTP**（`http://127.0.0.1:<port>`），但 `getAssetPath` **优先** `getAssetBasePath()` → `file:///…/resources/assets/…`。

缩略图链路：

1. `getAssetPath` 得到 `file://`  
2. `generateWallpaperThumbnail` / `readLocalFile` 任一失败（路径、nativeImage 空图、整图 IPC 过大）  
3. `<img src="file://…">` 从 HTTP 源加载，整页裂图  
4. 已写好的 HTTP `/wallpapers` 映射 **根本没被用上**

格子里的英文碎片是裂图 `alt`（壁纸专名，按尺子不翻译）。

## 3. 方案

HTTP 渲染进程里 `getAssetPath` **直接返回** `/wallpapers/…`，让本机 renderer 服务器读 extraResources。  
`file://` 只留给非 HTTP（极少）窗口。导出若要磁盘路径，继续用主进程 `getAssetBasePath`，不经过 img src。

## 4. 执行

已改 `src/lib/assetPath.ts` 与单测。  
**怎么验：** 新 portable 进 Studio → 场景「图片」，应出壁纸缩略图，不应 24 格裂图。
