# 01 · 需求：把 Recordly 改成 Portable

> 来源：工作区提示、`AGENTS.md` G1–G4、`R20260906-02` R18–R19 / R18c、你 2026-09-06 的改判（要 portable；安装包每次被内部拦截，将来发布不要以安装包为主）。

---

## 一、角色与为什么改

| 项 | 内容 |
|----|------|
| **角色** | 培训师，在 Windows 上录软件操作，导出给学员 |
| **现在卡在哪** | 本仓能打 NSIS 安装包，但**每一次安装都会被内部软件拦截**；身份改成 Electron（`a2e32fa1`）只解决「厂商名」，解决不了「像安装器」 |
| **成功** | 不解压失败 → 双击目录里的 exe → 能走完 录→停→编→导；**日常分发不再依赖安装包** |
| **失败** | 仍必须跑安装向导；或 ZIP 里的 exe 同样被拦且没有下一步；或 portable 改坏了金路径 |
| **不是为了** | 替上游做官方 Release、做 Linux AppImage、做成第二个产品 |

对应目标：**G1 装得上**（金路径的第 0 步）。G4：少而稳，改分发形态，不借机加功能。

---

## 二、需求条目（可验收）

| # | 需求 | 衡量 |
|---|------|------|
| N1 | Windows **解压即跑**：ZIP（或同等目录）里有可执行文件，无安装向导 | 不解压到 Program Files、不要管理员也能启动 |
| N2 | **对内主发 ZIP**，不把 NSIS 当日常分发 | 给你/同事的包是 ZIP；手册写「解压后打开 exe」 |
| N3 | 金路径不因 portable 断裂 | 录→停→编→导与现在一致 |
| N4 | 身份仍是 **Electron 默认** | 进程/厂商串不回到未备案名 |
| N5 | 构建机 **仍能**打出 NSIS（备胎） | 不删 `build:win` 安装能力；不当主发 |
| N6 | 第一步允许配置/录像仍在本机 AppData | 「能跑」优先于「U 盘带走全部数据」 |
| N7 | 第二步（可选）数据跟 exe 走 | 项目、设置、Whisper 模型可放在应用旁；默认仍可关 |
| N8 | 改了打开方式 → 同步使用指南 | `R20260906-01` 写清：原来双击安装，现在解压运行 |

**你点名的发布问题（已记）：** 将来发布是否只出 portable、不要安装包？——见 `03` 与 `14` D17。代决：对内主发 ZIP；彻底停打 NSIS 等 T3+T12 真机对比。

---

## 三、范围

**做：** 本仓 `dev-creator`、仅 Windows x64、electron-builder 产物与必要的路径/更新策略、手册。

**不做：** Linux / macOS portable；重建扩展商店；官方 GitHub Release 流程；把单文件自解压 `portable` 当默认（太像安装器）；本阶段不改金路径交互。

**不做完整「绿色软件神话」一步到位：** 不要求第一次就做到无 AppData、可写 U 盘、自动更新全关且完美。分步见 `03`。

---

## 四、与金路径的关系

```
拿到包 → 能启动 → 启动录制 → 选窗口 → 讲解 → 停止 → 编辑 → 导出
         ↑
      本主题只保证这一段（装得上 / 开得了）
```

Portable **不插队** HUD/麦/保存那些产品 P0。它跟 **轨道 B（能装能跑）** 走，不挡轨道 A。
